# 文件规划：frontend/src/views/GraphPage.vue 🟡

> 🟡 力导向图谱——ECharts 或 D3.js 实现，64 节点 + 8 宫关系边。

## 1. 基本信息
- **所属模块**：frontend/views/
- **优先级**：P2
- **依赖文件**：`echarts`（或 `d3`）、`frontend/src/api/index.js`、`shared/GuaCiFloat.vue`
- **被依赖文件**：`frontend/src/router/index.js`

## 2. 核心职责
网络图谱页面（独立全屏模式，非八宫变化页中的小窗）——力导向布局展示 64 卦之间的关系。

## 3. 页面布局
```
┌──────────────────────────────────────────────────┐
│  图谱类型: [八宫关系▼] [互卦关系] ...             │
├──────────────────────────────────────────────────┤
│                                                  │
│            力导向布局图谱                         │
│       ○ 节点 = 卦（大小=度数）                    │
│       ─ 边 = 八宫变化关系                         │
│       颜色 = 卦宫                                │
│       悬停 = 显示卦名+代码                        │
│       点击 = 弹出 GuaCiFloat                      │
│                                                  │
└──────────────────────────────────────────────────┘
```

## 4. 内部逻辑要点
- 节点数据：从 bagong_gua 获取 64 卦
- 边数据：八宫关系（本宫→一世→二世→...→归魂）
- 按卦宫着色（8 色）
- 力导向参数：斥力/引力/阻尼（ECharts `series.type: 'graph'` + `layout: 'force'`）

## 5. 测试要点
- 64 个节点全部显示
- 节点悬停→显示卦名+代码
- 节点点击→GuaCiFloat 弹出

### 用户测试 👤
打开网络图谱页→确认 64 卦节点完整→点击任一节点→卦爻辞浮窗出现→拖拽节点→图谱重新布局。

## 6. 潜在陷阱与风险
- [ECharts vs D3] ECharts 的 graph/force 适合简单图谱，D3 更灵活但学习成本高。推荐 ECharts（项目已使用）。
- [性能] 64 节点力导向计算量小，性能无问题。但如果后续加互卦边→边数增加，可能需要调整力导向参数。
- [节点位置持久化] 每次刷新页面节点重新布局→位置不固定。可考虑固定初始位置（按八宫分组）。
