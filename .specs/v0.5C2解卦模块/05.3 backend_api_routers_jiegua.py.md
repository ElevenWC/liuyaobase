# 文件规划：backend/api/routers/jiegua.py

## 1. 基本信息
- **所属模块**：api/routers/
- **优先级**：P1
- **依赖文件**：`backend/core/hugua.py`、`backend/crud/bagong_gua.py`、`backend/crud/guaci.py`、`backend/crud/guali.py`
- **被依赖文件**：`backend/api/main.py`

## 2. 核心职责
C2 解卦 API——互卦计算、网络图谱数据、卦爻辞查询。

## 3. 对外接口
```python
@router.get("/hugua/{gua_code}")
async def get_hugua(gua_code: str):
    """获取指定卦的互卦 → 本卦互卦+之卦互卦"""

@router.get("/graph/{graph_type}")
async def get_graph(graph_type: str, gua_code: str = None):
    """获取网络图谱数据（力导向布局的节点和边）"""

@router.get("/guaci/{gua_code}")
async def get_guaci(gua_code: str):
    """获取卦爻辞（供 GuaCiFloat 使用）"""
```

## 4. 内部逻辑要点

### 互卦
- 调 `core/hugua.calc_hugua(code)` 获取互卦代码
- 查 bagong_gua 获取互卦名称
- 如果是卦例编号入口 → 返回本卦互卦 + 之卦互卦

### 网络图谱
- 当前版本返回简单的节点-边 JSON（卦与卦之间的八宫变化关系）
- 节点：64 卦 + 标签（卦宫/五行）
- 边：本宫→一世→二世→...→归魂 的链

### 卦爻辞
- `GET /jiegua/guaci/{gua_code}` → 从 guaci 表查询 → 返回完整卦爻辞 JSON
- 被 C1/C2/C3/C4 的 GuaCiFloat 调用

## 5. 输入输出示例
```python
GET /api/jiegua/hugua/110010  # 水泽节 → {"code":"100001","name":"山雷颐"}
GET /api/jiegua/guaci/111111  # 乾卦 → {"gua_ci":"元亨利贞...", "yao_ci":{...}, "wenyan":"..."}
```

## 6. 测试要点
- 互卦结果与已知对照表一致
- 卦爻辞含全部字段（卦辞/彖传/象传/爻辞/文言/用九用六）

### 用户测试 👤
```bash
curl http://localhost:8001/api/jiegua/guaci/111111 | python -m json.tool
```
确认返回的卦辞/爻辞/文言数据完整。

## 7. 潜在陷阱与风险
- [网络图谱性能] 64 卦 + 8 宫关系的图谱数据可以预先缓存（数据固定，不依赖卦例），首次请求生成后缓存到内存。
