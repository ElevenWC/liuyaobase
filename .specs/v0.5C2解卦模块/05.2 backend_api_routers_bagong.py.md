# 文件规划：backend/api/routers/bagong.py

## 1. 基本信息
- **所属模块**：api/routers/
- **优先级**：P1
- **依赖文件**：`backend/core/bagong_bian.py`、`backend/crud/bagong_gua.py`
- **被依赖文件**：`backend/api/main.py`

## 2. 核心职责
八宫变化 API——输入卦代码，返回该卦的七种变化结果。

## 3. 对外接口
```python
router = APIRouter(prefix="/api/jiegua", tags=["解卦"])

@router.get("/bagong/{gua_code}")
async def get_bagong(gua_code: str, session=Depends(get_session)):
    """获取指定卦的八宫变化 → {"code":200, "data": {"ben_gua": {...}, "steps": [...]}}"""
```

## 4. 内部逻辑要点
- 接收 gua_code（6位）
- 调 `core/bagong_bian.calc_bagong_bian(code)` 获取七变结果
- 每个变化结果补充卦名（调 `crud/bagong_gua.get_by_code`）
- 如果本卦上爻为动爻（yao_bian_code[5]=='1'）→ 不可用八宫变化，返回提示

## 5. 输入输出示例
```python
GET /api/jiegua/bagong/111111
# → {"ben_gua": {"code":"111111","name":"乾为天"},
#     "steps": [{"type":"一世","code":"011111","name":"天风姤"}, ...7个]}
```

## 6. 测试要点
- 正常卦返回 7 步变化
- 上爻为动爻→返回提示"此卦不可用八宫变化"
- 无效卦代码→400

### 用户测试 👤
```bash
curl http://localhost:8001/api/jiegua/bagong/111111
```
应返回乾为天的七步变化。

## 7. 潜在陷阱与风险
- [上爻动爻限制] C2 规则：上爻为动爻的卦不能使用八宫变化。需从 guali 表读取 yao_bian_code 判断。
