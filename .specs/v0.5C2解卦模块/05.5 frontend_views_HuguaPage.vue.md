# 文件规划：frontend/src/views/HuguaPage.vue

## 1. 基本信息
- **所属模块**：frontend/views/
- **优先级**：P1
- **依赖文件**：`frontend/src/api/index.js`、`shared/GuaCiFloat.vue`
- **被依赖文件**：`frontend/src/router/index.js`

## 2. 核心职责
互卦页面——输入卦例编号或自定义卦名→展示本卦互卦和之卦互卦。

## 3. 页面布局
```
┌──────────────────────────────────────────────────┐
│  卦例编号: [___] [加载]  或 自定义: [选择卦▼]    │
├──────────────────────────────────────────────────┤
│                                                  │
│  原卦: 水泽节 110010                              │
│                                                  │
│  ┌─────────┐         ┌─────────┐                 │
│  │ 本卦互卦 │         │ 之卦互卦 │                 │
│  │         │         │         │                 │
│  │ 山雷颐  │         │ 风火家人 │                 │
│  │ 100001  │         │ 101011  │                 │
│  └─────────┘         └─────────┘                 │
│                                                  │
└──────────────────────────────────────────────────┘
```

## 4. 内部逻辑要点
- 输入卦例编号→调 API 获取 ben_code + zhi_code → 分别计算互卦
- 自定义→只展示一个卦的互卦（无之卦互卦）
- 互卦名称可点击→弹出 GuaCiFloat

## 5. 测试要点
- 水泽节→本卦互卦=山雷颐
- 卦名点击→GuaCiFloat 弹出

### 用户测试 👤
输入卦例编号→确认本卦互卦和之卦互卦正确。

## 6. 潜在陷阱与风险
- [之卦不存在] 若爻变代码=000000→只展示本卦互卦，之卦互卦显示"静卦无之卦"。
