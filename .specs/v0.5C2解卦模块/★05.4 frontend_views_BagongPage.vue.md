# 文件规划：frontend/src/views/BagongPage.vue 🟡

> 🟡 重要：用户选择卦例编号或自定义卦名→展示八宫七变→可点击卦图形触发 GuaCiFloat。

## 1. 基本信息
- **所属模块**：frontend/views/
- **优先级**：P1
- **依赖文件**：`frontend/src/api/index.js`、`shared/GuaCiFloat.vue`、`core/bagong_bian.py`（后端）
- **被依赖文件**：`frontend/src/router/index.js`

## 2. 核心职责
八宫变化页面——导航栏 Tab + 卦例编号输入 + 七步变化卦图形展示 + 网络图谱小窗。

## 3. 页面布局（4 行布局，对照设计文档 §2.6-2.7）
```
┌──────────────────────────────────────────────────┬──────────────┐
│  卦例编号: [___] [加载]  或 自定义: [选择卦▼]    │              │
├──────────────────────────────────────────────────┤  网络图谱    │
│  第1行 本卦: 乾为天 111111（卦宫/宫位/特殊类型） │  (小窗)      │
│  [本卦]→[一世]→[二世]→[三世]→[四世]→[五世]     │              │
│       →[游魂]→[归魂]                             │  单击→高亮   │
│                                                  │  双击→填充   │
│  第2行 之卦: 风火家人 101011（或无之卦→自定义）  │  到自定义行  │
│  [本卦]→[一世]→[二世]→[三世]→...→[归魂]        │              │
│                                          [放大🔍] │              │
│  第3行 自定义1: [从图谱双击填充]                 │              │
│  [本卦]→[一世]→[二世]→...→[归魂]                │              │
│                                                  │              │
│  第4行 自定义2: [从图谱双击填充]                 │              │
│  [本卦]→[一世]→[二世]→...→[归魂]                │              │
└──────────────────────────────────────────────────┴──────────────┘
```

### 4 行数据来源

| 行号 | 内容来源 | 说明 |
|------|---------|------|
| 第1行 | 本卦（默认） | 通过卦例编号自动获取 ben_code，或自定义选择 |
| 第2行 | 之卦（默认） | 通过卦例编号自动获取 zhi_code；若无动爻（yao_bian_code 全 0）→ 变为自定义模式；若上爻动爻 → 整行显示"此卦上爻为动爻，不可用八宫变化" |
| 第3行 | 自定义输入 | 初始显示占位提示，双击右侧图谱节点自动填充卦代码 |
| 第4行 | 自定义输入 | 同上，优先填充第3行，第3行已有则填充第4行 |

## 4. 内部逻辑要点
- 卦例编号入口：输入 guali_id → 调 API 获取 ben_code + zhi_code + yao_bian_code
  - 第1行展示本卦的八宫变化
  - 第2行展示之卦的八宫变化（若 yao_bian_code 全 0 → 静卦，之卦=本卦，第2行变为自定义模式）
- 自定义入口：从 64 卦下拉选择 → 填充到当前编辑行
- 每行七步变化用箭头连接（从左到右、从上到下）
- 每个卦图形可点击→弹出 GuaCiFloat
- 如果上爻为动爻（yao_bian_code[5]=='1'）→ 该行之卦显示"此卦上爻为动爻，不可用八宫变化"
- 右侧网络图谱：力导向布局，节点=卦，边=八宫关系
  - 单击节点 → 相连节点高亮 + 关系文字
  - 双击节点 → 填充到自定义行
  - 放大按钮 → 跳转到独立 GraphPage（/jiegua/graph）

## 5. 测试要点
- 输入卦例编号→第1行正确显示本卦八宫变化，第2行正确显示之卦八宫变化
- 无动爻（静卦）→第2行变为自定义模式
- 上爻动爻→第2行显示禁用提示
- 自定义选择卦→正确显示在对应行
- 双击图谱节点→自定义行被填充
- 点击卦图形→GuaCiFloat 弹出
- 放大按钮→跳转到 GraphPage

### 用户测试 👤
浏览器中打开 C2 八宫变化页面，输入一个已有卦例编号→加载→检查本卦和之卦两行七步卦名是否正确。双击图谱节点填充自定义行。点击任一卦图形→卦爻辞浮窗出现。

## 6. 潜在陷阱与风险
- [上爻限制] 上爻为动爻时八宫变化不可用→前端需从 guali 表的 yao_bian_code 判读第 6 位。
- [网络图谱性能] 节点多时力导向计算可能卡→使用小尺寸 canvas，只显示当前宫的关系。
- [4行数据管理] 每行独立维护自己的卦代码和七变数据，行之间互不影响。需注意自定义行的填充优先级（先第3行后第4行）。
