- `engine = create_engine(DATABASE_URL, echo=False)` — echo 在开发阶段可设为 True 看 SQL 日志
- `get_session()` 用 `yield` 实现，配合 FastAPI 的 `Depends()` 注入到路由函数

- **注意**：`create_all()` 只创建不存在的表，不会修改已有表结构

## 7. 潜在陷阱与风险
- [连接池耗尽] 每次请求创建新连接而不复用 → 高并发时连接数不够。规避：SQLModel 的 `create_engine` 默认启用连接池（pool_size=5, max_overflow=10），对当前项目足够。
- [echo=True 生产泄露] 开发时开 SQL 日志调试 → 部署到生产时忘记关掉，日志文件爆炸。规避：echo 值从配置文件读取，生产环境配置设为 False。
- [create_all 不更新表结构] 后续修改了 model 字段 → 调用 `init_db()` 不会自动加列。规避：v0.0 后数据库变更使用 Alembic 迁移或手动 ALTER TABLE。v0.0 阶段可以删表重建（还没有数据）。
- [engine 单例线程安全] `create_engine` 返回的 engine 是线程安全的，但 session 不是 → `get_session()` 每次调用必须返回新 session。
