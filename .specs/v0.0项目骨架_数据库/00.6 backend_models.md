# 文件规划：backend/models/（15 个模型文件）

## 1. 基本信息
- **所属模块**：基础设施（models/）
- **优先级**：P0（必须）— 所有 CRUD 和 Service 层依赖模型定义
- **依赖文件**：无（模型定义只依赖 SQLModel 库，不依赖项目内其他模块）
- **被依赖文件**：`backend/crud/*`、`backend/services/*`、`backend/schemas/*`、`backend/db/connection.py`（通过 SQLModel.metadata）

## 2. 核心职责

## 4. 内部逻辑要点
- 每个文件定义一个类，继承 `SQLModel, table=True`
- `Optional` 字段用 `Optional[type] = None`，必填字段直接声明类型
- 主键：单主键用 `Field(primary_key=True)`，联合主键用 `Field(primary_key=True)` 在多个字段上
- 外键：`Field(foreign_key="table.column")`
- JSON 类型字段：用 `sqlmodel.JSON` 或 `Dict[str, Any]`
- BOOLEAN 类型：用 `bool`，MySQL 自动映射为 TINYINT(1)
- 字段注释：用 `sa_column_kwargs={"comment": "..."}` 或 `Field(description="...")`

## 5. 输入输出示例
以 guali 模型为例：
```python
from sqlmodel import SQLModel, Field
from typing import Optional
from datetime import datetime

class Guali(SQLModel, table=True):
    __tablename__ = "guali"
    id: Optional[int] = Field(default=None, primary_key=True)
    zhanwen_time: datetime
    zhanwen_shiyou: Optional[str] = Field(default=None)
    zhanduan: Optional[str] = Field(default=None)
    ben_code: str = Field(max_length=6)
    yao_bian_code: str = Field(default="000000", max_length=6)
    zhi_code: str = Field(default="000000", max_length=6)
```

## 7. 潜在陷阱与风险
- [字段名不一致] Python 用 snake_case，数据库用 snake_case → 本项目统一用 snake_case，无需映射。但如果某处不小心用了 camelCase → SQLModel 自动转换为 snake_case 列名，与建表 SQL 的列名不一致。
- [TEXT vs VARCHAR] SQLModel 中 `str` 默认映射为 VARCHAR(255) → 对 TEXT 字段（如 zhanwen_shiyou、zhanduan）需用 `Field(sa_type=TEXT)` 或 SQLModel 的 Text 类型。
- [JSON 字段] guaci.yao_ci 和 guaci.yong 是 JSON 类型 → SQLModel 需用 `Field(sa_type=JSON)` 或 `sqlmodel.JSON`。
- [联合主键] static_* 表用联合主键 → SQLModel 中在多个字段上设置 `primary_key=True`。注意不能再用单独的 `id` 字段。
- [DECIMAL 精度] stock_day_kline 的价格字段是 DECIMAL(10,2) → SQLModel 中需指定精度，如 `Field(sa_type=DECIMAL(10,2))`。
- [BOOLEAN 默认值] guali_yao 的 is_dong 默认 FALSE，zengshan_exists 默认 FALSE → 在 Field 中设置 `default=False`。
