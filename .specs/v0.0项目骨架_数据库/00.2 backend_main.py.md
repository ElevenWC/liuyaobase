# 文件规划：backend/main.py

## 1. 基本信息
- **所属模块**：基础设施
- **优先级**：P0（必须）— 应用入口
- **依赖文件**：`backend/config.py`、`backend/db/connection.py`、`backend/api/main.py`（路由注册）
- **被依赖文件**：无（这是入口，不被其他文件导入）

## 2. 核心职责
FastAPI 应用入口——创建 app 实例、注册中间件、挂载路由、配置生命周期事件。

## 3. 对外接口
```python
# FastAPI 应用实例
app: FastAPI

# 生命周期事件（自动触发，非手动调用）
# - startup: 初始化数据库连接
# - shutdown: 关闭数据库连接
```

## 4. 内部逻辑要点
- 创建 `FastAPI()` 实例，设置 title="liuyaobase"
- 配置 CORS 中间件（开发阶段允许所有来源，生产再收紧）
- 注册路由：`app.include_router(api_main.router, prefix="/api")`
- 添加 `@app.get("/")` 根路径返回 `{"message": "liuyaobase API"}`
- startup 事件：调用 `connection.init_db()` 确保数据库表存在
- shutdown 事件：关闭数据库连接池

## 5. 输入输出示例
- `GET /` → `{"message": "liuyaobase API"}`
- `GET /docs` → Swagger UI 自动生成（FastAPI 内置）

## 6. 如何启动
在终端（cmd）中执行：
```bash
cd liuyaobase
uvicorn backend.main:app --reload --port 8001
```
- `--reload`：代码修改后自动重启（开发用）
- `--port 8001`：指定端口（8000 已被占用）
- 启动成功后终端显示 `Uvicorn running on http://0.0.0.0:8001`
- 浏览器访问 `http://localhost:8001/docs` 可看到 Swagger API 文档

## 8. 潜在陷阱与风险
- [端口占用] 8000 端口已被用户其他服务占用 → 使用配置文件中的端口（如 8001），不硬编码。
- [CORS 配置] 前端开发时可能跨域 → v0.0 阶段 `allow_origins=["*"]`，后续收紧。
- [路由注册时机] 如果 `api/main.py` 引入的 router 子模块还没创建，会 import 失败 → 用注释预留路由注册代码，或先创建空 router 占位文件。
