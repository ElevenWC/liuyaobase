# 文件规划：frontend/ 项目骨架

## 1. 基本信息
- **所属模块**：基础设施（前端）
- **优先级**：P0（必须）— 所有前端页面和组件的运行基础
- **依赖文件**：无（前端项目独立于后端）
- **被依赖文件**：全部前端 views/ 和 components/

## 2. 核心职责
搭建 Vue 3 + Vite 前端项目骨架——项目配置、路由、全局样式、API 封装、入口文件。确保 `npm run dev` 能启动一个空白但结构完整的前端应用。

## 3. 文件清单与接口

| 文件 | 说明 |
|------|------|
| `frontend/package.json` | 项目依赖声明——vue3、vite、axios、echarts、pinia、vue-router |
| `frontend/vite.config.js` | Vite 构建配置——代理 API 到后端端口 |
| `frontend/index.html` | HTML 入口 |
| `frontend/src/main.js` | Vue 应用入口——创建 app、注册 router/stores、挂载 |
| `frontend/src/App.vue` | 根组件——`<router-view>` + 全局布局框架 |
| `frontend/src/style.css` | 全局样式 |
| `frontend/src/router/index.js` | Vue Router——定义路由表，初始只有 Home 和 NotFound |
| `frontend/src/api/index.js` | axios 实例 + 请求拦截器 + 通用错误处理 |
| `frontend/src/stores/index.js` | Pinia 入口——空 store 占位，后续按模块拆分 |
| `frontend/src/views/Home.vue` | 首页——显示项目名和模块导航入口（暂为占位链接） |
| `frontend/src/views/NotFound.vue` | 404 页面 |

## 4. 内部逻辑要点

### 4.1 package.json
- `vue: ^3.4`、`vue-router: ^4`、`pinia: ^2`、`axios: ^1`、`echarts: ^5`
- devDependencies: `vite: ^5`、`@vitejs/plugin-vue`

### 4.2 vite.config.js
- `server.port: 5173`（Vite 默认）
- `server.proxy: { '/api': 'http://localhost:8001' }` — 开发时 API 请求代理到后端，避免跨域

### 4.3 router/index.js
```javascript
const routes = [
  { path: '/', component: Home },
  { path: '/:pathMatch(.*)*', component: NotFound }
]
```
后续模块开发时逐步添加路由，无需在 v0.0 全部定义。

### 4.4 api/index.js
```javascript
const api = axios.create({ baseURL: '/api', timeout: 10000 })
// 响应拦截器：统一处理错误，弹出提示
```

### 4.5 App.vue
- `<NavBar>`（可暂时为空占位）
- `<router-view>`
- 预留全局浮窗层 `<div id="float-layer">`（GuaCiFloat 等浮窗的挂载点）

## 5. 输入输出示例
- `npm run dev` → Vite 启动，浏览器访问 `http://localhost:5173` → 看到首页，有导航占位，点击链接可跳转
- `http://localhost:5173/api/guali` → 被 vite proxy 转发到 `http://localhost:8001/api/guali`

## 6. 测试要点

### AI 自测
- `npm install` 和 `npm run dev` 无报错

### 用户测试 👤（复制命令到终端执行）

**1. 安装依赖**：
```bash
cd d:/Code/liuyao/liuyaobase/frontend

```
等待安装完成，最后显示类似 `added 150 packages in 30s` 没有红色报错。

**2. 启动前端开发服务器**：

看到 `VITE v5.x.x ready in xxx ms` 和 `➜ Local: http://localhost:5173/` 说明启动成功。

**3. 打开浏览器**，访问 `http://localhost:5173/`：
- 应该看到首页，有"liuyaobase"标题和导航占位

测试完成后在终端按 `Ctrl+C` 停止前端服务。

## 7. 潜在陷阱与风险
- [proxy 端口不匹配] vite.config.js 中 proxy 端口与后端 SERVER_PORT 不一致 → 代理失败，API 请求 404。规避：端口从环境变量或统一配置读取。
- [Vue 版本] 注意 vue 3.x 的 Composition API 写法（`<script setup>`），不要引入 Options API 写法。
- [ECharts 引入] ECharts v5 按需引入 vs 全量引入 → v0.0 可全量引入（`import * as echarts from 'echarts'`），后续优化按需引入减小包体积。
- [Vite vs Vue CLI] 本项目用 Vite（不是 Vue CLI），配置文件是 `vite.config.js` 而非 `vue.config.js`。
