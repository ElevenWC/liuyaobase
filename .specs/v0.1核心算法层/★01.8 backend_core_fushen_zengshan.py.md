# 文件规划：backend/core/fushen_zengshan.py 🔴

> 🔴 核心文件：增删伏神涉及飞伏对应关系、跨卦查找本宫卦、六亲完整性判断。逻辑链长，容易出错。

## 1. 基本信息
- **所属模块**：core/
- **优先级**：P0（必须）
- **依赖文件**：`backend/core/enums.py`、`backend/core/najia.py`（获取本宫卦纳甲）、`backend/core/liuqin.py`（计算伏神/飞神六亲）
- **被依赖文件**：`backend/db/init_db.py`（v0.1 回填 static_fushen_zengshan）、`backend/services/precalculate_service.py`

## 2. 核心职责
B4 增删伏神：判断本卦缺少哪种六亲 → 从本宫卦中借入缺失六亲的爻作为伏神 → 本卦同爻位的爻为飞神。

## 3. 对外接口

## 4. 内部逻辑要点

### 计算步骤
1. 获取本卦 6 爻的六亲列表（调用 najia + liuqin）
2. 统计六亲集合，找出缺失的六亲（5种中缺少1-2种）
3. 若缺 → 查本卦所属卦宫的**本宫卦**（八宫首卦）
4. 在本宫卦中找到缺失六亲对应的爻位 → 该爻为伏神
5. 本卦同一爻位的爻为飞神
6. 伏神六亲 = 本宫卦该爻的六亲；飞神六亲 = 本卦该爻的六亲

### 八宫本宫卦对照
| 卦宫 | 本宫卦 | 代码 |
|------|--------|------|
| 乾宫 | 乾为天 | 111111 |
| 坎宫 | 坎为水 | 010010 |
| 艮宫 | 艮为山 | 001001 |
| 震宫 | 震为雷 | 100100 |
| 巽宫 | 巽为风 | 011011 |
| 离宫 | 离为火 | 101101 |

## 7. 潜在陷阱与风险

- [飞神取错] 飞神是**本卦同一爻位的爻**，不是本宫卦的爻。如果把本宫卦的爻当飞神 → 飞伏关系全错。
- [本宫卦查找] 需要先确认本卦的卦宫（从 bagong_gua 表或预存数据获取），才能找到正确的本宫卦。如果卦宫判断错了 → 伏神来自错的本宫卦。
- [六亲齐全无需伏神] 如乾为天六亲完整 → 返回空列表，不要强行找伏神。
- [多缺失] 个别卦可能缺2种六亲（如缺妻财又缺子孙） → 需要分别借入，每个缺失对应一条伏神记录。
