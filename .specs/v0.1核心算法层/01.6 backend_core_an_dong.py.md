# 文件规划：backend/core/an_dong.py

## 1. 基本信息
- **所属模块**：core/
- **优先级**：P0（必须）
- **依赖文件**：`backend/core/enums.py`（六冲对照表）
- **被依赖文件**：`backend/services/precalculate_service.py`

## 2. 核心职责
B3.5 暗动判断：日支冲本卦静爻 → 该爻标记为暗动（与动爻互斥）。

## 3. 对外接口

```python
def check_an_dong(ben_dizhi: str, is_dong: bool, day_zhi: str) -> bool:
    """判断本卦爻是否暗动
    条件: is_dong=False 且 ben_dizhi 与 day_zhi 相冲
    """
```

## 4. 内部逻辑要点
- 六冲组合：子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲（6组，无顺序）
- 暗动条件：`not is_dong AND (ben_dizhi, day_zhi) 在六冲组合中`
- 暗动仅适用于本卦静爻——变爻和之卦无暗动概念

## 5. 输入输出示例
```python
check_an_dong("子", False, "午")  # → True（子午冲，且非动爻）
check_an_dong("子", True, "午")   # → False（已是动爻，不判暗动）
check_an_dong("子", False, "丑")  # → False（子丑合不冲）
```

## 6. 测试要点
- 6组相冲全部覆盖
- 动爻排除：is_dong=True 时始终返回 False
- 地支相同不算冲：`check_an_dong("子", False, "子")` → False

### 用户测试 👤
```bash
python -c "
from backend.core.an_dong import check_an_dong
print('子静爻 日支午:', check_an_dong('子', False, '午'))  # True
print('子动爻 日支午:', check_an_dong('子', True, '午'))   # False
"
```

## 7. 潜在陷阱与风险
- [动爻互斥] 暗动只适用于静爻。如果先判断暗动再判断动爻 → 可能一个爻同时被标记为动爻和暗动。代码中必须 `is_dong=False` 作为前置条件。
- [六冲方向无关] 子午冲 = 午子冲，查表时双向匹配。
