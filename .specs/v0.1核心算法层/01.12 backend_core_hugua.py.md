# 文件规划：backend/core/hugua.py

## 1. 基本信息
- **所属模块**：core/
- **优先级**：P1（重要）— C2 解卦模块实时调用
- **依赖文件**：`backend/core/enums.py`
- **被依赖文件**：`backend/api/routers/jiegua.py`（C2 互卦 API）

## 2. 核心职责
B7 互卦计算：从原卦中取出二三四爻为互卦内卦、三四五爻为互卦外卦，组合成新卦。

## 3. 对外接口

```python
def calc_hugua(code: str) -> str:
    """输入6位卦代码，返回互卦代码（6位）
    例: calc_hugua("110010") → "100001"（水泽节→互卦山雷颐）
    """
```

## 4. 内部逻辑要点
- 互卦内卦 = 原卦第2、3、4位（从0开始：索引1、2、3）
- 互卦外卦 = 原卦第3、4、5位（索引2、3、4）
- 组合 = 内卦3位 + 外卦3位 → 6位新代码
- 适用于本卦和之卦

## 5. 输入输出示例
```python
calc_hugua("110010")  # 水泽节
# 第2位=1, 第3位=0, 第4位=0 → 100(震)
# 第3位=0, 第4位=0, 第5位=1 → 001(艮)
# → "100001" = 山雷颐
```

## 7. 潜在陷阱与风险
- [取位错误] "取二三四爻" = 取代码第2、3、4位的值（从1开始编号）。代码索引从0开始，所以是 index 1,2,3。不要取错位。
- [组合顺序] 互卦代码 = 内卦 + 外卦 = 前3位 + 后3位。不要搞反。
- [直接用代码查表] 得到互卦代码后直接用 bagong_gua 查表获取卦名，不要手推"X上Y下"。
