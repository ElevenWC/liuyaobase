# 文件规划：backend/core/gua_type.py 🟡

> 🟡 重要：六冲/六合判断采用查表法，但反吟伏吟涉及本卦与之内外卦比较，逻辑较复杂。

## 1. 基本信息
- **所属模块**：core/
- **优先级**：P0（必须）
- **依赖文件**：`backend/core/enums.py`
- **被依赖文件**：`backend/services/precalculate_service.py`（存 guali_gua 表）

## 2. 核心职责
B6 特殊卦判断：判断本卦/之卦是否六冲/六合卦，以及本卦与之卦之间是否存在反吟/伏吟关系。

## 3. 对外接口

```python
def check_liu_chong(code: str) -> bool:
    """查表判断是否六冲卦（10个）"""

def check_liu_he(code: str) -> bool:
    """查表判断是否六合卦（8个）"""

def get_special_type(code: str) -> str:
    """返回卦的特殊类型："六冲"/"六合"/"普通" """

def check_fan_yin_yimao(ben_code: str, zhi_code: str) -> str:
    """易冒反吟判断 → "无"/"内卦"/"外卦" """

def check_fan_yin_yaobian(ben_code: str, zhi_code: str) -> str:
    """爻变反吟判断 → "无"/"内卦"/"外卦" """

def check_fu_yin(ben_code: str, zhi_code: str) -> str:
    """伏吟判断 → "无"/"内卦"/"外卦" """
```

## 4. 内部逻辑要点

### 六冲卦（10个，查表）
乾为天、震为雷、坎为水、艮为山、坤为地、巽为风、离为火、兑为泽、雷天大壮、天雷无妄

### 六合卦（8个，查表）
天地否、水雷屯、火山旅、泽火革、地天泰、雷水解、山火贲、风泽中孚

### 易冒反吟：乾巽互变、坎离互变、艮坤互变、震兑互变
### 爻变反吟：坤巽互变
### 伏吟：乾震互变

判断方法：比较本卦和之内卦/外卦代码（各3位），看是否符合互变规则。

## 5. 输入输出示例
```python
check_liu_chong("111111")  # 乾为天 → True
check_liu_he("000111")     # 天地否 → True
check_fan_yin_yimao("111101", "111010")  # 外卦离→坎，坎离互变 → "外卦"
```

## 6. 测试要点
- 六冲10个 + 六合8个 全部验证
- 反吟伏吟各规则至少2个用例

### 用户测试 👤
```bash
python -c "
from backend.core.gua_type import check_liu_chong, check_liu_he
print('乾为天 六冲:', check_liu_chong('111111'))  # True
print('天地否 六合:', check_liu_he('000111'))     # True
print('天火同人 六冲:', check_liu_chong('101111')) # False
"
```

## 7. 潜在陷阱与风险
- [反吟判断看内/外卦] 比较的是本卦 vs 之卦的内卦或外卦，不是整个卦代码。
- [六冲六合查漏] 10+8 共18个卦代码需要全部列出，漏一个 → 该卦被误判为"普通"。
