## 4. 内部逻辑要点

### 4.1 纳甲地支表（固定规则）
| 单卦 | 内卦（初二三爻） | 外卦（四五上爻） |
|------|-----------------|-----------------|
| 乾(111) | 子、寅、辰 | 午、申、戌 |
| 坎(010) | 寅、辰、午 | 申、戌、子 |
| 艮(001) | 辰、午、申 | 戌、子、寅 |
| 震(100) | 子、寅、辰 | 午、申、戌 |
| 巽(011) | 丑、亥、酉 | 未、巳、卯 |
| 离(101) | 卯、丑、亥 | 酉、未、巳 |
| 坤(000) | 未、巳、卯 | 丑、亥、酉 |
| 兑(110) | 巳、卯、丑 | 亥、酉、未 |

### 4.2 纳天干规则
- **6 个普通单卦**：震(庚)、巽(辛)、坎(戊)、离(己)、艮(丙)、兑(丁) — 天干固定
- **乾坤特殊**：内卦乾→甲/壬（分季节），外卦乾→壬/甲（分季节），内卦坤→乙/癸，外卦坤→癸/乙
- 夏至→冬至：内乾甲、外乾壬、内坤乙、外坤癸
- 冬至→夏至：内乾壬、外乾甲、内坤癸、外坤乙

### 4.3 计算步骤
1. 解析 code → 前3位内卦、后3位外卦
2. 内卦三爻查"内卦"列，外卦三爻查"外卦"列 → 得 6 个地支
3. 判断每个爻的天干：普通卦直接用固定天干，乾坤相关卦根据季节选 summer/winter
4. 组装返回：36普通卦→tiangan 有值；28乾坤相关卦→tiangan 为 None，tiangan_summer/winter 各有值

## 7. 潜在陷阱与风险

- [内外卦查错列] 内卦必须查"内卦"列，外卦查"外卦"列。乾和震的纳甲相同（容易混淆），但天干不同（震=庚，乾=分季节）。
- [乾坤天干季节反了] 夏至→冬至 和 冬至→夏至 的天干分配不同。如果代码写反了 → 384条数据中最多28×6=168个天干值错误。需要精确判断当前日期所在的节气区间。
- [代码位序] code[0]=初爻，code[5]=上爻。取内卦是 code[:3]，外卦是 code[3:]。不要搞反——初爻在左（第0位），上爻在右（第5位）。
- [单卦代码映射] 3位代码有8种（000~111缺010），映射到单卦名查 enums.GUA_CODE 的反向映射。
