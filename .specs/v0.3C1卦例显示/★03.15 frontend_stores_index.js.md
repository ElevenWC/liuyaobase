# 文件规划：frontend/src/stores/index.js 🟡

## 1. 基本信息
- **所属模块**：frontend/stores/
- **优先级**：P0
- **依赖文件**：`pinia`
- **被依赖文件**：`GualiList.vue`、`GualiDetail.vue`、后续 C3 Search.vue

## 2. 核心职责
Pinia 全局状态管理——当前选中卦例 ID（C1 左右联动）、标签树缓存、通用 UI 状态。

## 3. 对外接口

```javascript
// useAppStore — 全局应用状态
export const useAppStore = defineStore('app', () => {
  const currentGualiId = ref(null)       // 当前选中的卦例 ID
  const tagTree = ref([])                // 标签树缓存
  const tagTreeLoaded = ref(false)       // 标签树是否已加载
  const sidebarCollapsed = ref(false)    // 侧栏是否折叠
  
  function selectGuali(id) { currentGualiId.value = id }
  async function loadTagTree() { ... }
  
  return { currentGualiId, tagTree, selectGuali, loadTagTree, ... }
})
```

## 4. 内部逻辑要点
- `currentGualiId`：GualiList 点击卡片→set ID→GualiDetail watch ID→加载详情
- `tagTree`：首次加载后缓存，减少重复 API 请求
- 标签树在 GualiDetail 标签编辑时需要→与 GualiList 共享同一份数据

## 5. 测试要点
- GualiList 点击卡片→store.currentGualiId 变化→GualiDetail 自动加载新详情
- 标签树首次加载后缓存→再次打开标签选择器不再请求

## 6. 潜在陷阱与风险
- [缓存过期] 用户新增标签后 tagTree 未刷新→新标签不可见。新增标签后手动 `tagTreeLoaded = false` 或直接更新 `tagTree`。
- [多 Tab 状态] 用户浏览器多 Tab 打开→store 状态不共享（Pinia 默认内存存储）。对当前项目 OK，不需要跨 Tab 同步。
