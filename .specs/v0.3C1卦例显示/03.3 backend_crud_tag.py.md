# 文件规划：backend/crud/tag.py

## 1. 基本信息
- **所属模块**：crud/
- **优先级**：P1
- **依赖文件**：`backend/models/tag.py`
- **被依赖文件**：`backend/services/tag_service.py`

## 2. 核心职责
标签表和卦例-标签关联表的 CRUD。

## 3. 对外接口
```python
def get_all(session) -> list[Tag]: ...
def get_by_id(session, tag_id: int) -> Tag | None: ...
def create(session, name: str, parent_id: int = None) -> Tag: ...
def update(session, tag_id: int, name: str) -> Tag: ...
def delete(session, tag_id: int): ...
# 关联表操作
def add_guali_tag(session, guali_id: int, tag_id: int): ...
def remove_guali_tag(session, guali_id: int, tag_id: int): ...
def get_tags_by_guali(session, guali_id: int) -> list[Tag]: ...
def get_guali_ids_by_tag(session, tag_id: int) -> list[int]: ...
```

## 4. 内部逻辑要点
- 关联表 `guali_tag` 联合主键 (guali_id, tag_id)
- add/remove 直接操作关联表
- 删除标签时 MySQL 外键 CASCADE 自动清理关联

## 5. 测试要点
- 同一卦例打多个标签不冲突
- 删除标签后 guali_tag 关联自动清除

## 6. 潜在陷阱与风险
- [重复关联] INSERT 相同的 (guali_id, tag_id) 组合 → MySQL 主键冲突。用 INSERT IGNORE 或先检查是否存在。
