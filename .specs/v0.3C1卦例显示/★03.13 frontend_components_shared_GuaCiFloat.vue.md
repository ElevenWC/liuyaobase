# 文件规划：frontend/src/components/shared/GuaCiFloat.vue 🔵

> 🔵 共享组件：C1/C2/C3/C4 四个模块共用。修改此组件影响全部模块。

## 1. 基本信息
- **所属模块**：frontend/components/shared/
- **优先级**：P1
- **依赖文件**：`frontend/src/api/index.js`
- **被依赖文件**：`GualiDetail.vue`(C1)、C2 八宫变化页、C3 搜索结果、`GualiFloatPanel.vue`(C4)

## 2. 核心职责
卦爻辞浮窗——点击卦名触发，可拖动、可多开、显示卦辞/彖传/象传/爻辞/文言/用九用六。

## 3. 对外接口
```vue
<!-- Props -->
gua_code: String   # 6位卦代码，必传
gua_name: String   # 卦名（显示用）

<!-- 行为 -->
可拖动（mousedown + mousemove）
可多开（每个浮窗独立实例）
可关闭（× 按钮）
```

## 4. 内部逻辑要点
- `watch(gua_code)` → 调 API `GET /api/jiegua/guaci/{gua_code}` 获取卦爻辞
- 显示内容：卦辞、彖传、象传、6条爻辞、文言（仅乾坤）、用九/用六（仅乾坤）
- 文言用 `|` 分隔→前端 `split('|')` → 逐段换行显示
- 浮窗定位：初始居中，可拖拽到任意位置
- `z-index` 管理：新打开的浮窗在最上层

## 5. 关键 UI 交互
- 点击卦名→创建新浮窗实例（每个实例独立的 position）
- 鼠标按住标题栏拖动→浮窗跟随
- × 关闭→浮窗销毁

## 6. 测试要点
- 点击乾卦名→弹出浮窗→显示卦辞/彖传/象传/文言/用九
- 点击普通卦名→显示卦辞/彖传/象传/爻辞，无文言/用九
- 同时打开 3 个浮窗→可独立拖动、独立关闭

### 用户测试 👤
在卦例详情页，分别点击本卦名和之卦名→两个浮窗独立弹出→拖动其中一个→两个互不影响→关闭再打开→内容完整。

## 7. 潜在陷阱与风险
- [多个浮窗实例] 同一卦名被点击两次→是再开一个新浮窗还是聚焦已有？按设计：可多开，每次新浮窗。
- [浮窗层级] 多个浮窗打开→点下面的浮窗标题→该浮窗应升到最上层。维护全局 z-index 计数器。
- [拖拽越界] 浮窗拖到屏幕外→用户无法拖回。限制浮窗 `top` 和 `left` 不超出视口。
- [内存泄漏] 浮窗关闭→事件监听器未移除。`onUnmounted` 中 `removeEventListener`。
