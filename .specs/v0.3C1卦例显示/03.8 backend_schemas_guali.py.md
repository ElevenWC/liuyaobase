# 文件规划：backend/schemas/guali.py

## 1. 基本信息
- **所属模块**：schemas/
- **优先级**：P0
- **依赖文件**：`backend/models/guali.py`（类型参考）、`pydantic`
- **被依赖文件**：`backend/api/routers/guali.py`

## 2. 核心职责
卦例相关的请求/响应 Pydantic 模型——入参校验 + 出参格式化。

## 3. 对外接口
```python
class GualiListResponse(SQLModel):        # 列表项
class GualiDetailResponse(SQLModel):      # 详情（含 time/yao_list/shensha/gua/tags）
class GualiUpdateRequest(SQLModel):       # 更新（zhanwen_shiyou?, zhanduan?）
class GualiBatchDeleteRequest(SQLModel):  # 批量删除（ids: list[int]）
class GualiTagRequest(SQLModel):          # 标签关联（tag_id: int）
```

## 4. 内部逻辑要点
- 响应模型把数据库模型字段转为前端友好的字段名（保持 snake_case）
- 列表响应精简（不含大文本），详情响应完整
- yao_list 为 list[YaoItemSchema] 嵌套结构

## 5. 输入输出示例
```python
class GualiUpdateRequest(SQLModel):
    zhanwen_shiyou: Optional[str] = None
    zhanduan: Optional[str] = None
```

## 6. 测试要点
- 字段校验：缺少必填字段返回 422
- 多余字段自动忽略（不报错）

## 7. 潜在陷阱与风险
- [前后端字段名] 后端 snake_case，前端如果用 camelCase → 需在 api/index.js 中做转换。或者统一用 snake_case（推荐）。
