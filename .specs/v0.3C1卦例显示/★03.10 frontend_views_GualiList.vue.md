# 文件规划：frontend/src/views/GualiList.vue 🟡

> 🟡 左侧卦例列表——用户最常操作的入口，分页/搜索/标签筛选都要流畅。

## 1. 基本信息
- **所属模块**：frontend/views/
- **优先级**：P0
- **依赖文件**：`frontend/src/api/index.js`、`frontend/src/stores/index.js`
- **被依赖文件**：`frontend/src/router/index.js`

## 2. 核心职责
左侧卦例列表——卡片展示、搜索框、标签筛选、分页。点击卡片→右侧显示详情。

## 3. 对外接口
无函数接口。通过 Pinia store 共享选中状态，通过 `$emit` 或 store 通知父组件切换详情。

## 4. 内部逻辑要点

### 数据流
1. `onMounted` → 调 API `GET /api/guali?page=1`
2. 搜索框输入 → 防抖 300ms → 调 API `GET /api/guali?keyword=xxx`
3. 标签筛选 → 调 API `GET /api/guali?tag_id=N`
4. 分页 → `GET /api/guali?page=N`
5. 点击卡片 → store 设置 `currentGualiId`

### 卡片显示内容
- 占问时间（日期格式）
- 占问事由（截断 50 字）
- 标签（最多 3 个，不同颜色）

## 5. 关键 UI 交互
- 搜索框实时搜索（debounce 300ms）
- 点击标签→筛选同类标签卦例
- 加载状态：骨架屏或 loading spinner
- 空状态：显示"暂无卦例"

## 6. 测试要点
- 分页切换正常
- 搜索"橡胶"→只显示含"橡胶"的卦例
- 标签筛选：点击标签→列表过滤

### 用户测试 👤
```bash
cd frontend && npm run dev
```
浏览器访问 `http://localhost:5173`，确保后端已启动。在列表页测试搜索、分页、标签筛选。

## 7. 潜在陷阱与风险
- [debounce 泄漏] 组件卸载时 debounce timer 未清除 → 内存泄漏。`onUnmounted` 中 clearTimeout。
- [缓存失效] 删除卦例后列表未刷新 → 删除操作后调用 `refetch()`。
