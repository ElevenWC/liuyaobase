# 文件规划：frontend/src/views/GualiInput.vue

## 1. 基本信息
- **所属模块**：frontend/views/
- **优先级**：P1
- **依赖文件**：`frontend/src/api/index.js`
- **被依赖文件**：`frontend/src/router/index.js`

## 2. 核心职责
手动导入卦例表单——用户输入占问时间/事由/占断/本卦名/之卦名→后端转换为代码→存入数据库。

## 3. 表单字段
| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| 占问时间 | 日期选择器 | ✅ | 公历日期 |
| 占问事由 | 文本输入 | ✅ | |
| 占断 | 多行文本 | ❌ | |
| 本卦名 | 下拉选择 | ✅ | 64 卦名列表（从 bagong_gua 表获取） |
| 之卦名 | 下拉选择 | ❌ | 空=无之卦（爻变代码全0） |

## 4. 内部逻辑要点
- 卦名下拉从 `GET /api/tags` 或专用的卦名列表接口获取 64 卦名
- 之卦名为空→yao_bian_code="000000"，zhi_code=ben_code
- 提交→`POST /api/import/manual` → 成功→跳转卦例列表

## 5. 测试要点
- 选择本卦"天火同人"+之卦"风火家人"→提交成功
- 不选之卦→提交→之卦代码=本卦代码（静卦）

## 6. 潜在陷阱与风险
- [卦名→代码映射] 需要 64 卦的中文名到代码的映射表。前端可以调一次 API 全量加载缓存。
