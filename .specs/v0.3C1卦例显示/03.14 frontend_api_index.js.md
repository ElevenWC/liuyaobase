# 文件规划：frontend/src/api/index.js 🟣

> 🟣 基础设施：所有前端页面的 API 调用封装。

## 1. 基本信息
- **所属模块**：frontend/api/
- **优先级**：P0
- **依赖文件**：`axios`
- **被依赖文件**：全部前端 views/ 和 components/

## 2. 核心职责
创建 axios 实例 + 请求/响应拦截器 + 统一错误处理。封装各模块的 API 函数。

## 3. 对外接口

```javascript
// axios 实例
const api = axios.create({ baseURL: '/api', timeout: 10000 })

// 请求拦截器：添加公共 header
// 响应拦截器：统一错误提示

// API 函数
export function fetchGualiList(params)          // GET /api/guali
export function fetchGualiDetail(id)            // GET /api/guali/{id}
export function updateGuali(id, data)           // PUT /api/guali/{id}
export function deleteGuali(id)                 // DELETE /api/guali/{id}
export function deleteGualiBatch(ids)           // DELETE /api/guali/batch
export function addGualiTag(gualiId, tagId)     // POST /api/guali/{id}/tags
export function removeGualiTag(gualiId, tagId)  // DELETE /api/guali/{id}/tags/{tagId}

export function fetchTagTree()                  // GET /api/tags
export function createTag(data)                 // POST /api/tags
export function deleteTag(id)                   // DELETE /api/tags/{id}

export function importJson(file)                // POST /api/import/json
export function importManual(data)              // POST /api/import/manual
export function fetchImportStatus()             // GET /api/import/status
```

## 4. 内部逻辑要点
- `baseURL: '/api'` → Vite proxy 转发到后端
- 响应拦截器：`response.data.code !== 200` → 弹出错误提示
- 每个函数返回 Promise，调用方用 `await` 或 `.then()`

## 5. 测试要点
- `fetchGualiList({page:1})` 成功返回数据
- 后端未启动→响应拦截器捕获错误→console 输出而非页面崩溃

## 6. 潜在陷阱与风险
- [接口路径变更] 后端改了路由路径→前端 API 调用 404。前后端路径在一处统一管理，避免散落各组件。
