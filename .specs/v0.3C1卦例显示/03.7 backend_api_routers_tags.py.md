# 文件规划：backend/api/routers/tags.py

## 1. 基本信息
- **所属模块**：api/routers/
- **优先级**：P1
- **依赖文件**：`backend/services/tag_service.py`
- **被依赖文件**：`backend/api/main.py`

## 2. 核心职责
标签 API 路由——树形列表/增删改/按标签查卦例。

## 3. 对外接口
```python
router = APIRouter(prefix="/api/tags", tags=["标签"])
@router.get("")              # 标签树
@router.post("")             # 创建
@router.put("/{tag_id}")     # 重命名
@router.delete("/{tag_id}")  # 删除
@router.get("/{tag_id}/guali") # 该标签下的卦例列表
```

## 4. 内部逻辑要点
- tag_id 路径参数校验：是否存在
- 删除标签前检查是否有子标签

## 5. 测试要点
- POST 创建二级标签 → GET 树形列表中出现在正确的一级下
- DELETE 已关联卦例的标签 → 不影响卦例本身

## 6. 潜在陷阱与风险
- [占验标签] 用户通过此路由修改占验标签时，前端需确保互斥逻辑（先删旧再加新）。路由层不限制，由 service 层和前端共同保证。
