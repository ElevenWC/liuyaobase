# 文件规划：backend/services/guali_service.py 🟡

> 🟡 重要：C1 卦例详情查询需拼装 5 张表数据，拼装逻辑漏一个 JOIN → 前端显示缺字段。

## 1. 基本信息
- **所属模块**：services/
- **优先级**：P0（必须）
- **依赖文件**：`backend/crud/guali.py`、`backend/crud/guali_time.py`、`backend/crud/guali_yao.py`、`backend/crud/guali_shensha.py`、`backend/crud/guali_gua.py`、`backend/crud/tag.py`
- **被依赖文件**：`backend/api/routers/guali.py`

## 2. 核心职责
卦例列表查询（分页+搜索+标签筛选）和卦例详情拼装（5 表 JOIN → 统一响应结构）。

## 4. 内部逻辑要点

### 详情拼装数据来源
| 数据 | 来源表 | 字段 |
|------|--------|------|
| 基本信息 | guali | zhanwen_time, zhanwen_shiyou, zhanduan, ben_code, zhi_code |
| 时间干支 | guali_time | 年柱/月柱/日柱/旬空 |
| 6爻详情 | guali_yao | 六神/六亲/地支/天干/世应/动暗/伏神（20字段×6行） |
| 神煞 | guali_shensha | 4神煞地支值 + 是/带爻位 |
| 卦类 | guali_gua | 卦宫/宫位/特殊类型/反吟伏吟 |
| 标签 | tag + guali_tag | 该卦例关联的标签列表 |

### 列表查询
- 默认按 zhanwen_time DESC 排序
- keyword 搜索 zhanwen_shiyou（LIKE）
- tag_id 筛选需 JOIN guali_tag 表
- 返回精简版（只含列表卡片需要的字段：id, zhanwen_time, zhanwen_shiyou 前50字, ben_code, 标签）

## 7. 潜在陷阱与风险
- [N+1 查询] 每个卦例的标签单独查一次 → 列表 20 条 = 21 次查询。规避：标签批量查询，一次 SQL 获取全部 20 个卦例的标签，再在 Python 层分配。
- [缺表] 如果卦例的 guali_time 等扩展表记录不存在（预计算失败或未完成）→ 返回空对象而非 500。每个子查询容错处理。
- [大字段] zhanduan 可能是几千字长文本 → 列表接口不返回此字段，只在详情接口返回。
