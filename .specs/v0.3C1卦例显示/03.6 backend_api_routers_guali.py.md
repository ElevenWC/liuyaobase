# 文件规划：backend/api/routers/guali.py

## 1. 基本信息
- **所属模块**：api/routers/
- **优先级**：P0
- **依赖文件**：`backend/services/guali_service.py`、`backend/schemas/guali.py`
- **被依赖文件**：`backend/api/main.py`

## 2. 核心职责
C1 卦例 API 路由——列表/详情/增删改/标签关联。

## 3. 对外接口

```python
router = APIRouter(prefix="/api/guali", tags=["卦例"])

@router.get("")              # 列表（分页+搜索+标签筛选）
@router.get("/{guali_id}")   # 详情（5表拼装）
@router.put("/{guali_id}")   # 更新（仅 zhanwen_shiyou/zhanduan）
@router.delete("/{guali_id}") # 删除单个
@router.delete("/batch")     # 批量删除
@router.post("/{guali_id}/tags")       # 关联标签
@router.delete("/{guali_id}/tags/{tag_id}") # 解除标签关联
```

## 4. 内部逻辑要点
- 路由层只做参数校验和响应格式化，业务逻辑全在 guali_service
- 统一响应：`{"code": 200, "data": ..., "message": "success"}`
- 列表接口响应精简，详情接口响应完整

## 5. 测试要点
- `GET /api/guali?page=1&keyword=橡胶` → 返回分页列表
- `GET /api/guali/1` → 返回完整详情含 time/yao_list 等

### 用户测试 👤
浏览器访问 `http://localhost:8001/docs`，在 Swagger 页面直接测试各端点。

## 6. 潜在陷阱与风险
- [批量删除入参] DELETE 请求的 body 在某些代理/防火墙下可能被丢弃 → 考虑用 POST /batch-delete 传 body，或 URL 参数传逗号分隔的 ID 串。
