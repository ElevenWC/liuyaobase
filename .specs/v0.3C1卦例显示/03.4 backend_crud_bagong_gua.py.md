# 文件规划：backend/crud/bagong_gua.py

## 1. 基本信息
- **所属模块**：crud/
- **优先级**：P0
- **依赖文件**：`backend/models/bagong_gua.py`
- **被依赖文件**：`backend/services/guali_service.py`、`backend/services/precalculate_service.py`、`backend/services/import_service.py`

## 2. 核心职责
八宫卦序表只读查询——卦代码↔卦名↔卦宫↔五行↔宫位类型。

## 3. 对外接口
```python
def get_by_code(session, code: str) -> BagongGua | None: ...
def get_by_name(session, name: str) -> BagongGua | None: ...
def get_all(session) -> list[BagongGua]: ...
def get_by_palace(session, palace: str) -> list[BagongGua]: ...
```

## 4. 内部逻辑要点
- 纯只读，无增删改
- 64 条数据在 v0.0 已从 zhouyiData.json 填充
- 常用作字典缓存：`{code: BagongGua}` 全量加载到内存（仅 64 行）

## 5. 测试要点
- `get_by_code("101111")` → 天火同人/离宫/火/归魂卦
- `get_by_name("天火同人")` → code="101111"

## 6. 潜在陷阱与风险
- [缓存过期] 如果后续新增卦种（不太可能），全量缓存不会自动更新 → 系统重启后重新加载即可。
