# 文件规划：backend/crud/guali_gua.py

## 1. 基本信息
- **所属模块**：crud/
- **优先级**：P0（必须）
- **依赖文件**：`backend/models/guali_gua.py`
- **被依赖文件**：`backend/services/precalculate_service.py`、`backend/services/guali_service.py`、`backend/services/search_service.py`

## 2. 核心职责
卦类扩展表 CRUD——每卦例 1 行 14 字段（本卦/之卦的卦宫、宫位、特殊类型、反吟伏吟）。

## 3. 对外接口

```python
def create(session: Session, guali_id: int, data: dict) -> GualiGua:

def get_by_guali_id(session: Session, guali_id: int) -> GualiGua | None:
    """按卦例 ID 查询"""
```

## 4. 内部逻辑要点
- data 来自 gua_type.py 的判断结果 + bagong_gua 表查询
- 14 字段：1个guali_id + 本卦5字段 + 之卦5字段 + 反吟伏吟3字段
- 反吟伏吟值："无"/"内卦"/"外卦"（VARCHAR(4)）
- 不设更新方法

## 5. 输入输出示例

create(session, 1, {

    "zhi_inner_code": "101", "zhi_outer_code": "011",

## 6. 测试要点
- 创建后可正常读取全部 14 字段
- 反吟伏吟字段值在 {"无", "内卦", "外卦"} 范围内

## 7. 潜在陷阱与风险
- [反吟伏吟互斥？] 同一卦例可以同时有多种反吟（如既是易冒反吟又是爻变反吟）→ 三个字段独立判断，不互斥。
- [ben_special_type 三种值] "六合"/"六冲"/"普通"——不会为 NULL。
