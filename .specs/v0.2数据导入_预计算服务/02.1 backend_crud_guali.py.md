# 文件规划：backend/crud/guali.py

## 1. 基本信息
- **所属模块**：crud/
- **优先级**：P0（必须）— 卦例主表是所有模块的数据入口
- **依赖文件**：`backend/models/guali.py`（模型定义）、`backend/db/connection.py`（get_session）
- **被依赖文件**：`backend/services/guali_service.py`、`backend/services/import_service.py`、`backend/services/search_service.py`

## 2. 核心职责
卦例主表的基础 CRUD——增删改查 + 列表分页 + 按条件筛选。

## 3. 对外接口

```python
def create(session: Session, data: dict) -> Guali:
    """新增一条卦例，返回 Guali 实例"""

def get_by_id(session: Session, guali_id: int) -> Guali | None:
    """按 ID 查询"""

def list_guali(session: Session, page: int, page_size: int,
               keyword: str = "", tag_id: int = None) -> tuple[list[Guali], int]:
    """分页列表：按占问时间倒序；keyword 搜索占问事由；tag_id 按标签筛选"""

def update(session: Session, guali_id: int, data: dict) -> Guali:
    """更新卦例（仅 zhanwen_shiyou 和 zhanduan 可修改）"""

def delete(session: Session, guali_id: int) -> bool:
    """删除单个卦例（级联删除 guali_* 扩展表由外键 CASCADE 处理）"""

def delete_batch(session: Session, ids: list[int]) -> int:
    """批量删除，返回删除数量"""

def get_by_code(session: Session, ben_code: str) -> list[Guali]:
    """按本卦代码查询"""
```

## 4. 内部逻辑要点
- 所有操作使用 SQLModel Session
- 列表查询按 `zhanwen_time DESC` 排序
- keyword 搜索用 `LIKE '%keyword%'` 匹配 `zhanwen_shiyou`
- 标签筛选需 JOIN `guali_tag` 表：`WHERE guali_tag.tag_id = ?`
- 更新操作只允许修改可编辑字段（zhanwen_shiyou、zhanduan），不可修改时间/代码
- 删除单条时外键 CASCADE 自动清理 guali_* 扩展表和 guali_tag

## 5. 输入输出示例
```python
# 创建
guali = create(session, {
    "zhanwen_time": datetime(2026, 3, 25),
    "zhanwen_shiyou": "橡胶走势",
    "zhanduan": "下跌",
    "ben_code": "101111",
    "yao_bian_code": "000100",
    "zhi_code": "101011"
})

# 列表查询
results, total = list_guali(session, page=1, page_size=20, keyword="橡胶")
```

## 6. 测试要点
- 创建→查ID→字段一致
- 更新仅改 zhanwen_shiyou，其他字段不变
- 删除后级联删除关联的 guali_yao 等扩展表记录
- 批量删除返回正确数量

### 用户测试 👤
启动后端后：

```bash
curl http://localhost:8001/api/guali?page=1
```
应返回卦例列表（空列表或已有数据）。

## 7. 潜在陷阱与风险
- [更新字段范围] 只允许修改 zhanwen_shiyou 和 zhanduan。如果传入 ben_code 等字段 → 忽略或报错，不要静默修改。
- [级联删除] 依赖 MySQL 外键 CASCADE。需确认建表时外键声明了 ON DELETE CASCADE。
- [zhi_code 冗余] zhi_code = ben_code XOR yao_bian_code，存表是冗余但提升查询性能。创建时务必三者一致。
