# 文件规划：backend/crud/guali_shensha.py

## 1. 基本信息
- **所属模块**：crud/
- **优先级**：P0（必须）
- **依赖文件**：`backend/models/guali_shensha.py`
- **被依赖文件**：`backend/services/precalculate_service.py`、`backend/services/guali_service.py`

## 2. 核心职责
神煞扩展表 CRUD——每卦例 1 行 37 字段（4 神煞地支 + 32 组是/带爻位）。导入时写入，查询时只读。

```python
    """新增神煞记录"""

def get_by_guali_id(session: Session, guali_id: int) -> GualiShensha | None:
    """按卦例 ID 查询"""
```

## 4. 内部逻辑要点
- data 来自 shensha.calc_shensha_status() 的返回
- 37 字段：1 个 guali_id + 4 个神煞地支 + 32 组状态（4神煞×4来源×2状态）
- "是/带"爻位用逗号分隔字符串存储（如 "1,3,5"），空值用 ""
- 不设更新方法——神煞数据导入后不可修改

## 5. 输入输出示例
```python
create(session, 1, {
    "gan_lu": "寅", "yi_ma": "申", "yang_ren": "卯", "tao_hua": "子",
    "yimao_is_ganlu": "3", "yimao_dai_ganlu": "1,5",
    "ben_is_ganlu": "", "ben_dai_ganlu": "1,4",
    # ... 共 37 键
})
```

## 6. 测试要点
- 创建后全部 37 字段可正常读取
- 空值字段返回 "" 而非 NULL

## 7. 潜在陷阱与风险
- [空值 vs NULL] 32 组状态字段空值用 "" 而非 NULL——C3 的 FIND_IN_SET 对 NULL 返回 NULL（不是 0），会导致 WHERE 条件失效。
- [字段数量] 37 个字段容易漏填。precalculate_service 传入 data 字典时，AI 自审确认 key 的数量 = 37。
