# 文件规划：backend/api/routers/import_data.py

## 1. 基本信息
- **所属模块**：api/routers/
- **优先级**：P0（必须）
- **依赖文件**：`backend/services/import_service.py`
- **被依赖文件**：`backend/api/main.py`（路由注册）

## 2. 核心职责
导入模块 API 路由——接收前端请求，调用 import_service，返回导入结果。Router 层只做参数校验和响应格式化。

## 3. 对外接口

```python
router = APIRouter(prefix="/api/import", tags=["导入"])

@router.post("/json")
async def import_json(file: UploadFile, session=Depends(get_session)):
    """上传 JSON 文件批量导入 → {"code": 200, "data": {"imported": N, "skipped": N}}"""

@router.post("/manual")
async def import_manual(data: ManualImportSchema, session=Depends(get_session)):
    """手动导入单个卦例"""

@router.get("/status")
async def import_status(session=Depends(get_session)):
    """获取上次导入时间 → {"code": 200, "data": {"last_import_time": "..."}}"""
```

## 4. 内部逻辑要点
- `/json`：接收 `UploadFile`，保存到临时目录 → 调 `import_service.import_from_json()` → 删除临时文件
- `/manual`：接收 ManualImportSchema {zhanwen_time, zhanwen_shiyou, zhanduan, ben_code?, ben_name?, zhi_name?} → 如果前端传卦名而非代码 → 查 bagong_gua 表转换
- `/status`：从 system_config 查 last_import_time → 返回
- 统一响应格式：`{"code": 200, "data": {...}, "message": "success"}`

## 5. 输入输出示例

```json
// POST /api/import/manual
{
    "zhanwen_time": "2026-03-25",
    "zhanwen_shiyou": "橡胶走势",
    "zhanduan": "看涨",
    "ben_name": "天火同人",
    "zhi_name": "风火家人"
}
// 响应: {"code": 200, "data": {"guali_id": 1}, "message": "success"}
```

## 6. 测试要点
- POST /api/import/json 上传含 5 条卦例的 JSON → 返回 imported=5
- POST /api/import/manual 输入卦名（非代码）→ 正确转换并导入
- GET /api/import/status 返回 last_import_time

### 用户测试 👤
启动后端后，用浏览器打开 `http://localhost:8001/docs`，在 Swagger 页面直接测试三个端点。

## 7. 潜在陷阱与风险
- [文件上传安全] 用户上传非 JSON 文件 → 解析失败应返回明确错误信息，不要 500。
- [卦名转代码] 手动导入时前端传卦名（如"天火同人"），需在 service 层查 bagong_gua 表获取代码。如果卦名不存在 → 返回 400 "卦名不存在"。
- [大文件] JSON 文件可能很大（数百条卦例）→ FastAPI 默认上传大小限制需调整，或前端分批上传。
