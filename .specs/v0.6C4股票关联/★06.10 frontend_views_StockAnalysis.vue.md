# 文件规划：frontend/src/views/StockAnalysis.vue 🔴

> 🔴 核心页面：C4 主界面——股票管理列表 + K线图 + 周期切换。

## 1. 基本信息
- **所属模块**：frontend/views/
- **优先级**：P0
- **依赖文件**：`KlineChart.vue`、`IntradayChart.vue`、`GualiFloatPanel.vue`、`frontend/src/api/index.js`
- **被依赖文件**：`frontend/src/router/index.js`

## 2. 核心职责
C4 股票关联主页面——搜索添加标的、管理列表、K线图展示、周期切换、卦例浮窗。

## 3. 页面布局
```
┌──────────────────────────────────────────────────┐
│  [返回]  000503 ST生物               [设置]      │
├──────────────────────────────────────────────────┤
│  周期: [日K] [月K] [年K]                          │
├──────────────────────────────────────────────────┤
│                                                  │
│              KlineChart 主区域 (ECharts)           │
│                                                  │
│  横轴: 公历日期 + 月柱/日柱                       │
│  纵轴: 价格 + 成交量副图                           │
│                                                  │
├──────────────────────────────────────────────────┤
│  该标的关联卦例数: 24 条                           │
└──────────────────────────────────────────────────┘
```

## 4. 内部逻辑要点
- 顶栏：股票名称 + 周期选择（日/月/年）
- 主区域：KlineChart 组件（ECharts）
- K 线双击→弹出 IntradayChart 分时图浮窗 + GualiFloatPanel 卦例浮窗
- K 线样式：应验=实心，模糊/不验=灰底空心，无卦例=空心
- 月K横轴：农历月名（如"卯月(3/5-4/5)"）
- 管理列表：左侧或弹窗，列出已添加的股票，可新增/更新/删除

## 5. 测试要点
- 搜索股票→添加到列表→K线图加载
- 日K/月K/年K切换→数据正确
- 双击有卦例的日K→分时图+卦例浮窗弹出

### 用户测试 👤
浏览器中打开 C4 页面，搜索"平安"→添加 000001 → 查看日K→切换月K→双击某日K线→确认浮窗内容。

## 6. 潜在陷阱与风险
- [ECharts 生命周期] onMounted init → onUnmounted dispose。切换股票时先 dispose 再 init，否则图表叠加。
- [月K聚合性能] 10 年日K数据聚合为月K→数据量不大（~2500 条日K），纯 Python 计算毫秒级，无需预存。
