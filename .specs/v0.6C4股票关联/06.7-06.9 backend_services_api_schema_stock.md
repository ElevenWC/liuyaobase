## 06.7 backend/services/zhanyan_service.py

### 基本信息
- **所属模块**：services/
- **优先级**：P2
- **依赖文件**：`backend/crud/tag.py`
- **被依赖文件**：`backend/api/routers/stock.py`

### 核心职责
占验标签管理——修改卦例的占验状态（通过 guali_tag 表操作）。

### 对外接口
```python
def set_zhanyan(session, guali_id: int, zhanyan: str):
    """设置占验状态
    zhanyan: "应验" / "模糊" / "不验" / ""（清除）
    先 DELETE 旧占验标签关联 → INSERT 新关联
    """
```

### 内部逻辑要点
- 占验标签是互斥的（同一卦例同一时刻只有一个占验状态）
- 修改时事务操作：DELETE 旧 + INSERT 新
- 标签名："占验-应验"、"占验-模糊"、"占验-不验"

## 06.8 backend/api/routers/stock.py

### 基本信息
- **所属模块**：api/routers/
- **优先级**：P1
- **依赖文件**：`backend/services/stock_data_service.py`、`backend/services/market_service.py`、`backend/services/zhanyan_service.py`、`backend/schemas/stock.py`

### 对外接口（9 个端点）
```python
router = APIRouter(prefix="/api/stock", tags=["股票"])

@router.get("/search")              # 搜索股票
@router.get("/list")                # 已添加股票列表
@router.post("")                    # 添加新标的 + 拉取数据
@router.delete("/{stock_id}")       # 删除标的
@router.post("/{stock_id}/update")  # 手动更新数据
@router.get("/{stock_id}/klines")   # K线数据（period=day/month/year）
@router.get("/{stock_id}/minute")   # 分钟K
@router.get("/{stock_id}/guacases") # 指定日期卦例列表
@router.put("/{stock_id}/guacase/{guali_id}/zhanyan")  # 修改占验
```
