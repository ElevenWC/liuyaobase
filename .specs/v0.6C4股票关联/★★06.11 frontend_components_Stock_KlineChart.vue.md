# 文件规划：frontend/src/components/Stock/KlineChart.vue 🔴🔴

> 🔴🔴 最高审查：ECharts K 线图——三种样式联动 + 双击弹窗 + 横轴干支标注。

## 1. 基本信息
- **所属模块**：frontend/components/Stock/
- **优先级**：P0
- **依赖文件**：`echarts`、`frontend/src/api/index.js`
- **被依赖文件**：`StockAnalysis.vue`

## 2. 核心职责
ECharts K 线图组件——日K/月K/年K 切换渲染，K 线三种样式（实心/空心/灰底），双击弹出分时图+卦例浮窗。

## 3. 对外接口
```vue
<!-- Props -->
stockId: Number         # 股票 ID
period: String          # "day" / "month" / "year"
height: String          # 图表高度

<!-- Events -->
@dblclick-kline(date)   # 双击 K 线 → 父组件弹出浮窗
```

## 4. 内部逻辑要点

### 4.1 K 线三种样式
| 类型 | 条件 | 阳线 | 阴线 |
|------|------|------|------|
| 普通 | 该日无卦例 | 空心红色 | 空心绿色 |
| 应验 | 有卦例 + 占验=应验 | **实心**红色 | **实心**绿色 |
| 待验 | 有卦例 + 占验=模糊/不验 | 空心+灰底 | 空心+灰底 |

ECharts 实现：每个 K 线单独设置 `itemStyle.color` 和 `itemStyle.borderColor`，根据 guacase_map 逐个覆盖。

### 4.2 横轴标注
- 日K：公历日期 + 干支日柱（从 guali_time 获取）
- 月K：农历月名 + 公历范围
- 年K：干支年份

### 4.3 成交量副图
- K 线图下方叠加成交量柱状图
- 红色柱 = 涨，绿色柱 = 跌

## 5. 测试要点
- 三种 K 线样式正确渲染
- 日K/月K/年K 切换无报错
- 双击触发事件携带正确日期

### 用户测试 👤
打开 C4 页面→选一只已关联卦例的股票→日K图中确认：
1. 有卦例日期显示实心 K 线
2. 无卦例日期显示空心 K 线
3. 双击实心 K 线→分时图+卦例浮窗弹出
4. 切换到月K→横轴为农历月名
5. 成交量柱颜色与涨跌一致

## 6. 潜在陷阱与风险

- [ECharts 自定义样式限制] ECharts 的 candlestick 系列不直接支持每根 K 线独立颜色 → 需要用 `series.itemStyle` + 回调函数逐根设置，或拆分为多个 series 分别渲染三种类型。
- [响应式] 窗口缩放时图表自适应 → 监听 `window.resize` 或使用 ECharts 的 `resize` 方法。
- [月K数据为空] 农历月无交易日→该月不渲染 K 线，不要显示空白占位。
- [ECharts dispose] 组件卸载时必须 `dispose()` → 否则切换股票时旧图表残留在 DOM。
- [双击事件冲突] ECharts 的 dblclick 和 click 事件可能冲突 → 用计时器区分：300ms 内连续两次 click = dblclick。
