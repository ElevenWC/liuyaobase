# 文件规划：backend/crud/stock_*.py + backend/models/stock_*.py（6个文件）

## 1. 基本信息
- **所属模块**：crud/ + models/
- **优先级**：P1
- **依赖文件**：`backend/db/connection.py`
- **被依赖文件**：`backend/services/stock_data_service.py`、`backend/services/market_service.py`

## 2. 核心职责
股票 3 张表的基础 CRUD + SQLModel 模型定义。与卦例的 guali_* CRUD 完全同模式。

## 3. 文件清单

| 文件 | 对应表 | 说明 |
|------|--------|------|
| `models/stock_info.py` | stock_info | 股票基本信息 |
| `models/stock_day_kline.py` | stock_day_kline | 日K（OHLC） |
| `models/stock_minute_kline.py` | stock_minute_kline | 分钟K（OHLC） |
| `crud/stock_info.py` | stock_info | 增删查 |
| `crud/stock_day_kline.py` | stock_day_kline | 批量插入 + 日期范围查询 |
| `crud/stock_minute_kline.py` | stock_minute_kline | 批量插入 + 时间范围查询 |

## 4. 内部逻辑要点

### stock_info CRUD
```python
def create(session, data: dict) -> StockInfo: ...
def get_all(session) -> list[StockInfo]: ...
def delete(session, stock_id: int): ...
```

### stock_day_kline CRUD
```python
def insert_batch(session, stock_id: int, rows: list[dict]): ...
    # 用 INSERT IGNORE 防重复（UNIQUE KEY uk_stock_date）
def get_by_date_range(session, stock_id: int, start: date, end: date) -> list: ...
```

### stock_minute_kline CRUD
```python
def insert_batch(session, stock_id: int, rows: list[dict]): ...
    # 每分钟一条，量很大
def get_by_time_range(session, stock_id: int, start: datetime, end: datetime) -> list: ...
```

## 5. 测试要点
- 批量插入日K后按日期查询无遗漏
- INSERT IGNORE 重复数据不报错

## 6. 潜在陷阱与风险
- [分钟K数据量] 每天 240 分钟 × 每年 ~250 交易日 = 60000 条/年/股。批量插入务必用 `session.add_all()` + 分批提交（每 1000 条一批）。
- [日期/时间类型] 日K的 trade_date 用 DATE，分钟K的 trade_time 用 DATETIME（含跨天夜盘时间）。
