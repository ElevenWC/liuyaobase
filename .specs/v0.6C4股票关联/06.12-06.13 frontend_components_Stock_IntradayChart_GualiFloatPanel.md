# 文件规划：06.12 IntradayChart + 06.13 GualiFloatPanel（2个组件）

## 06.12 frontend/src/components/Stock/IntradayChart.vue

### 基本信息
- **所属模块**：frontend/components/Stock/
- **优先级**：P2
- **依赖文件**：`echarts`、`frontend/src/api/index.js`
- **被依赖文件**：`StockAnalysis.vue`

### 核心职责
分时图浮窗——双击日K后弹出，显示当日分钟级价格走势曲线。

### 对外接口
```vue
Props: stockId: Number, tradeDate: String
```

### 内部逻辑要点
- 调 API `GET /api/stock/{id}/minute?date=xxx` 获取分钟K
- ECharts 折线图：横轴=时间，纵轴=价格
- 支持拖拽和关闭
- 如果有夜盘跨天→时间轴显示完整 datetime

## 06.13 frontend/src/components/Stock/GualiFloatPanel.vue 🟡

### 基本信息
- **所属模块**：frontend/components/Stock/
- **优先级**：P1
- **依赖文件**：`frontend/src/api/index.js`、`shared/GuaCiFloat.vue`
- **被依赖文件**：`StockAnalysis.vue`

### 核心职责
卦例详情浮窗——双击日K后弹出，显示该日期关联卦例的完整信息（复用 C1 的 5 表查询）。

### 对外接口
```vue
Props: gualiId: Number
```

### 内部逻辑要点
- 调 API 获取卦例详情（复用 C1 的 guali_service）
- 显示：卦象表格（复用 GualiDetail 的展示逻辑）、占问事由、占断
- 卦名点击→弹出 GuaCiFloat
- [修改占验] 按钮→调 zhanyan API → 更新 guali_tag
- 如果该日有多个卦例→每个卦例独立浮窗

### 显示开关
- 天干开关：独立控制（与 C1 详情页不联动），默认关闭
