# 文件规划：frontend/src/components/Search/WindowManager.vue

## 1. 基本信息
- **所属模块**：frontend/components/Search/
- **优先级**：P2
- **依赖文件**：无
- **被依赖文件**：`Search.vue`

## 2. 核心职责
浮窗管理器——管理检索页面中所有浮窗的 z-index 层级和定位。多浮窗共存时，最后点击的在上层。

## 3. 内部逻辑要点
- 维护全局 z-index 计数器（初始 1000）
- 浮窗获得焦点→z-index + 1
- 浮窗关闭→计数器不变（避免同层碰撞）
- 不负责浮窗内容（内容由 GuaCiFloat 等组件自己渲染）

## 4. 测试要点
- 打开 3 个 GuaCiFloat→点击第 1 个→升到最上
- 关闭中间浮窗→其余两个层级正确

## 5. 潜在陷阱与风险
- [全局唯一性] 如果 C1/C4 也打开了浮窗→跨模块 z-index 冲突。改为使用 provide/inject 全局 z-index 或 CSS 变量统一管理。
