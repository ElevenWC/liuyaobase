# 文件规划：backend/schemas/search.py 🟡

> 🟡 重要：检索请求结构定义了前端和后端的通信协议，字段设计直接影响 C3 全部功能。

## 1. 基本信息
- **所属模块**：schemas/
- **优先级**：P0
- **依赖文件**：`pydantic`
- **被依赖文件**：`backend/api/routers/search.py`、`backend/services/search_service.py`

## 2. 核心职责
C3 检索请求/响应 Pydantic 模型——条件、逻辑链、分页、结果格式。

## 3. 对外接口

```python
class Condition(SQLModel):
    """单个检索条件"""
    id: str                        # 条件唯一 ID（如 "cond_1"）
    field: str                     # 字段名（如 "ben_liuqin"）
    operator: str                  # 运算符（equals/not_equals/in/not_in/gt/lt/gte/lte/range）
    value: str | list[str]         # 值（单个或列表）
    scope: str | None              # 来源范围（ben_gua/zhi_gua/yimao/zengshan/bian_yao）

class RelationCondition(Condition):
    """关系条件——两个地支对象之间的关系"""
    left_type: str                 # 左对象类型（yao_object/time_object/condition_group_ref）
    left_value: str                # 左对象值
    relation: str                  # 关系：生/克/合/冲/半合/三合/=/长生/帝旺/墓/绝
    right_type: str                # 右对象类型
    right_value: str               # 右对象值
    bureau: str | None             # 三合局类型（水/木/火/金/不限），仅三合时有效

class LogicItem(SQLModel):
    """逻辑链节点"""
    type: str                      # "condition" / "and" / "or" / "not" / "(" / ")"

class SearchRequest(SQLModel):
    conditions: list[Condition | RelationCondition]
    logic: list[LogicItem]
    pagination: dict               # {"page": 1, "page_size": 50}

class SearchResponse(SQLModel):
    results: list[dict]
    total: int
    page: int
    page_size: int
```

## 4. 内部逻辑要点
- Condition 和 RelationCondition 用 Union 类型区分
- logic 链定义了条件之间的 AND/OR/NOT/括号关系
- pagination 默认每页 50 条

## 5. 输入输出示例
```json
{
  "conditions": [
    {"id": "c1", "field": "ben_liuqin", "operator": "equals", "value": "妻财", "scope": "ben_gua"},
    {"id": "r1", "left_type": "yao_object", "left_value": "世爻",
     "relation": "克", "right_type": "condition_group_ref", "right_value": "c1"}
  ],
  "logic": [{"type": "("}, {"type": "condition", "id": "c1"}, {"type": "and"}, {"type": "condition", "id": "r1"}, {"type": ")"}],
  "pagination": {"page": 1, "page_size": 50}
}
```

## 6. 测试要点
- 必填字段缺失 → 422
- relation 为"三合"时 bureau 必填

## 7. 潜在陷阱与风险
- [scope 与 field 兼容] 不是所有字段都支持所有 scope→service 层需校验。schema 层只校验格式。
