# 文件规划：frontend/src/components/Search/RecommendedSchemes.vue

> **2026-05-27 更新**：仅保留用户自定义方案（localStorage），不需要预设方案。

## 1. 基本信息
- **所属模块**：frontend/components/Search/
- **优先级**：P2
- **依赖文件**：`useSearchStore.js`
- **被依赖文件**：`Search.vue`

## 2. 核心职责
自定义方案管理——用户保存当前检索条件为方案、载入已保存方案、删除方案。方案存储在 localStorage。

## 3. 对外接口
- 方案列表展示（名称、保存时间）
- 保存当前条件为方案（用户自定义名称）
- 点击方案→载入条件（`store.applyScheme(scheme)`）
- 删除方案

## 4. 内部逻辑要点
- store 已有 `loadSchemes/saveScheme/applyScheme/deleteScheme` 方法，直接调用
- 方案数据结构：`{ name, conditions, logic, time }`
- 保存时去重同名方案
- 不需要预设方案，不需要后端 API

## 5. 测试要点
- 保存方案→刷新页面→方案仍存在
- 点击方案→条件区域自动填充
- 删除方案→列表更新

## 6. 潜在陷阱与风险
- [方案版本] 字段名或运算符如果后续变更→旧方案失效。加版本号，载入时校验。
- [同名覆盖] 目前去重同名方案，用户保存时需提示
