# 文件规划：frontend/src/components/Search/RecommendedSchemes.vue

## 1. 基本信息
- **所属模块**：frontend/components/Search/
- **优先级**：P2
- **依赖文件**：`useSearchStore.js`
- **被依赖文件**：`Search.vue`

## 2. 核心职责
推荐方案面板——预设检索模板，用户点击即可载入条件。

## 3. 预设方案示例
| 方案名 | 条件描述 |
|--------|---------|
| 动爻带干禄 | 本卦动爻 AND 带干禄 |
| 世爻是驿马 | 世爻 AND 是驿马 |
| 妻财爻生世爻 | 妻财爻克世爻（看官鬼持世） |

## 4. 内部逻辑要点
- 从 store.schemes 读取方案列表
- 点击→ `store.applyScheme(scheme)`
- 支持用户保存当前条件为自定义方案（localStorage）

## 5. 测试要点
- 点击推荐方案→条件区域自动填充
- 自定义方案保存→刷新页面→仍存在

## 6. 潜在陷阱与风险
- [方案版本] 预设方案的字段名或运算符如果后续变更→旧方案失效。加版本号，载入时校验。
