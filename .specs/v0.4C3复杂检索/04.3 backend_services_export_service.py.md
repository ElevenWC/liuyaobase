# 文件规划：backend/services/export_service.py

## 1. 基本信息
- **所属模块**：services/
- **优先级**：P2
- **依赖文件**：`backend/services/search_service.py`
- **被依赖文件**：`backend/api/routers/search.py`

## 2. 核心职责
检索结果导出——将搜索结果转为 CSV 或 JSON 文件，返回下载链接。

## 3. 对外接口
```python
def export_results(session, request: SearchRequest, format: str = "csv") -> str:
    """执行检索 → 格式化为 CSV/JSON → 保存临时文件 → 返回文件路径"""
```

## 4. 内部逻辑要点
- 复用 `search_service.execute_search()` 获取结果（不分页，全量）
- CSV：用 Python `csv` 模块写出，编码 utf-8-sig
- JSON：`json.dumps()` 写出
- 临时文件存 `backend/exports/` 目录，返回下载 URL

## 5. 测试要点
- 无结果时导出空文件（含表头）
- CSV 中文不乱码（Excel 可直接打开）

## 6. 潜在陷阱与风险
- [大数据量] 检索结果可能上千条 → CSV 流式写出，避免全量加载到内存。
