# 文件规划：frontend/src/components/Search/ConditionBuilder.vue 🔴

> 🔴 核心组件：C3 最复杂的 UI——字段选择/运算符/值输入/条件组/关系/神煞/数目判断，全部在此组件中。

## 1. 基本信息
- **所属模块**：frontend/components/Search/
- **优先级**：P0
- **依赖文件**：`useSearchStore.js`、`FieldLibrary.vue`、`frontend/src/api/index.js`
- **被依赖文件**：`Search.vue`

## 2. 核心职责
条件构建器——用户在此完成所有检索条件的输入和编辑。支持 6 种条件类型 × 多种交互模板。

## 3. 内部逻辑要点

### 3.1 6 种条件类型及其交互

**① 爻属性条件**（最常用）
```
[来源:本卦▼] [字段:六亲▼] [运算符:=▼] [值:妻财▼]
```
来源 5 选 1（本卦/变爻/之卦静爻/易冒伏神/增删伏神），字段和值根据来源动态变化。

**② 关系条件**（生克合冲半合三合=）
```
[左对象:世爻▼] [关系:生▼] [右对象:月支▼]
```
- 关系为"半合/合/冲"→ 2 个地支对象，无"于"字
- 关系为"三合"→ 3 个地支对象 + 局类型选择
- 关系为"生克"→ 2 个地支对象，有顺序
- 关系为"长生/帝旺/墓/绝"→ 2 个地支对象 + "于"字

**③ 神煞条件**
```
[对象:妻财爻▼] [是/带/是或带▼] [神煞:干禄▼]
```

**④ 数目判断**
```
[范围:本卦▼] 中 [属性:六亲=妻财▼] 的数目 [运算符:=▼] [值:0▼]
```

**⑤ 卦类条件**（独立，不需要条件组）
```
[字段:本卦卦宫▼] [=▼] [值:离宫▼]
```

**⑥ 时间条件**（独立，不需要条件组）
```
[字段:日支▼] [=▼] [值:子▼]
```

### 3.2 条件组
- **同一爻条件组**（OR 逻辑）：从多个来源中找符合条件的爻
- **同爻位条件组**（AND 逻辑）：要求多个来源在同一爻位都满足
- **飞神条件组**：指定用神六亲 → 自动返回飞神

### 3.3 逻辑链编辑
- 每个条件/条件组旁边有"+"按钮→添加 AND/OR/NOT/括号
- 逻辑链以可视化标签展示，可拖拽调整顺序

## 4. 关键 UI 交互
- 字段下拉支持搜索（字段很多，需要搜索过滤）
- 添加条件→动画滑入
- 条件组折叠/展开
- 实时预览检索表达式（顶部）

## 5. 测试要点
- 6 种条件类型全部能正确添加/编辑/删除
- 三合关系的 3 个地支选择器联动
- 逻辑链 AND/OR 切换

### 用户测试 👤
在检索页面逐一创建 6 种条件类型，确认每种类型的下拉选项和数据正确。特别是：三合关系的 3 个对象选择器；神煞的"是/带/是或带"三个选项；数目判断的运算符。

## 6. 潜在陷阱与风险
- [字段选项联动] 选了来源"变爻"→字段下拉应只显示变爻支持的字段（不含暗动、世应等）。联动逻辑复杂，容易漏。
- [三合特殊交互] 三合是唯一需要 3 个对象的类型 → 条件模板从 2 列扩展为 4 列（左对象1/左对象2/左对象3/关系/局类型），与二合/冲的 3 列不同。
- [条件组嵌套] 理论上条件组内可以再嵌套条件组 → 目前不支持，前端阻止。
