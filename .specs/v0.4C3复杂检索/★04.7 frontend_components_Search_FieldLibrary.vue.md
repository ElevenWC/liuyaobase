# 文件规划：frontend/src/components/Search/FieldLibrary.vue 🟡

## 1. 基本信息
- **所属模块**：frontend/components/Search/
- **优先级**：P1
- **依赖文件**：`useSearchStore.js`
- **被依赖文件**：`ConditionBuilder.vue`

## 2. 核心职责
字段库面板——按分类展示所有可检索的字段，用户点击拖拽到条件构建区。

## 3. 字段分类
| 分类 | 包含字段 |
|------|---------|
| 时间类 | 公历年、年柱/干/支、月柱/干/支、日柱/干/支、旬空 |
| 卦类 | 本卦名、之卦名、本卦卦宫、之卦卦宫、宫位、特殊类型、反吟伏吟 |
| 爻属性 | 爻位、爻类型、六亲、天干、地支、六神、世应、动爻、暗动 |
| 关系 | 生克、合冲、半合、三合、=、生旺墓绝 |
| 神煞 | 干禄、驿马、羊刃、桃花（是/带/是或带） |
| 数目 | 某属性在卦中的数量统计 |

## 4. 内部逻辑要点
- 左侧分类树 + 右侧字段列表
- 点击字段→弹出条件类型选择（普通/关系/神煞/数目）
- 折叠/展开分类
- 搜索框实时过滤字段

## 5. 测试要点
- 每类字段展开后子项正确
- 搜索"妻财"→过滤出六亲相关字段

## 6. 潜在陷阱与风险
- [字段可用性] 某些字段只在特定来源下可用（如暗动只在本卦）→ 字段上标灰色提示。
