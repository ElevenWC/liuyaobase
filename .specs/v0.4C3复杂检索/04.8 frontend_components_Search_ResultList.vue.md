# 文件规划：frontend/src/components/Search/ResultList.vue

## 1. 基本信息
- **所属模块**：frontend/components/Search/
- **优先级**：P0
- **依赖文件**：`useSearchStore.js`、`shared/GuaCiFloat.vue`
- **被依赖文件**：`Search.vue`

## 2. 核心职责
检索结果列表——分页表格展示、排序、点击卦名弹出卦爻辞浮窗。

## 3. 内部逻辑要点
- 表格列：序号/占问时间/占问事由/本卦名/之卦名/标签
- 本卦名/之卦名可点击→弹出 GuaCiFloat
- 点击行→跳转 C1 详情页
- 分页器：底部，显示"共 N 条，第 P 页"
- 多选模式：每行有 checkbox，支持批量打标签

## 4. 测试要点
- 搜索结果 0 条→显示"无结果"
- 点击卦名→GuaCiFloat 弹出
- 批量选择→点击"批量打标签"→弹出标签选择器

## 5. 潜在陷阱与风险
- [结果集太大] 1000+ 条结果分页渲染 → 用虚拟滚动或限制单页最多 100 条。
