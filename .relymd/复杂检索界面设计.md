### 5.3 窗口间通信

```javascript
// 使用 postMessage API 进行窗口间通信
// 主窗口
const childWindow = window.open('/search?condition=...', '_blank');

// 子窗口

  if (event.data.type === 'share_search') {
```

## 十三、字段详细说明

### 12.1 时间类字段

| 字段名 | 字段类型 | 可选值/格式 | 说明 |
|--------|---------|------------|------|
| **公历年** | 单值 | 四位数字，如2024、2025 | 卦例占卜的公历年份 |
| **公历月日** | 单值 | MM.DD格式，如02.12 | 卦例占卜的公历月日 |
| **年柱** | 单值 | 甲子、乙丑...癸亥 | 干支时间表示的年柱，由公历年转换而来 |
| **月柱** | 单值 | 甲子、乙丑...癸亥 | 干支时间表示的月柱，由公历月日转换而来 |
| **日柱** | 单值 | 甲子、乙丑...癸亥 | 干支时间表示的日柱，由公历月日转换而来 |
| **日干** | 单值 | 甲、乙、丙、丁、戊、己、庚、辛、壬、癸 | 日柱的天干部分，用于判断六神、干禄、羊刃 |
| **日支** | 单值 | 子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥 | 日柱的地支部分，用于判断旬空、驿马、桃花 |
| **旬空** | 单值 | 戌亥空、申酉空、午未空、辰巳空、寅卯空、子丑空 | 根据日支判断的旬空，表示该旬内空亡的地支 |

### 12.2 卦类字段

| 字段名 | 字段类型 | 可选值/格式 | 说明 |
|--------|---------|------------|------|
| **本卦名** | 单值 | 64个六十四重卦标准名称，如乾为天、山风蛊等 | 卦例的本卦名称，根据八宫卦序表确定，用户手动输入 |
| **之卦名** | 单值 | 64个六十四重卦标准名称，可为空 | 卦例的之卦名称，若为空则无动爻，用户手动输入 |
| **内卦** | 单值 | 乾、兑、离、震、巽、坎、艮、坤 | 本卦代码前3位对应的单卦，下拉选择 |
| **外卦** | 单值 | 乾、兑、离、震、巽、坎、艮、坤 | 本卦代码后3位对应的单卦，下拉选择 |
| **本卦代码** | 单值 | 6位二进制，如111111 | 本卦的代码表示，便于计算机处理，不显示在界面中 |
| **之卦代码** | 单值 | 6位二进制，可为空 | 之卦的代码表示，不显示在界面中 |
| **爻变代码** | 单值 | 6位二进制，如000010 | 通过本卦与之卦按位异或得到，为1的位置为动爻，不显示在界面中 |
| **卦宫** | 单值 | 乾宫、坎宫、艮宫、震宫、巽宫、离宫、坤宫、兑宫 | 本卦所属的卦宫，下拉选择 |
| **卦宫五行** | 单值 | 金、水、土、木、火 | 卦宫对应的五行属性，用于六亲计算 |
| **宫位** | 单值 | 本宫、一世、二世、三世、四世、五世、游魂、归魂 | 本卦在卦宫中的位置，根据八宫卦序表确定，下拉选择 |
| **特殊类型** | 单值 | 六冲、六合、普通 | 本卦的特殊分类，六冲卦10个，六合卦8个，下拉选择 |
| **内卦** | 单值 | 乾、兑、离、震、巽、坎、艮、坤 | 本卦代码前3位对应的单卦 |
| **外卦** | 单值 | 乾、兑、离、震、巽、坎、艮、坤 | 本卦代码后3位对应的单卦 |

### 12.3 爻类字段

| 字段名 | 字段类型 | 可选值/格式 | 说明 |
|--------|---------|------------|------|
| **爻位** | 单值 | 初爻、二爻、三爻、四爻、五爻、上爻 | 重卦中六个爻的位置，下拉选择 |
| **爻类型** | 单值 | 阳爻、阴爻 | 爻的类型，用1/0表示，下拉选择 |
| **爻状态** | 单值 | 动爻、静爻 | 爻的状态，根据爻变代码判断，下拉选择 |
| **爻地支** | 单值 | 子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥 | 根据纳甲装卦规则，每个爻位固定对应一个地支，无论本卦还是之卦都相同，下拉选择 |
| **爻地支五行** | 单值 | 水、木、火、金、土 | 爻地支的五行属性，根据地支五行规则判断，下拉选择 |
| **爻六亲** | 单值 | 父母、官鬼、子孙、妻财、兄弟 | 根据卦宫五行与爻地支五行的生克关系判断：<br>爻地支五行生卦宫五行→父母<br>爻地支五行克卦宫五行→官鬼<br>卦宫五行生爻地支五行→子孙<br>卦宫五行克爻地支五行→妻财<br>卦宫五行=爻地支五行→兄弟，下拉选择 |
| **爻六神** | 单值 | 青龙、朱雀、勾陈、螣蛇、白虎、玄武 | 根据日干和爻位判断，不同日干六神排列不同，下拉选择 |

### 13.7 高级关系检索场景

#### 场景1：检索日支与妻财爻的地支相冲的卦例

**检索条件**：
```
(妻财爻.地支) 与 日支 = 相冲
```

**说明**：
1. **妻财爻.地支**：找出卦例中六亲为"妻财"的爻的地支
   - 首先找出卦例中六亲为"妻财"的爻（可能是一个或多个）
   - 获取该爻的地支属性
   - 例如：三爻的六亲是妻财，地支是亥

2. **与 日支 = 相冲**：判断妻财爻的地支是否与卦例的日支相冲
   - 地支相冲关系：子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲
   - 例如：如果日支是巳，妻财爻.地支是亥，则巳亥冲，条件满足

**完整表达式示例**：
```
日支 = 巳 AND (妻财爻.地支) 与 日支 = 相冲
# 即：日支是巳，且妻财爻的地支是亥（巳亥冲）
```

**界面操作步骤**：
1. 拖拽"日支"字段到构建区
2. 选择运算符"="，选择值"巳"
3. 选择逻辑运算符"AND"
4. 拖拽"妻财爻.地支"字段到构建区
5. 选择关系运算符"与"
6. 拖拽"日支"字段到构建区
7. 选择关系类型"相冲"

**返回结果**：
- 所有日支为巳，且卦例中妻财爻的地支是亥的卦例

#### 场景2：检索存在爻地支与日支相冲关系的卦例

**检索条件**：
```
(某爻.地支) 与 日支 = 相冲
```

**说明**：
1. **某爻.地支**：卦例中任意一个爻的地支
   - 不限制六亲类型
   - 可以是初爻到上爻中的任意一个
   - 只要有一个爻满足条件即可

2. **与 日支 = 相冲**：判断任意一个爻的地支是否与日支相冲
   - 只要有一个爻的地支与日支相冲，条件即满足
   - 例如：日支是子，如果初爻地支是午（子午冲），条件满足

**完整表达式示例**：
```
日支 = 子 AND (
  (初爻.地支) 与 日支 = 相冲 OR
  (二爻.地支) 与 日支 = 相冲 OR
  (三爻.地支) 与 日支 = 相冲 OR
  (四爻.地支) 与 日支 = 相冲 OR
  (五爻.地支) 与 日支 = 相冲 OR
  (上爻.地支) 与 日支 = 相冲
)
```

**界面操作步骤**：
1. 拖拽"日支"字段到构建区
2. 选择运算符"="，选择值"子"
3. 选择逻辑运算符"AND"
4. 添加括号分组
5. 依次拖拽"初爻.地支"、"二爻.地支"...到构建区
6. 每个选择关系运算符"与"
7. 拖拽"日支"字段
8. 选择关系类型"相冲"
9. 各条件之间用"OR"连接

**返回结果**：
- 所有日支为子，且卦例中至少有一个爻的地支与子相冲的卦例
- 例如：初爻地支为午（子午冲），或二爻地支为午等

### 13.8 关系运算符说明

| 运算符 | 说明 | 适用关系类型 | 示例 |
|--------|------|------------|------|
| **与** | 判断两个字段间的关系 | 地支相合、地支相冲、五行相生、五行相克、生旺墓绝 | `世爻.地支 与 日支 = 相合` |
| **WITH** | 判断两个字段间存在指定关系 | 地支相合、地支相冲、地支与地支的相合/相冲组合 | `子孙爻.地支 WITH 日支 = 相合` |

**关系类型选项**：
- **地支相合**：子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合
- **地支相冲**：子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲
- **五行相生**：金生水、水生木、木生火、火生土、土生金
- **五行相克**：金克木、木克土、土克水、水克火、火克金

**WITH运算符详细说明**：

WITH运算符用于判断两个字段之间是否存在指定的关系（如相合、相冲等）。与"与"运算符不同：
- **与运算符**：判断两个字段的值是否直接满足某个关系，需要两个值是特定的对
- **WITH运算符**：判断两个字段的值是否在指定的关系列表中，只要有一对满足即可

**WITH运算符的判断逻辑**：

当使用`字段A WITH 字段B = 关系类型`时：
1. 找出字段A和字段B的值
2. 判断这两个值是否满足指定的关系类型
3. 关系类型为"相合"、"相冲"、"三合局"等

**示例说明**：

1. **子孙爻.地支 WITH 日支 = 相合**
   - 找出子孙爻的地支和日支的值
   - 判断这两个地支是否相合（子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合）
   - 只要有一对相合，条件即满足
   - 例如：子孙爻地支=亥，日支=寅，则亥寅合，满足条件

2. **妻财爻.地支 WITH 日支 = 相合**
   - 找出妻财爻的地支和日支的值
   - 判断这两个地支是否相合
   - 例如：妻财爻地支=辰，日支=酉，则辰酉合，满足条件

3. **(初爻.地支) WITH (二爻.地支 OR 三爻.地支) = 相冲**
   - 找出初爻的地支，以及二爻或三爻的地支
   - 判断初爻地支是否与二爻或三爻地支相冲
   - 只要有一个相冲，条件即满足
   - 例如：初爻地支=子，二爻地支=午，则子午冲，满足条件

**WITH与OR的组合**：
```
(子孙爻.地支) WITH 日支 = 相合
```
表示：子孙爻的地支与日支相合

如果需要判断是否满足多种关系中任意一种，可以使用OR连接：
```
(子孙爻.地支) WITH 日支 = 相合 OR (子孙爻.地支) WITH 日支 = 相冲
```
表示：子孙爻的地支与日支相合，或者子孙爻的地支与日支相冲

**WITH与AND的组合**：
```
(子孙爻.地支) WITH 日支 = 相合 AND (官鬼爻.地支) WITH 日支 = 相冲
```
表示：子孙爻的地支与日支相合，且官鬼爻的地支与日支相冲

**后端实现建议**：
WITH运算符可以映射为以下SQL查询：
```sql
-- 示例：子孙爻.地支 WITH 日支 = 相合
SELECT * FROM yao_detail yd
JOIN guali g ON yd.guali_id = g.id
WHERE yd.liuqin = '子孙'
AND (
  -- 地支相合
  (yd.dizhi, g.dizhi_day) IN (('子', '丑'), ('寅', '亥'), ('卯', '戌'), ('辰', '酉'), ('巳', '申'), ('午', '未'))
)
```

**前端使用建议**：
在条件构建器中，当用户选择WITH运算符时：
1. 显示"关系类型"下拉选择（相合、相冲等）
2. 显示"是否区分关系类型"选项（是/否）
   - 是：只判断指定的关系类型
   - 否：判断所有可用关系类型
3. 条件卡片显示格式：`(字段1) WITH (字段2) = 关系类型`
- **生旺墓绝**：长生、帝旺、墓、绝

### 13.9 特殊状态条件

用于判断特殊的存在状态。

**示例**：
- `伏神.存在 = true`（存在伏神的卦例）
- `反吟伏吟.易冒反吟 = true`（易冒反吟的卦例）
- `之卦.存在 = true`（有之卦的卦例，即有动爻）
- `暗动 = 有暗动`（本卦中存在与日支相冲的爻）
- `占验情况 = 应验`（实际占验情况为应验的卦例）

## 十五、运算符详细说明

### 14.1 比较运算符

| 运算符 | 说明 | 适用字段 | 示例 |
|--------|------|---------|------|
| **=** | 等于 | 所有单值字段 | `公历年 = 2024` |
| **≠** 或 **!=** | 不等于 | 所有单值字段 | `卦宫 ≠ 坎宫` |
| **>** | 大于 | 年份、日期 | `公历年 > 2020` |
| **<** | 小于 | 年份、日期 | `公历年 < 2025` |
| **≥** 或 **>=** | 大于等于 | 年份、日期 | `公历年 ≥ 2020` |
| **≤** 或 **<=** | 小于等于 | 年份、日期 | `公历年 ≤ 2024` |

### 14.2 成员运算符

| 运算符 | 说明 | 适用字段 | 示例 |
|--------|------|---------|------|
| **IN** | 在列表中 | 爻位、爻六亲、宫位等 | `爻六亲 IN (子孙, 妻财)` |
| **NOT IN** | 不在列表中 | 爻位、爻六亲、宫位等 | `宫位 NOT IN (本宫, 归魂)` |

### 14.3 文本运算符

| 运算符 | 说明 | 适用字段 | 示例 |
|--------|------|---------|------|
| **包含** | 包含指定文本 | 占问事由、占断 | `占问事由 包含 "股票"` |
| **不包含** | 不包含指定文本 | 占问事由、占断 | `占断 不包含 "下跌"` |
| **匹配** | 正则表达式匹配 | 占问事由、占断 | `占问事由 匹配 "股票.*走势"` |

### 14.4 关系运算符

| 运算符 | 说明 | 适用字段 | 示例 |
|--------|------|---------|------|
| **相合** | 地支相合关系 | 地支类字段 | `世爻.地支 与 日支 = 相合` |
| **相冲** | 地支相冲关系 | 地支类字段 | `子孙爻.地支 与 日支 = 相冲` |
| **相生** | 五行相生关系 | 五行类字段 | `妻财爻.五行 与 日支.五行 = 相生` |
| **相克** | 五行相克关系 | 五行类字段 | `卦宫五行 与 爻地支五行 = 相克` |
| **同** | 五行相同 | 五行类字段 | `卦宫五行 与 爻地支五行 = 同` |

### 14.5 逻辑运算符

| 运算符 | 说明 | 优先级 | 示例 |
|--------|------|-------|------|
| **AND** | 逻辑与 | 低 | `宫位 = 游魂 AND 爻六亲 = 子孙` |
| **OR** | 逻辑或 | 低 | `本卦名 = 乾为天 OR 本卦名 = 坤为地` |
| **NOT** | 逻辑非 | 中 | `NOT 特殊类型 = 六冲` |

### 14.6 括号

| 运算符 | 说明 | 示例 |
|--------|------|------|
| **(** | 左括号，提高优先级 | `(本卦名 = 乾为天 OR 本卦名 = 坤为地) AND 宫位 = 游魂` |
| **)** | 右括号，提高优先级 | 见上 |

**运算符优先级**（从高到低）：
1. 括号 `()`
2. NOT
3. 比较运算符 `=、≠、>、<、≥、≤`
4. 成员运算符 `IN、NOT IN`
5. 文本运算符 `包含、不包含、匹配`
6. 关系运算符 `相合、相冲、生、克、同`
7. AND
8. OR

### 14.7 特殊运算符

| 运算符 | 说明 | 适用字段 | 示例 |
|--------|------|---------|------|
| **存在** | 判断字段/对象是否存在 | 伏神、之卦、反吟伏吟等 | `伏神.存在 = true` |
| **WITH** | 判断两个对象之间存在某种关系 | 爻之间、地支之间 | `子孙爻.地支 WITH 日支 = 相合` |
