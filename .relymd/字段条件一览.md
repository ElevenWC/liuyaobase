# 字段条件一览

#### 本文件集中于自定义检索引擎中所需要的字段和条件,是编写者自己对于字段和条件施加的约束,以防止过多无用或不准确的字段和条件

## 字段库
- 是对应复杂检索界面设计.md中第十二章字段详细说明部分的修改和约束
- 请加入输入方式的列,有手动输入和下拉选择两种
- 之后说的用户实际界面示例为同文件2.1字段库部分的示例

1. 时间类字段中前五个为手动输入,后三个为下拉选择
2. 卦类字段中前两个为手动输入,本卦代码之卦代码爻变代码不需要出现在用户实际界面示例,后面六个为下拉选择,把内卦和外卦也添加到用户实际界面示例相应位置中
3. 爻类字段全部都为下拉选择,有如下修改意见:
````
0. 所有爻类字段除了变爻默认都只检索本卦中的爻,这是显然但是需要强调的
1. 变爻不需要有无变爻的可选值了,因为只要动爻.存在=true就一定存在变爻,变爻只需要作为变爻.[某某]的前提即可,不需要下拉选择
2. 把存在爻地支与日支相冲的关系弄成一个常用判断项添加到爻类字段中,命名为暗动,可选值为有暗动和无暗动
3. 把爻地支五行也添加到用户实际界面示例相应位置中
4. 更改用户实际界面示例的相应部分,使内容匹配
````
4. 关系类字段一般都是出现在判断中,不需要下拉选择,有如下修改意见:
````
1. 地支相合和地支相冲需标注及实现在拖拽到构建区之后变成相合和相冲,即从四个字变为后两个字
2. 五行生克也要分开,五行相生和五行相克,也需标注及实现在拖拽到构建区之后变成相生和相克,即从四个字变为后两个字
3. 反吟伏吟需要下拉选择后再来拖拽
4. 关于生旺墓绝,需要遵循严格的顺序,比如地支1 与 地支2 = 长生的意思就是地支1长生于地支2,一定是[地支1,地支2]对应[寅,亥]等,后面的地支顺序不能互换
5. 飞神伏神的需要下拉选择后再来拖拽
````
5. 神煞类字段全部都为下拉选择,把可选值中的"此神煞"都替换成那一行对应的神煞
6. 其他字段由用户手动输入
