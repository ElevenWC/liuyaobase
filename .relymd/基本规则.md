## 二、干支规则系统

```
亥子：水
寅卯：木
巳午：火
申酉：金
丑未辰戌：土
```

```
克：金克木 → 木克土 → 土克水 → 水克火 → 火克金
```

- 特别注意:以后的描述中,当出现"乾,坤,震,兑,坎,离,艮,巽"这些单字或"乾卦"这样后面加了个"卦"字的名字时,特指三爻叠成的单卦;而出现上述存在于八宫卦序表中的卦名时,特指两个三爻的单卦叠成的六爻重卦


### 3.2 世应定位规则
**《增删卜易》世爻定位法**：
1. **确定卦宫**：查上表得本卦所属宫位
2. **确定宫位**：
````
   - 本宫卦：世在上爻,应在三爻
   - 一世卦：世在初爻,应在四爻
   - 二世卦：世在二爻,应在五爻
   - 三世卦：世在三爻,应在上爻
   - 四世卦：世在四爻,应在初爻
   - 五世卦：世在五爻,应在二爻
   - 游魂卦：世在四爻,应在初爻
   - 归魂卦：世在三爻,应在上爻
````

### 3.3 纳甲装卦规则
**《增删卜易》京房纳甲法--纳地支**：
```
乾卦（内卦）：子、寅、辰
乾卦（外卦）：午、申、戌

坎卦（内卦）：寅、辰、午
坎卦（外卦）：申、戌、子

艮卦（内卦）：辰、午、申
艮卦（外卦）：戌、子、寅

震卦（内卦）：子、寅、辰
震卦（外卦）：午、申、戌

巽卦（内卦）：丑、亥、酉
巽卦（外卦）：未、巳、卯

离卦（内卦）：卯、丑、亥
离卦（外卦）：酉、未、巳

坤卦（内卦）：未、巳、卯
坤卦（外卦）：丑、亥、酉

兑卦（内卦）：巳、卯、丑
兑卦（外卦）：亥、酉、未
```
- 内卦指初爻,二爻,三爻所构成的单卦;外卦指四爻,五爻,上爻所构成的单卦

**装卦步骤**：
1. 确定本卦上下卦（如乾为天：上乾下乾）
2. 内卦从初爻开始装地支（乾在内卦：初爻子,二爻寅,三爻辰）
3. 外卦从四爻开始装地支（乾在外卦：四爻午,五爻申,上爻戌）

### 3.4 六亲生成规则
1. **确定所属的卦宫五行**（见3.1）
2. **各爻六亲**：
   - 爻地支五行生卦宫五行：父母
   - 爻地支五行克卦宫五行：官鬼
   - 卦宫五行生爻地支五行：子孙
   - 卦宫五行克爻地支五行：妻财
   - 卦宫五行=爻地支五行：兄弟

**示例**：乾宫中的卦（卦宫五行为金），子爻(爻地支为子,子的五行为水)：
- 金生水 → 宫五行生爻支五行 → 该子爻的六亲为子孙

### 3.6 伏神规则
**伏神查找条件**：
1. 用神不上卦（卦中无全部六亲）
2. 从本宫卦借爻

**根据《增删卜易》寻找伏神(简称增删伏神)**

**查找步骤**：
1. 确定本卦中无全部六亲(比如缺少妻财爻)
2. 查本宫首卦(即本宫卦)
3. 将本宫卦中对应爻(比如妻财爻)"伏"在本卦对应爻位置下

**示例**：占得天风姤（乾宫）
- 本卦无妻财爻
- 查乾宫首卦乾为天：妻财在寅木（二爻）
- 则妻财寅木称为伏神,天风姤本来的二爻子孙亥水称为飞神



### 3.7 反吟伏吟规则
**反吟**：
1. **易冒反吟**：本卦的内卦或外卦产生了如下的变化
   ```
   乾巽互变
   坎离互变
   艮坤互变
   震兑互变
   ```
   - 如火天大有之水天需是外卦易冒反吟,火天大有之火风鼎是内卦易冒反吟

2. **爻变反吟**：本卦的内卦或外卦产生了如下的变化
   ```
   坤巽互变
   ```
   - 如火风鼎之火地晋是内卦爻变反吟,地水师之风水涣是外卦爻变反吟

**伏吟**： 本卦的内卦或外卦产生了如下的变化
   ```
   乾震互变
   ```
   - 如水雷屯之水天需是内卦伏吟,雷风恒之天风姤是外卦伏吟

### 3.8 六冲六合卦判断
**六冲卦**：六十四重卦中的特殊类型,包括如下重卦
```
乾为天,震为雷,坎为水,艮为山,坤为地,巽为风,离为火,兑为泽,雷天大壮,天雷无妄
```

**六合卦**：六十四重卦中的特殊类型,包括如下重卦

