# 六爻卦例分析系统元素关系图谱

## 一、元素分类

### 1.1 时间类元素
- **公历时间**: 年、月、日
- **干支时间**: 年柱、月柱、日柱
- **天干**: 甲、乙、丙、丁、戊、己、庚、辛、壬、癸（10个）
- **地支**: 子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥（12个）
- **旬空**: 戌亥、申酉、午未、辰巳、寅卯、子丑（6种）

### 1.2 卦类元素
- **八单卦**: 乾、兑、离、震、巽、坎、艮、坤（8个）
  - 单卦代码: 3位二进制
- **六十四重卦**: 乾为天、天风姤等（64个）
  - 重卦代码: 6位二进制
  - 卦宫: 乾宫、坎宫、艮宫、震宫、巽宫、离宫、坤宫、兑宫（8个）
  - 卦宫五行: 金、水、土、木、火
  - 宫位: 本宫、一世、二世、三世、四世、五世、游魂、归魂（8个）
  - 特殊卦类: 六冲卦、六合卦、普通卦

### 1.3 爻类元素
- **爻位**: 初爻、二爻、三爻、四爻、五爻、上爻（6个）
- **爻类型**: 阳爻(1)、阴爻(0)
- **爻状态**: 动爻(1)、静爻(0)
- **爻组合**: 动阳爻、动阴爻、静阳爻、静阴爻

### 1.4 卦理属性元素
- **五行**: 木、火、土、金、水
- **六亲**: 父母、官鬼、子孙、妻财、兄弟
- **六神**: 青龙、朱雀、勾陈、螣蛇、白虎、玄武
- **神煞**: 干禄、驿马、羊刃、桃花

### 1.5 特殊关系元素
- **地支相合**: 子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合
- **地支相冲**: 子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲
- **地支三合局**: 申子辰合水局、亥卯未合木局、寅午戌合火局、巳酉丑合金局
- **生旺墓绝**: 长生、帝旺、墓、绝

## 二、元素间关系映射

### 2.1 地支系统关系

| 关系类型 | 关系描述 | 关系规则 |
|---------|---------|---------|
| **地支→五行** | 每个地支对应一个五行 | 亥子→水、寅卯→木、巳午→火、申酉→金、丑未辰戌→土 |
| **地支相合** | 六组地支成对相合 | 子丑合、寅亥合、卯戌合、辰酉合、巳申合、午未合 |
| **地支相冲** | 六组地支成对相冲 | 子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲 |
| **地支三合局** | 四组地支三合成局 | 申子辰→水局、亥卯未→木局、寅午戌→火局、巳酉丑→金局 |
| **地支带神煞** | 根据日干或日支判断 | 见2.3神煞系统 |

### 2.2 天干系统关系

| 关系类型 | 关系描述 | 关系规则 |
|---------|---------|---------|
| **天干→五行** | 每个天干对应一个五行 | 甲乙→木、丙丁→火、戊己→土、庚辛→金、壬癸→水 |
| **天干带神煞** | 根据日干判断 | 见2.3神煞系统 |

### 2.3 神煞系统关系

| 神煞 | 判断依据 | 关联地支 | 带神煞地支（冲/合） |
|------|---------|---------|---------------------|
| **干禄** | 日干 | 甲→寅、乙→卯、丙戊→巳、丁己→午、庚→申、辛→酉、壬→亥、癸→子 | 合/冲地支也带干禄 |
| **驿马** | 日支 | 申子辰→寅、亥卯未→巳、寅午戌→申、巳酉丑→亥 | 合/冲地支也带驿马 |
| **羊刃** | 日干 | 甲→卯、乙→寅、丙戊→午、丁己→巳、庚→酉、辛→申、壬→子、癸→亥 | 合/冲地支也带羊刃 |
| **桃花** | 日支 | 申子辰→酉、亥卯未→子、寅午戌→卯、巳酉丑→午 | 合/冲地支也带桃花 |

**神煞传播规则**: 若地支A是神煞1，则与地支A相冲的地支B、与地支A相合的地支C也都"带神煞1"。

### 2.4 单卦系统关系

| 关系类型 | 关系描述 | 关系规则 |
|---------|---------|---------|
| **单卦→代码** | 每个单卦对应3位二进制代码 | 乾→111、兑→110、离→101、震→100、巽→011、坎→010、艮→001、坤→000 |
| **单卦→五行** | 每个单卦对应一个五行 | 坎→水、震巽→木、离→火、乾兑→金、坤艮→土 |

### 2.5 重卦系统关系

| 关系类型 | 关系描述 | 关系规则 |
|---------|---------|---------|
| **重卦→代码** | 每个重卦对应6位二进制代码 | 前3位为内卦代码，后3位为外卦代码 |
| **重卦→单卦(内外)** | 重卦由内外单卦组成 | 前3位→内卦，后3位→外卦 |
| **重卦→卦宫** | 每个重卦属于一个卦宫 | 见八宫卦序表 |
| **重卦→卦宫五行** | 卦宫对应的五行 | 乾兑宫→金、坎宫→水、艮坤宫→土、震巽宫→木、离宫→火 |
| **重卦→宫位** | 每个重卦有一个宫位 | 本宫、一世、二世、三世、四世、五世、游魂、归魂 |
| **重卦→特殊类型** | 六冲卦或六合卦 | 六冲卦10个、六合卦8个 |
| **宫位→世应爻位** | 根据宫位确定世爻和应爻位置 | 本宫→世上/应三、一世→世初/应四、二世→世二/应五、三世→世三/应上、四世→世四/应初、五世→世五/应二、游魂→世四/应初、归魂→世三/应上 |

### 2.6 爻系统关系（纳甲装卦）

| 关系类型 | 关系描述 | 关系规则 |
|---------|---------|---------|
| **爻位→地支(内卦)** | 根据内卦单卦确定初二三爻地支 | 乾内→子寅辰、兑内→巳卯丑、离内→卯丑亥、震内→子寅辰、巽内→丑亥酉、坎内→寅辰午、艮内→辰午申、坤内→未巳卯 |
| **爻位→地支(外卦)** | 根据外卦单卦确定四五上爻地支 | 乾外→午申戌、兑外→亥酉未、离外→酉未巳、震外→午申戌、巽外→未巳卯、坎外→申戌子、艮外→戌子寅、坤外→丑亥酉 |

**重要**: 爻的地支无论何时都不变化，无论该爻是动爻、静爻还是变爻。

### 2.7 六亲系统关系

| 关系类型 | 关系描述 | 关系规则 |
|---------|---------|---------|
| **爻地支五行+卦宫五行→六亲** | 根据生克关系确定六亲 | 爻地支五行生卦宫五行→父母<br>爻地支五行克卦宫五行→官鬼<br>卦宫五行生爻地支五行→子孙<br>卦宫五行克爻地支五行→妻财<br>卦宫五行=爻地支五行→兄弟 |

**作用范围**: 本卦的六个爻和之卦的变爻。

### 2.8 六神系统关系

| 关系类型 | 关系描述 | 关系规则 |
|---------|---------|---------|
| **日干+爻位→六神** | 根据日干确定各爻的六神 | 甲乙日→初青二朱三勾四螣五白上玄<br>丙丁日→初朱二勾三螣四白五玄上青<br>戊日→初勾二螣三白四玄五青上朱<br>己日→初螣二白三玄四青五朱上勾<br>庚辛日→初白二玄三青四朱五勾上螣<br>壬癸日→初玄二青三朱四勾五螣上白 |

### 2.9 伏神系统关系

| 关系类型 | 关系描述 | 关系规则 |
|---------|---------|---------|
| **本卦缺六亲→本宫卦查伏神** | 查找本宫卦中对应六亲的爻 | 1. 检查本卦六亲是否齐全<br>2. 若缺某六亲，查同宫本宫卦<br>3. 本宫卦中对应六亲的爻为伏神<br>4. 本卦同爻位的爻为飞神 |
| **飞神-伏神** | 爻位相同 | 本卦某爻位的爻为飞神，本宫卦同爻位的爻为伏神 |

### 2.10 反吟伏吟系统关系

| 关系类型 | 关系描述 | 关系规则 |
|---------|---------|---------|
| **内卦易冒反吟** | 本卦内卦与之卦内卦互变 | 乾巽互变、坎离互变、艮坤互变、震兑互变 |
| **外卦易冒反吟** | 本卦外卦与之卦外卦互变 | 同上 |
| **内卦爻变反吟** | 本卦内卦与之卦内卦互变 | 坤巽互变 |
| **外卦爻变反吟** | 本卦外卦与之卦外卦互变 | 同上 |
| **内卦伏吟** | 本卦内卦与之卦内卦互变 | 乾震互变 |
| **外卦伏吟** | 本卦外卦与之卦外卦互变 | 同上 |

### 2.11 本卦-之卦关系

| 关系类型 | 关系描述 | 关系规则 |
|---------|---------|---------|
| **本卦代码+之卦代码→爻变代码** | 按位异或运算 | 逐位相减取绝对值得到6位爻变代码 |
| **爻变代码→动爻/变爻** | 爻变代码为1的位置 | 本卦中对应爻位的爻为动爻<br>之卦中对应爻位的爻为变爻 |
| **无之卦** | 爻变代码为000000 | 所有爻为静爻 |

## 三、五行生克关系

### 3.1 五行相生
```
金生水 → 水生木 → 木生火 → 火生土 → 土生金
```

### 3.2 五行相克
```
金克木 → 木克土 → 土克水 → 水克火 → 火克金
```

### 3.3 生旺墓绝关系

| 地支五行 | 长生 | 帝旺 | 墓 | 绝 |
|---------|------|------|---|----|
| 寅卯(木) | 亥 | 卯 | 未 | 申 |
| 巳午(火) | 寅 | 午 | 戌 | 亥 |
| 申酉(金) | 巳 | 酉 | 丑 | 寅 |
| 亥子(水) | 申 | 子 | 辰 | 巳 |
| 丑辰未戌(土) | 申 | 子 | 辰 | 巳 |

**作用范围**: 动爻与变爻之间、飞神与伏神之间、爻支与日支之间。

## 五、完整关系网络图

```
时间输入
  ├── 公历年月日
  │     └── lunar-python → 干支时间(年柱、月柱、日柱)
  │           ├── 日干 → 六神(各爻位)
  │           │         └── 干禄(神煞)
  │           │         └── 羊刃(神煞)
  │           ├── 日支 → 旬空
  │           │       └── 驿马(神煞)
  │           │       └── 桃花(神煞)
  │           └── 年干 → (其他计算)

卦输入
  ├── 本卦(卦名)
  │     └── → 本卦代码(6位)
  │           ├── 前3位 → 内卦(单卦)
  │           │         └── → 初二三爻地支(纳甲装卦)
  │           │         └── → 内卦五行
  │           └── 后3位 → 外卦(单卦)
  │                     └── → 四五上爻地支(纳甲装卦)
  │                     └── → 外卦五行
  ├── 之卦(卦名)
  │     └── → 之卦代码(6位)
  │           └── (同本卦逻辑)
  └── 本卦+之卦 → 爻变代码
                  └── → 动爻/变爻识别

卦宫与卦理
  ├── 重卦 → 卦宫
  │         └── → 卦宫五行
  │         └── → 宫位
  │         └── → 世应爻位
  │         └── → 本宫卦(查伏神用)
  └── 六亲计算
      ├── 卦宫五行
      ├── 爻地支(纳甲装卦) → 爻地支五行
      └── 五行生克 → 六亲(父母、官鬼、子孙、妻财、兄弟)

神煞系统
  ├── 日干 → 干禄、羊刃
  ├── 日支 → 驿马、桃花
  └── 地支合冲 → 神煞传播

特殊关系
  ├── 反吟(易冒/爻变)
  │     └── 内卦/外卦互变关系
  ├── 伏吟
  │     └── 内卦/外卦乾震互变
  └── 伏神
        ├── 检查六亲齐全
        └── 本宫卦借爻

生旺墓绝
  └── 作用范围: 动爻-变爻、飞神-伏神、爻支-日支

特殊卦类
  ├── 六冲卦
  └── 六合卦
```

## 六、复杂检索可能的关系组合

基于以上关系图谱，复杂检索可以实现以下类型的查询：

### 6.1 单元素检索
- 按卦名查询（本卦、之卦）
- 按卦宫查询
- 按宫位查询（本宫、一世等）
- 按时间查询（公历/干支）
- 按特定神煞查询（如"带干禄"的卦例）
- 按特殊卦类查询（六冲/六合）

### 6.2 元素间关系检索
- 按地支相合/相冲查询
- 按五行生克关系查询（如"某五行克某五行"的爻）
- 按三合局查询
- 按生旺墓绝状态查询

### 6.3 复合条件检索
- 按六亲+地支查询（如"某地支为父母爻"）
- 按六神+爻位查询
- 按神煞+地支查询
- 按世应+六亲查询
- 按伏神+飞神关系查询
- 按反吟/伏吟状态查询
- 按动爻/变爻属性查询

### 6.4 时间相关检索
- 按旬空查询
- 按日干/日支范围查询
- 按神煞随时间变化查询

### 6.5 跨系统检索
- 结合卦宫+六亲+地支的查询
- 结合时间+神煞+六亲的查询
- 结合卦理+股票信息的查询（通过占问事由关键词）
