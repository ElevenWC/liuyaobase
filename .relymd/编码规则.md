## 二、干支规则系统

### 2.0/2.2 五行与五行生克
- 五行作为一种基本属性,需要用在很多地方,比如十二个地支分别属于不同的五行,八个单卦也属于不同的五行,六十四重卦也分属于不同的宫位从而有根本的五行属性参与六亲的运算
- 因此五行作为编码的基础,需要深入思考其编码方式
- 五行也就是木,火,土,金,水
```
生：金生水 → 水生木 → 木生火 → 火生土 → 土生金
克：金克木 → 木克土 → 土克水 → 水克火 → 火克金
```
- 以上为五行生克关系, 建议做成一个枚举类,可以快速判断五行之间的生克关系
- 对于其他需要用到五行生克关系的地方,需要将五行属性映射到所需的地方(如地支,单卦,重卦,三合局),其映射关系会在后面给出

- 需要将五行与地支之间的映射关系理清,从而能够判断地支之间,地支与其他有五行属性的元素的生克关系

## 三、重卦规则系统
本章将更加细致地介绍卦的基本原理,部分内容请参照前文与<基本规则.md>
以下我将介绍一些基本术语, 用以更好的了解六爻的基本规则

### 1.爻,阳爻,阴爻,动爻,静爻
- 爻是构成卦的基本单位.爻类型有两种,为阳爻和阴爻;爻状态有两种,为动爻和静爻.
- 因此爻的类型与状态相互组合就有四种,分别为动阳爻,动阴爻,静阳爻,静阴爻

### 2.八单卦与其单卦代码
- 三个爻按顺序构成单卦,构成单卦的爻没有状态区别,也就是不分动静
- 因此单卦一共有八种,如下表,按照(单卦名):(爻的类型)
```
乾:阳爻,阳爻,阳爻
震:阳爻,阴爻,阴爻
坎:阴爻,阳爻,阴爻
艮:阴爻,阴爻,阳爻
坤:阴爻,阴爻,阴爻
巽:阴爻,阳爻,阳爻
离:阳爻,阴爻,阳爻
兑:阳爻,阳爻,阴爻
```
- 所以,如果我们将阳爻存储为1,阴爻存储为0,那么乾的单卦代码就是111,震的就是100,以此类推
```
乾:111
震:100
坎:010
艮:001
坤:000
巽:011
离:101
兑:110
```

### 3.六十四重卦

#### 3.1 重卦的名称,重卦代码与爻位
- 八个单卦中任意两个或者自身相重叠,就得到了重卦,重卦共有六十四个
- 具体的重卦名称详见'基本规则.md'中的完整八宫卦序表
- 因此重卦也可以用代码来存储,比如乾为天的重卦代码就是111111,火天大有的就是111101,以此类推
- 因为每个数字都是代表一个爻的类型,我们给重卦中不同位置的爻也起了名字
- 从左到右分别是初爻,二爻,三爻,四爻,五爻,上爻. 称为爻位
- 我们使用火山旅001101来举例,其首位是0,就代表火山旅的初爻为阴爻
- 下面说是按照八宫顺序表利用数字来表示的六十四重卦的名称与重卦代码的一一对应

#### 3.2 卦宫,卦宫五行与宫位
- 以上卦序表每行以{卦宫(卦宫五行): 本宫卦、一世卦、二世卦、三世卦、四世卦、五世卦、游魂卦、归魂卦}的顺序排列
- 显然的,乾为天为本宫卦,宫位为本宫;雷风恒为三世卦,宫位为三世.
- 某一重卦为本宫卦和其宫位为本宫的说法完全等价,其余以此类推
- 卦宫五行前面已经说过
- 卦宫五行与宫位也是六十四重卦的重要属性,需要对每一个重卦加以映射

#### 3.3 世爻与应爻
- 在一个重卦的六个爻中,有两个爻会有爻位外地特殊属性,是世爻与应爻
- 世爻和应爻的爻位由该重卦所在的卦宫决定,如下表:
````
   - 本宫卦：世在上爻,应在三爻
   - 一世卦：世在初爻,应在四爻
   - 二世卦：世在二爻,应在五爻
   - 三世卦：世在三爻,应在上爻
   - 四世卦：世在四爻,应在初爻
   - 五世卦：世在五爻,应在二爻
   - 游魂卦：世在四爻,应在初爻
   - 归魂卦：世在三爻,应在上爻
````
- 举个例子,对于任意的游魂卦,如火地晋/地火明夷/风泽中孚/泽风大过...其世爻都是在四爻,应爻都是在初爻
- 世爻和应爻是重卦中爻的重要属性

#### 3.4 内卦与外卦
- 由于重卦是由两个单卦重叠而成的,所以我们给这两个单卦也赋予了不同的名字
- 对于一个重卦,我们将其重卦代码的前三位所形成的单卦代码对应的单卦称之为内卦,后三位所形成的单卦代码对应的单卦称之为外卦
- 内卦和外卦就是某一单卦,当后文出现内卦和外卦的时候,其含义与某一单卦是等价的
- 如风天小畜的重卦代码为111011,前三位为111,即内卦为乾,后三位为011,即外卦为巽.其余卦以此类推

#### 3.5 本卦,之卦,动爻,变爻与爻变代码
- 我们会以如下形式来利用重卦:
- 在输入的时候,会先输入一个重卦,再输入另一个重卦
- 首先是本卦,这是一个重卦,其一定存在
- 其次是之卦,这也是一个重卦,若没有输入则默认置空
- 因此输入的卦例有两种形式:其一是本卦之卦两个卦,其二是只有本卦一个卦,我们接下来来看前者这种情况
- 例如本卦是山火贲(101001),之卦是风火家人(101011),利用之卦与本卦的代码按位对位的相减再取绝对值,得到爻变代码000010
- 爻变代码000010是用以判断重卦中六个爻的状态的代码,第一位是0,代表初爻是静爻,第五位是1,代表五爻是动爻,以此类推
- 所以如果我们的输入是本卦卦名,之卦卦名的话,我们需要存储的是本卦代码,之卦代码和爻变代码
- 直接存储爻变代码的好处是可以直接获取动爻是哪一个爻(爻变代码中为1的爻位),这在实际应用是很常用的
- 利用爻变代码,可以知道动爻的爻位,在本卦中在此爻位上的爻就是动爻,而在之卦中在此爻位上的爻为变爻
- 变爻与动爻一一对应
- 当输入的卦例是只有本卦的情况时,爻变代码就默认是000000,即所有爻都是静爻
- 在以下的叙述中,卦之间的变化我会使用<之>,比如本卦是山泽损,之卦是火泽睽,我会表述为<山泽损之火泽睽>

#### 3.6 爻与地支的对应关系(纳甲装卦规则)
- 在重卦中,一共有64*6个爻,每个爻都对应着十二地支中的某个地支,这个映射关系是不会改变的
- 爻与地支之间的映射关系由该重卦的内卦与外卦分别是是哪个单卦所决定
- 具体的决定关系见下表
```
基本形式:
内卦:初爻地支,二爻地支,三爻地支
外卦:四爻地支,五爻地支,上爻地支

具体映射:
乾卦（内卦）：子、寅、辰
乾卦（外卦）：午、申、戌

坎卦（内卦）：寅、辰、午
坎卦（外卦）：申、戌、子

艮卦（内卦）：辰、午、申
艮卦（外卦）：戌、子、寅

震卦（内卦）：子、寅、辰
震卦（外卦）：午、申、戌

巽卦（内卦）：丑、亥、酉
巽卦（外卦）：未、巳、卯

离卦（内卦）：卯、丑、亥
离卦（外卦）：酉、未、巳

坤卦（内卦）：未、巳、卯
坤卦（外卦）：丑、亥、酉

兑卦（内卦）：巳、卯、丑
兑卦（外卦）：亥、酉、未
```
- 对于任意重卦,其六个爻的地支自始至终是固定的,可以在运算后固定存储
- 例如,对于泽水困,其代码为010110,其内卦代码为010,为坎,那么它的初爻地支就是寅,二爻地支就是辰,三爻地支就是午
- 其外卦代码为110,为兑,那么它的四爻地支就是亥,五爻地支就是酉,上爻地支就是未
- 其余卦依次类推
- 无论何时,无论某一重卦是本卦还是之卦,其任意一爻的地支都不会变化,无论这个爻是动爻还是静爻,又或者是变爻

#### 3.7 本卦-之卦系统中的爻的属性(六亲生成规则)
- 当我们利用重卦的时候,是输入本卦和之卦来利用的(之卦置空的情况也算在内)(当然还有其他参数,之后再说)
- 本卦有一个属性是卦宫五行,而本卦的所有爻和本质上是属于之卦的变爻都对应着地支,而地支也具有五行属性
- 因此每一个爻的五行属性也可以确定,我们称之为爻地支五行
- 通过判断卦宫五行和爻地支五行之间的生克关系可以得到在此也仅限于此本卦-之卦系统中的爻(本卦中的爻和变爻)的属性,我们称为六亲
- 六亲这个爻属性包含五个元素:父母,官鬼,子孙,妻财,兄弟.其判断规则如下:
````
爻地支五行生卦宫五行：父母
爻地支五行克卦宫五行：官鬼
卦宫五行生爻地支五行：子孙
卦宫五行克爻地支五行：妻财
卦宫五行与爻地支五行相同：兄弟
````
- 例如山泽损(110001)之火泽睽(110101),在这里本卦的六个爻从初爻到上爻对应地支分别为[巳,卯,丑,戌,子,寅],五行分别为[火,木,土,土,水,木]
- 我们可以知道爻变代码为000100,那么变爻就是火泽睽的四爻,其对应地支为酉,五行为金
- 山泽损所属卦宫为艮宫,其卦宫五行为土
- 根据上述判断规则,可以得到本卦六个爻从初爻到上爻的六亲属性为[父母,官鬼,兄弟,兄弟,妻财,官鬼]
- 变爻的六亲属性为子孙
- 当有多个动爻导致有多个变爻时,也一样来判断

#### 3.8 伏神规则
- 当我们确定了本卦六个爻的六亲属性之后,需要判断这六个六亲中是否包含了所有的六亲,即父母,官鬼,子孙,妻财,兄弟全部都有
- 若全部都有,那么之后的步骤不需要做;若其中缺少了至少一个六亲,那么需要进行如下的操作
- 在与本卦相同卦宫的本宫卦中检查各个爻的六亲属性,查找本卦缺少的六亲属性对应的一个或更多的爻
- 记录这个爻的爻位,爻地支与六亲属性,我们称这样的一个或更多的爻为伏神
- 与这个爻爻位相同的本卦中的爻称为飞神
- 建议将八个本宫卦的六亲属性固定存储,以便于直接查找
- 例如,本卦为山泽损(110001),卦宫为艮宫,从初爻到上爻的六亲属性为[父母,官鬼,兄弟,兄弟,妻财,官鬼],经检查其中缺少了子孙这个六亲
- 所以我们检查艮宫的本宫卦艮为山(001001),其从初爻到上爻的六亲属性为[兄弟,父母,子孙,兄弟,妻财,官鬼]
- 其中六亲属性为子孙的爻的爻位为三爻,爻地支为申,所以我们称这个属性为[三爻,申,子孙]的爻为伏神
- 而本卦中处于三爻爻位的属性为[三爻,兄弟,丑]的爻为飞神

#### 3.9反吟伏吟规则
- 以下的易冒反吟,爻变反吟和伏吟是本卦-之卦对的属性,只有存在本卦-之卦对的时候才需要判断
- 1.反吟
- 反吟分为两种,分别是易冒反吟和爻变反吟,我们来分别判断
- 1.1 易冒反吟
- 易冒反吟是通过比较本卦内卦与之卦内卦,本卦外卦与之卦外卦之间是否为以下这四种情况之一来判断的
```
   乾巽互变(所谓互变,就是本卦内/外卦为乾,之卦内/外卦为巽符合情况,本卦内/外卦为巽,之卦内/外卦为乾也符合情况)
   坎离互变
   艮坤互变
   震兑互变
```
- 比如若本卦内卦为乾,之卦内卦为巽,则称为内卦易冒反吟;若本卦外卦为巽,之卦外卦为乾,则称之为外卦易冒反吟
- 比如火天大有(111101)之水天需(111010),本卦外卦为101,为离,之卦外卦为010,为坎,符合坎离互变,则为外卦易冒反吟
- 而火天大有(111101)之火风鼎(011101),本卦内卦为111,为乾,之卦内卦为011,为巽,符合乾巽互变,则为内卦易冒反吟

- 1.2 爻变反吟
- 爻变反吟与易冒反吟类似,但是只有这一种判断情况
````
坤巽互变
````
- 比如若本卦内卦为坤,之卦内卦为巽,则称为内卦爻变反吟;若本卦外卦为巽,之卦外卦为坤,则称之为外卦爻变反吟
- 比如火风鼎(011101)之火地晋(000101),本卦内卦为011巽,之卦内卦为000坤,符合坤巽互变,为内卦爻变反吟
- 而地水师(010000)之风水涣(010011),本卦外卦为000坤,之卦外卦为011巽,符合坤巽互变,为外卦爻变反吟

- 2.伏吟
- 伏吟也与易冒反吟类似,但是只有这一种判断情况
````
乾震互变
````
- 参考上面两种很容易理解伏吟
- 比如水雷屯(100010)之水天需(111010)是内卦伏吟,雷风恒(011100)之天风姤(011111)是外卦伏吟

#### 3.10 六冲卦和六合卦判断
- 六冲卦和六合卦是六十四重卦中的特殊类型,是属于重卦的特殊属性,独立于这个重卦是本卦还是之卦之外
- 具体有哪些重卦是六冲卦,哪些是六合卦请参考<基本规则.md>中的同名章节
- 即六十四重卦除了根据宫位分成八组外有了另一种分类,即六冲卦,六合卦,普通卦
- 但是存储只需要存储六冲卦和六合卦即可

#### 3.11 六神排列规则
- 我们输入卦例时,除了会输入本卦,之卦之外,还会输入并存储一个年月日的时间
- 年月日的时间需要存储两份,分别是公历的表示和转换后的干支的表示
- 转换后的干支表示中的日称为日柱,日柱中包含日的天干和日的地支,我们在这里只取日干
- 在日干不同时,本卦中不同的爻位也会有不同的属性,我们称这种属性为六神
- 六神一共有六种,根据日干的不同这六种六神分别对应不同的爻位,具体如下
```
日干为甲或乙：初爻青龙,二爻朱雀,三爻勾陈,四爻螣蛇,五爻白虎,上爻玄武
日干为丙或丁：初爻朱雀,二爻勾陈,三爻螣蛇,四爻白虎,五爻玄武,上爻青龙
日干为戊：初爻勾陈,二爻螣蛇,三爻白虎,四爻玄武,五爻青龙,上爻朱雀
日干为己：初爻螣蛇,二爻白虎,三爻玄武,四爻青龙,五爻朱雀,上爻勾陈
日干为庚或辛：初爻白虎,二爻玄武,三爻青龙,四爻朱雀,五爻勾陈,上爻螣蛇
日干为壬或癸：初爻玄武,二爻青龙,三爻朱雀,四爻勾陈,五爻螣蛇,上爻白虎
```
- 如在丁巳日的任意本卦,其初爻到上爻对应的六神为[朱雀,勾陈,螣蛇.白虎,玄武,青龙]

## 四、神煞规则系统
- 神煞是地支的属性,根据输入卦例的日干或者日支来判断哪些地支具有哪种神煞属性
- 地支的神煞属性并非地支五行那样的固定属性,而是根据输入卦例的日柱不同而改变的属性
- 当某一地支在一个卦例中具有某种神煞属性,即神煞1是地支1(我们赋予地支1'是神煞1'的属性)时,存在与地支1有'冲'的关系的地支2以及与地支1有'合'的关系的地支3
- 地支1,地支2,地支3都具有一个共同的属性叫做'带神煞1'
- 因此神煞属性是两步运算,第一步通过神煞1的判断条件找到地支1,并给地支1赋予'是神煞1'的属性;第二步通过地支1与其他地支的合冲关系找到地支2,地支3
- 最后给找到的这三个地支赋予'带神煞1'的属性
- 以下为神煞的判断条件

### 4.1 干禄
- 干禄为一种神煞属性,根据卦例的日干来判断,规则如下
```
甲禄在寅(日干为甲时地支寅是干禄)，乙禄在卯
丙戊禄在巳(日干为丙或戊时地支巳是干禄)，丁己禄在午
庚禄在申，辛禄在酉
壬禄在亥，癸禄在子
```
- 在规则中的第一句解释了规则意思,应该可以看懂,之后的神煞也会这么解释

### 4.2 驿马
- 驿马为一种神煞属性,根据卦例的日支来判断,规则如下
```
申子辰日：驿马在寅(日支为申或子或辰时地支寅是驿马)
亥卯未日：驿马在巳
寅午戌日：驿马在申
巳酉丑日：驿马在亥
```

### 4.3 羊刃
- 羊刃为一种神煞属性,根据卦例的日干来判断,规则如下
```
甲刃在卯(日干为甲时地支卯是羊刃)，乙刃在寅
丙戊刃在午(日干为丙或戊时地支午是羊刃)，丁己刃在巳
庚刃在酉，辛刃在申
壬刃在子，癸刃在亥
```
### 4.4 桃花
- 桃花为一种神煞属性,根据卦例的日支来判断,规则如下
```
申子辰日：桃花在酉(日支为申或子或辰时地支酉是桃花)
亥卯未日：桃花在子
寅午戌日：桃花在卯
巳酉丑日：桃花在午
```
