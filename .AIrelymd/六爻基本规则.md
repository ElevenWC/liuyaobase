# 六爻基本规则汇总

> 本文档整理了六爻预测学的所有核心知识规则，供系统开发参考。
> 每个知识点均配有具体示例，便于理解与验证。

---

## 一、时间系统

### 1.1 公历转干支

**规则**：使用lunar-python库将公历年月日转换为干支表示（年柱、月柱、日柱）。
- 年柱 = 年干 + 年支（如：甲子）
- 月柱 = 月干 + 月支（如：丙寅）
- 日柱 = 日干 + 日支（如：戊辰）

**术语说明**：
- "柱"：干支组合，如"甲子"为一柱
- "干"：天干，如日干指日柱的天干
- "支"：地支，如日支指日柱的地支

**示例**：
```
公历 2025年3月25日 → lunar-python转换 →
年柱：乙巳
月柱：己卯
日柱：甲午
日干：甲
日支：午
```

---

### 1.2 旬空计算

**规则**：根据日柱所在的旬来判断哪两个地支为"空"。

**旬空表**：
```
甲子旬（甲子、乙丑、丙寅、丁卯、戊辰、己巳、庚午、辛未、壬申、癸酉）：戌亥空
甲戌旬：申酉空
甲申旬：午未空
甲午旬：辰巳空
甲辰旬：寅卯空
甲寅旬：子丑空
```

**示例**：
```
日柱为甲午，属于甲午旬 → 旬空为辰、巳
即该日辰、巳两个地支为"空亡"

日柱为乙巳，属于甲辰旬 → 旬空为寅、卯
即该日寅、卯两个地支为"空亡"
```

### 2.5 地支三合局

**规则**：三个地支合成一个五行局。

**三合局表**：
```
申子辰合水局
亥卯未合木局
寅午戌合火局
巳酉丑合金局
```

**示例**：
```
若卦中有申、子、辰三个地支的爻（不论位置），则成"水局"
若日支为申，卦中有子、辰两个地支，也成"水局"
实际应用：水泽节卦中，二爻辰、四爻申、初爻寅，其中辰申与日支若为子，则三合成水局
```

### 2.6 生旺墓绝

**规则**：根据地支五行，判断其处于十二长生中的哪个阶段。主要使用长生、帝旺、墓、绝四个阶段。

**生旺墓绝表**：
| 地支五行 | 长生 | 帝旺 | 墓 | 绝 |
|---------|------|------|---|----|
| 木（寅卯） | 亥 | 卯 | 未 | 申 |
| 火（巳午） | 寅 | 午 | 戌 | 亥 |
| 金（申酉） | 巳 | 酉 | 丑 | 寅 |
| 水（亥子） | 申 | 子 | 辰 | 巳 |
| 土（丑辰未戌） | 申 | 子 | 辰 | 巳 |

**作用范围**：动爻与变爻之间、飞神与伏神之间、爻支与日支之间。

**示例**：
```
某爻地支为寅（木），日支为亥 → 木长生于亥，该爻"临长生"
某爻地支为申（金），日支为巳 → 金长生于巳，该爻"临长生"
动爻地支为酉（金），变爻地支为丑 → 金墓于丑，变爻"入墓"于动爻
注意:我们只看变爻是不是动爻的生旺墓绝,飞神是不是伏神的生旺墓绝,日支是不是爻支的生旺墓绝,不会反过来看
```

## 四、卦象系统

### 4.1 八单卦

**规则**：三个爻构成一个单卦，共有八种。

**八单卦代码表**：
| 单卦 | 代码 | 爻构成 |
|-----|------|--------|
| 乾 | 111 | 阳阳阳 |
| 兑 | 110 | 阳阳阴 |
| 离 | 101 | 阳阴阳 |
| 震 | 100 | 阳阴阴 |
| 巽 | 011 | 阴阳阳 |
| 坎 | 010 | 阴阳阴 |
| 艮 | 001 | 阴阴阳 |
| 坤 | 000 | 阴阴阴 |

**示例**：
```
乾卦 = 111 = 阳爻 + 阳爻 + 阳爻（从下到上）
震卦 = 100 = 阳爻 + 阴爻 + 阴爻
巽卦 = 011 = 阴爻 + 阳爻 + 阳爻
```

---

### 4.2 八单卦五行

**规则**：每个单卦对应一个五行属性。

| 单卦 | 五行 |
|-----|------|
| 坎 | 水 |
| 震、巽 | 木 |
| 离 | 火 |
| 乾、兑 | 金 |
| 坤、艮 | 土 |

**示例**：
```
坎卦 → 五行为水
离卦 → 五行为火
乾卦 → 五行为金
震卦、巽卦 → 五行均为木
```

---

### 4.3 六十四重卦与代码

**规则**：两个单卦重叠构成重卦，共64种。重卦代码为6位二进制，前3位为内卦代码，后3位为外卦代码。

**示例**：
```
乾为天 = 111111（内卦乾111 + 外卦乾111）
坤为地 = 000000（内卦坤000 + 外卦坤000）
```

**示例（续）**：
```
水火既济 = 101010（内卦离101 + 外卦坎010）
解析：水火既济，坎上离下，内卦（下卦）为离，外卦（上卦）为坎
验证：离=101，坎=010，组合为101010 ✓

天火同人 = 101111（内卦离101 + 外卦乾111）
解析：天火同人，乾上离下，内卦（下卦）为离，外卦（上卦）为乾
验证：离=101，乾=111，组合为101111 ✓
```

**注意**：代码从左到右代表初爻到上爻。

---

### 4.4 内卦与外卦

**规则**：
- 内卦：重卦代码前3位对应的单卦，代表初爻、二爻、三爻
- 外卦：重卦代码后3位对应的单卦，代表四爻、五爻、上爻

**示例**：
```
风天小畜 = 111011
- 前3位：111 → 内卦为乾
- 后3位：011 → 外卦为巽
- 该卦可称为"巽上乾下"或"风天小畜"

火地晋 = 000101
- 前3位：000 → 内卦为坤
- 后3位：101 → 外卦为离
- 该卦可称为"离上坤下"或"火地晋"
```

## 五、爻系统

### 5.1 爻位与爻类型

**规则**：
- 爻位：初爻、二爻、三爻、四爻、五爻、上爻（共6个位置）
- 爻类型：阳爻（用1表示）、阴爻（用0表示）

**示例**：
```
火天大有 111101：
解析：火天大有，离上乾下，内卦为乾，外卦为离
代码：前3位111（内卦乾）+ 后3位101（外卦离）= 111101

爻位分解（从左到右 = 初爻到上爻）：
- 初爻：1（阳爻）
- 二爻：1（阳爻）
- 三爻：1（阳爻）  ← 以上三爻构成内卦乾
- 四爻：1（阳爻）
- 五爻：0（阴爻）
- 上爻：1（阳爻）  ← 以上三爻构成外卦离
```

---

### 5.2 爻状态（动静）

**规则**：
- 静爻：不动的爻
- 动爻：本卦中发生变化的爻
- 变爻：之卦中对应动爻变化后的爻

**爻状态组合**：
| 组合 | 说明 |
|-----|------|
| 静阳爻 | 不动的阳爻 |
| 静阴爻 | 不动的阴爻 |
| 动阳爻 | 要变的阳爻（阳变阴） |
| 动阴爻 | 要变的阴爻（阴变阳） |

---

### 5.3 爻变代码

**规则**：用6位二进制表示哪些爻在变化。1表示动爻，0表示静爻。爻变代码 = 本卦代码 与 之卦代码 按位取差的绝对值。

**计算公式**：爻变代码 = abs(本卦代码 - 之卦代码) 逐位运算

**示例**：
```
本卦：山火贲 101001
之卦：风火家人 101011

计算：
  1 0 1 0 0 1  (本卦)
- 1 0 1 0 1 1  (之卦)
─────────────
  0 0 0 0 1 0  (按位差的绝对值)

爻变代码 = 000010
含义：第五位为1，表示五爻是动爻

本卦五爻为阴爻(0)，之卦五爻为阳爻(1)，五爻由阴变阳
```

**无之卦的情况**：
```
若只有本卦无之卦，则爻变代码 = 000000
表示所有爻都是静爻
```

### 5.4 纳甲装卦（爻配地支）

**规则**：每个爻根据其所在单卦（内卦或外卦）配置对应的地支。爻的地支是固定的，不会变化。

**纳甲地支表**：
| 单卦 | 内卦（初二三爻） | 外卦（四五上爻） |
|-----|-----------------|-----------------|
| 乾 | 子、寅、辰 | 午、申、戌 |
| 坎 | 寅、辰、午 | 申、戌、子 |
| 艮 | 辰、午、申 | 戌、子、寅 |
| 震 | 子、寅、辰 | 午、申、戌 |
| 巽 | 丑、亥、酉 | 未、巳、卯 |
| 离 | 卯、丑、亥 | 酉、未、巳 |
| 坤 | 未、巳、卯 | 丑、亥、酉 |
| 兑 | 巳、卯、丑 | 亥、酉、未 |

**示例**：
```
泽水困 010110：
- 内卦代码010 = 坎 → 初爻寅、二爻辰、三爻午
- 外卦代码110 = 兑 → 四爻亥、五爻酉、上爻未

完整爻地支：
- 初爻：寅
- 二爻：辰
- 三爻：午
- 四爻：亥
- 五爻：酉
- 上爻：未
```

**重要原则**：无论何时，无论该爻是动爻、静爻还是变爻，其地支都不会变化。

### 5.5 六亲生成

**规则**：根据卦宫五行与爻地支五行的生克关系确定六亲属性。

**六亲**：父母、官鬼、子孙、妻财、兄弟

**判断规则**：
| 关系 | 六亲 |
|-----|------|
| 爻地支五行 生 卦宫五行 | 父母 |
| 爻地支五行 克 卦宫五行 | 官鬼 |
| 卦宫五行 生 爻地支五行 | 子孙 |
| 卦宫五行 克 爻地支五行 | 妻财 |
| 卦宫五行 = 爻地支五行 | 兄弟 |

**示例**：
```
卦例：天风姤 011111（乾宫，卦宫五行为金）

纳甲地支：初爻丑、二爻亥、三爻酉、四爻午、五爻申、上爻戌
地支五行：土、水、金、火、金、土

六亲计算：
- 初爻丑（土）：土生金（爻生宫）→ 父母
- 二爻亥（水）：金生水（宫生爻）→ 子孙
- 三爻酉（金）：金=金（宫=爻）→ 兄弟
- 四爻午（火）：火克金（爻克宫）→ 官鬼
- 五爻申（金）：金=金（宫=爻）→ 兄弟
- 上爻戌（土）：土生金（爻生宫）→ 父母

结果：[父母, 子孙, 兄弟, 官鬼, 兄弟, 父母]
```

**变爻六亲**：
```
山泽损 110001 之 火泽睽 110101
- 爻变代码：000100，四爻动
- 变爻为火泽睽的四爻，地支为酉，五行为金
- 本卦卦宫为艮宫，五行为土
- 金泄土（爻生宫的反向）→ 土生金 → 子孙

变爻六亲为：子孙
```

**六神起法表**：

|-----|------|------|------|------|------|------|
| 甲、乙 | 青龙 | 朱雀 | 勾陈 | 螣蛇 | 白虎 | 玄武 |
| 丙、丁 | 朱雀 | 勾陈 | 螣蛇 | 白虎 | 玄武 | 青龙 |
| 戊 | 勾陈 | 螣蛇 | 白虎 | 玄武 | 青龙 | 朱雀 |
| 己 | 螣蛇 | 白虎 | 玄武 | 青龙 | 朱雀 | 勾陈 |
| 庚、辛 | 白虎 | 玄武 | 青龙 | 朱雀 | 勾陈 | 螣蛇 |
| 壬、癸 | 玄武 | 青龙 | 朱雀 | 勾陈 | 螣蛇 | 白虎 |

**示例**：
```

- 初爻：青龙

- 三爻：勾陈
- 四爻：螣蛇
- 五爻：白虎

日干为庚或辛日：
- 初爻：白虎
- 二爻：玄武
```

## 六、伏神系统

### 6.1 增删伏神（本宫借爻）

**规则**：当本卦六爻的六亲属性不完整（缺少某个六亲）时，从本宫的本宫卦中借入缺失的六亲爻。

**查找步骤**：
1. 检查本卦六个爻的六亲是否包含全部五种（父母、官鬼、子孙、妻财、兄弟）
2. 若缺某种六亲，查同宫的本宫卦
3. 本宫卦中该六亲对应的爻即为伏神
4. 本卦中与伏神相同爻位的爻为飞神

**示例**：
```
卦例：天风姤（乾宫）

天风姤六亲：[父母, 子孙, 兄弟, 官鬼, 兄弟, 父母]
检查：有父母、子孙、兄弟、官鬼，缺少"妻财"

查乾宫本宫卦（乾为天）的六亲：
乾为天纳甲：子、寅、辰、午、申、戌
乾为天六亲：[子孙, 妻财, 兄弟, 父母, 兄弟, 父母]
其中二爻寅木为妻财

因此：
- 伏神：二爻，寅木，妻财
- 飞神：天风姤二爻，亥水，子孙
- 飞神与伏神同在二爻位，形成"飞伏"关系
```

### 6.2 易冒伏神规则

**规则**：另一种伏神取法，遵循"阴阳相互，前后相从"原则。

**取法规则**：
```
1. 八纯卦（本宫卦）：两两阴阳互伏
   - 乾伏坤、坤伏乾
   - 震伏巽、巽伏震
   - 坎伏离、离伏坎
   - 艮伏兑、兑伏艮

2. 一世卦至五世卦：皆以本宫首卦为伏

3. 游魂卦：
   - 外卦：伏于五世卦的外卦
   - 内卦：伏于本宫首卦的对宫卦的内卦

4. 归魂卦：
   - 外卦：伏本宫首卦
   - 内卦：伏本宫首卦的对宫卦
```

**示例**：
```
乾宫游魂卦 - 火地晋：
- 外卦离（101）→ 伏山地剥的外卦艮（001）
- 内卦坤（000）→ 伏坤的对宫乾（111）的内卦
- 综合伏神：山天大畜

乾宫归魂卦 - 火天大有：
- 外卦离（101）→ 伏乾的外卦乾（111）
- 内卦乾（111）→ 伏乾的对宫坤（000）的内卦
- 综合伏神：天地否
```
