# 六爻知识处理注意事项与自检提示词

> 本文档记录在处理六爻相关知识时容易犯的错误及注意事项，
> 用于提醒自己避免重复犯错。

---

## 一、核心概念辨析（最重要）

### 1.1 内卦与外卦

**⚠️ 易错点**：内外卦的概念容易混淆！

| 概念 | 等价称呼 | 包含爻位 | 代码位置 |
|------|---------|---------|---------|
| **内卦** | 下卦 | 初爻、二爻、三爻 | 代码**前3位** |
| **外卦** | 上卦 | 四爻、五爻、上爻 | 代码**后3位** |

**记忆口诀**：内下前，外上后
- 内卦 = 下卦 = 前三位
- 外卦 = 上卦 = 后三位

**自检提示词**：
```
当我写"内卦"时，问自己：
1. 内卦是上卦还是下卦？答：下卦
2. 内卦包含哪些爻？答：初、二、三爻
3. 内卦在代码的哪个位置？答：前3位
```

---

### 1.2 卦名解读规则

**规则**：卦名"XY"的格式中，**X在上（外卦），Y在下（内卦）**

**示例解析**：
| 卦名 | X（上/外卦） | Y（下/内卦） | 内卦代码 | 外卦代码 | 完整代码 |
|------|-------------|-------------|---------|---------|---------|
| 水火既济 | 水=坎 | 火=离 | 离=101 | 坎=010 | 101010 |
| 天火同人 | 天=乾 | 火=离 | 离=101 | 乾=111 | 101111 |
| 风火家人 | 风=巽 | 火=离 | 离=101 | 巽=011 | 101011 |
| 火天大有 | 火=离 | 天=乾 | 乾=111 | 离=101 | 111101 |
| 水泽节 | 水=坎 | 泽=兑 | 兑=110 | 坎=010 | 110010 |

**自检提示词**：
```
当我看到"XY"卦名时：
1. X是什么卦？X在上（外卦），代码在后3位
2. Y是什么卦？Y在下（内卦），代码在前3位
3. 组合时：内卦代码 + 外卦代码 = 前三位 + 后三位
```

---

## 二、代码与爻位对应

### 2.1 爻位读取规则

**⚠️ 易错点**：代码位序与爻位的对应关系！

**规则**：6位代码从**左到右**依次代表**初爻到上爻**

```
代码位序：  [1] [2] [3] [4] [5] [6]
            ↓   ↓   ↓   ↓   ↓   ↓
爻位：     初爻 二爻 三爻 四爻 五爻 上爻
```

**示例**：
```
火天大有 111101：
- 第1位=1 → 初爻阳爻
- 第2位=1 → 二爻阳爻
- 第3位=1 → 三爻阳爻
- 第4位=1 → 四爻阳爻
- 第5位=0 → 五爻阴爻  ← 注意！
- 第6位=1 → 上爻阳爻
```

**自检提示词**：
```
当我读取爻位时：
1. 代码第几位对应什么爻？第n位对应第n爻
2. 初爻在代码哪里？最左边（第1位）
3. 上爻在代码哪里？最右边（第6位）
```

---

### 2.2 八单卦代码速查

| 单卦 | 代码 | 记忆法 |
|------|------|--------|
| 乾 | 111 | 三阳 |
| 兑 | 110 | 上缺（下两阳） |
| 离 | 101 | 中虚（中阴） |
| 震 | 100 | 仰盂（上一阳下两阴） |
| 巽 | 011 | 下断（下一阴上两阳） |
| 坎 | 010 | 中满（中阳） |
| 艮 | 001 | 覆碗（上一阴下两阳） |
| 坤 | 000 | 三阴 |

## 三、纳甲装卦

### 3.1 查表原则

**⚠️ 易错点**：内卦和外卦使用不同的纳甲表！

**规则**：
- 内卦（初二三爻）→ 查"内卦"列
- 外卦（四五上爻）→ 查"外卦"列

**纳甲速查表**：
| 单卦 | 内卦（初二三） | 外卦（四五上） |
|------|---------------|---------------|
| 乾 | 子、寅、辰 | 午、申、戌 |
| 坎 | 寅、辰、午 | 申、戌、子 |
| 艮 | 辰、午、申 | 戌、子、寅 |
| 震 | 子、寅、辰 | 午、申、戌 |
| 巽 | 丑、亥、酉 | 未、巳、卯 |
| 离 | 卯、丑、亥 | 酉、未、巳 |
| 坤 | 未、巳、卯 | 丑、亥、酉 |
| 兑 | 巳、卯、丑 | 亥、酉、未 |

**完整装卦示例**：
```
天火同人 101111：
- 解析：乾上离下，内卦离，外卦乾
- 内卦离（初二三爻）：卯、丑、亥
- 外卦乾（四五上爻）：午、申、戌
- 完整地支：初卯、二丑、三亥、四午、五申、上戌
```

**自检提示词**：
```
当我进行纳甲装卦时：
1. 先确定内卦是什么单卦？（下卦）
2. 先确定外卦是什么单卦？（上卦）
3. 内卦查"内卦"列，外卦查"外卦"列
4. 装完后验证：乾震纳甲相同，坤兑相似
```

## 四、互卦计算

### 4.1 互卦取爻规则

**规则**：
- 互卦内卦 = 原卦的**二、三、四**爻
- 互卦外卦 = 原卦的**三、四、五**爻

**示例**：
```
原卦：水泽节 110010
爻位：初1、二1、三0、四0、五1、上0

互卦内卦（二三四爻）：1、0、0 → 100 → 震卦
互卦外卦（三四五爻）：0、1、0 → 010 → 坎卦

互卦 = 坎上震下 = 010100 = 雷水解
```

**自检提示词**：
```
当我计算互卦时：
1. 互卦内卦取哪几爻？二、三、四爻
2. 互卦外卦取哪几爻？三、四、五爻
3. 取爻顺序是否正确？按原卦顺序取，不要颠倒
```

## 五、六亲计算

### 5.1 六亲判断规则

**⚠️ 易错点**：六亲是根据"爻地支五行"与"卦宫五行"的关系判断的！

**规则表**：
| 关系 | 六亲 |
|------|------|
| 爻地支五行 **生** 卦宫五行 | 父母 |
| 爻地支五行 **克** 卦宫五行 | 官鬼 |
| 卦宫五行 **生** 爻地支五行 | 子孙 |
| 卦宫五行 **克** 爻地支五行 | 妻财 |
| 卦宫五行 **=** 爻地支五行 | 兄弟 |

**计算步骤**：
1. 确定本卦的卦宫五行
2. 纳甲装卦，得到每个爻的地支
3. 查地支五行表，得到每个爻地支的五行
4. 对比爻地支五行与卦宫五行，判断六亲

**自检提示词**：
```
当我计算六亲时：
1. 卦宫五行是什么？
2. 该爻地支五行是什么？
3. 谁生谁？谁克谁？
   - 爻生宫 = 父母
   - 爻克宫 = 官鬼
   - 宫生爻 = 子孙
   - 宫克爻 = 妻财
   - 宫=爻 = 兄弟
```

## 六、反吟伏吟

### 6.1 判断规则

**易冒反吟**：乾巽互变、坎离互变、艮坤互变、震兑互变
**爻变反吟**：坤巽互变
**伏吟**：乾震互变

**注意**：比较的是**本卦与之卦**的内卦/外卦变化！

**自检提示词**：
```
当我判断反吟伏吟时：
1. 比较的是什么？本卦与之卦
2. 内卦比较：本卦内卦 vs 之卦内卦
3. 外卦比较：本卦外卦 vs 之卦外卦
4. 是否符合互变规则？
```

## 七、验证检查清单

在完成任何六爻计算后，请按以下清单自检：

### 7.1 代码验证
- [ ] 内外卦是否正确？（内=下，外=上）
- [ ] 代码位序是否正确？（左=初，右=上）
- [ ] 与八宫卦序表是否一致？

### 7.2 纳甲验证
- [ ] 内卦是否查"内卦"列？
- [ ] 外卦是否查"外卦"列？
- [ ] 地支顺序是否正确？

### 7.3 六亲验证
- [ ] 卦宫五行是否正确？
- [ ] 地支五行是否正确？
- [ ] 生克关系判断是否正确？

### 7.4 整体一致性验证
- [ ] 同一卦的内卦代码与纳甲地支是否对应？
- [ ] 六亲结果是否覆盖了所有五种（或判断缺少哪种）？

## 八、常见错误模式

| 错误类型 | 表现 | 原因 | 修正方法 |
|---------|------|------|---------|
| 内外卦颠倒 | 代码、纳甲全错 | 把内卦当上卦 | 记住：内=下=前三位 |
| 爻位错位 | 爻类型判断错误 | 代码位序搞反 | 记住：左=初，右=上 |
| 纳甲查错表 | 地支错误 | 内外卦用错表 | 先定内外卦，再查对应列 |
| 六亲算错 | 全部六亲错误 | 生克关系搞反 | 明确"谁对谁"的关系 |

---

## 九、关键记忆点

1. **内卦=下卦=初二三爻=代码前3位**
2. **外卦=上卦=四五上爻=代码后3位**
3. **卦名XY：X在上外，Y在下内**
4. **代码从左到右=从初到上**
5. **纳甲分内外，查表要分清**
6. **六亲看生克，先定谁是主**

## 十、第二次修正经验（重点！）

### 10.1 互卦取爻必须用"第n位"

**⚠️ 极易错点**：描述"取三四五爻"时，容易误取！

**错误做法**：
```
说"取三四五爻"，误以为是代码的第3、4、5个值
实际：应该是原卦的第3位、第4位、第5位
```

**正确做法**：用**第n位**来描述，而不是用爻名
```
水泽节 110010
互卦外卦（取三四五爻）：
- 正确：第3位0、第4位0、第5位1 → 001 → 艮卦
- 错误：0、1、0 → 010 → 坎卦（把位置搞混了）
```

**自检提示词**：
```
当我取互卦爻位时：
1. 说"取二三四爻" = 取第2位、第3位、第4位的值
2. 说"取三四五爻" = 取第3位、第4位、第5位的值
3. 取完后验证：3个值组成的新代码对应什么单卦？
```

---

### 10.1.1 互卦代码组合顺序（新增！）

**⚠️ 极易错点**：互卦代码 = 内卦代码 + 外卦代码，**不是反过来**！

**规则**：所有重卦代码都是 **前3位=内卦（下卦），后3位=外卦（上卦）**

**错误示例**：
```
互卦内卦 = 震 = 100
互卦外卦 = 艮 = 001
❌ 错误：互卦代码 = 001100（把外卦放前面了）
✓ 正确：互卦代码 = 100001（内卦在前，外卦在后）

记忆：代码从左到右 = 从下到上 = 从内到外
```

**验证方法**：
```
互卦代码 = 100001
前3位 = 100 = 震 = 内卦（下卦）→ 在下 ✓
后3位 = 001 = 艮 = 外卦（上卦）→ 在上 ✓
卦名：艮上震下 = 山雷颐 ✓
```

**最佳实践：直接用代码查表，不要用"X上Y下"推导卦名**

**反面教材**：
```
❌ 错误方式：
- 内卦离101，外卦巽011
- 推导：巽上离下 → 火风鼎 ← 卦名推导错了！

✓ 正确方式：
- 内卦离101，外卦巽011
- 代码 = 101 + 011 = 101011
- 直接查表：101011 = 风火家人 ✓

说明：火风鼎的代码是011101，不是101011！
```

**自检提示词**：
```
当我得到互卦代码后：
1. 直接用完整6位代码查八宫卦序表
2. 得到卦名
3. 不要用"X上Y下"的方式推导卦名，容易搞反
```

---

### 10.2 变爻地支必须查之卦外卦列

**⚠️ 易错点**：变爻地支不是"随便推"的，必须查表！

**规则**：变爻在之卦的某个爻位，必须查**之卦外卦**的纳甲列

**错误示例**：
```
天火同人 101111 之 风火家人 101011
四爻动 → 变爻在之卦四爻
错误：认为变爻地支是"巳"
```

**正确做法**：
```
1. 确定变爻在哪一卦：之卦四爻属于外卦
2. 之卦外卦是什么？风火家人，外卦巽
3. 查巽外卦纳甲列：四爻未、五爻巳、上爻卯
4. 变爻地支 = 未（不是巳！）
```

**自检提示词**：
```
当我计算变爻时：
1. 变爻在之卦第几爻？
2. 该爻属于之卦的内卦还是外卦？
3. 之卦内/外卦是什么单卦？
4. 查该单卦对应的纳甲列，取对应爻位的地支
```

---

### 10.3 六亲判断要看清"谁克谁"

**⚠️ 易错点**：六亲判断时，"爻克宫"和"宫克爻"是不同的！

**规则对比**：
| 关系 | 六亲 | 说明 |
|------|------|------|
| 爻地支 **克** 卦宫 | 官鬼 | 爻是主动方 |
| 卦宫 **克** 爻地支 | 妻财 | 宫是主动方 |

**示例**：
```
卦宫五行=火，三爻地支=亥（水）
问：三爻六亲是什么？
答：水克火（爻克宫）→ 官鬼 ✓

错误思路：火克水（宫克爻）→ 妻财 ✗
原因：搞反了谁克谁！
```

**自检提示词**：
```
当我判断六亲时：
1. 爻地支五行是什么？
2. 卦宫五行是什么？
3. 问自己：谁克谁？是爻克宫，还是宫克爻？
   - 爻克宫 = 官鬼
   - 宫克爻 = 妻财
```

---

### 10.4 六合卦示例的正确选择

**⚠️ 易错点**：不是所有卦都能直观展示六合规则！

**正确示例**：天地否 000111
```
内卦乾：子、寅、辰
外卦坤：丑、亥、酉

对应爻位相合：
- 初子 与 四丑：子丑合 ✓
- 二寅 与 五亥：寅亥合 ✓
- 三辰 与 上酉：辰酉合 ✓

三组皆合，完美展示六合规则
```

**自检提示词**：
```
当我选六合卦示例时：
1. 纳甲装卦是否正确？
2. 内外卦对应爻位的地支是什么？
3. 是否真的相合？（查六合表验证）
```

## 十一、终极自检清单

**每次完成六爻计算后，必须过一遍此清单**：

### 代码层面
- [ ] 代码第n位 = 第n爻（不是反过来）
- [ ] 前3位 = 内卦，后3位 = 外卦
- [ ] 卦名XY：X在外（后3位），Y在内（前3位）

### 纳甲层面
- [ ] 内卦查"内卦"列，外卦查"外卦"列
- [ ] 变爻地支：查之卦的纳甲表，不是本卦
- [ ] 变爻在哪一卦？内卦还是外卦？查对应的列

### 六亲层面
- [ ] 六亲基于"爻地支五行"与"卦宫五行"的关系
- [ ] 谁克谁？谁生谁？方向不能反
- [ ] 爻克宫 = 官鬼，宫克爻 = 妻财

### 互卦层面
- [ ] 取二三四爻 = 取第2、3、4位的值
- [ ] 取三四五爻 = 取第3、4、5位的值
- [ ] 新组成的代码对应什么单卦？验证一下

## 十二、一句话总结

> **"位序对应要牢记，内外分清查对表，生克方向看清楚，取爻用位不用名，代码内前外后在"**

- 位序对应：第n位 = 第n爻
- 内外分清：内=下=前3位，外=上=后3位
- 生克方向：爻克宫≠宫克爻，方向决定六亲
- 取爻用位：说"取三四五爻"就是取第3、4、5位的值
- **代码组合：内卦代码在前 + 外卦代码在后 = 前3位 + 后3位**
