### 功能说明

**CsvImport.vue** 实现以下功能：
- 拖拽上传CSV文件
- 支持UTF-8和GBK编码
- 显示导入进度和结果统计

### CSV格式要求

```
格式: 年;月.日,本卦,之卦,占问事由,占断,图片路径
示例: 2024;02.12,山风蛊,火地晋,占问股票走势,占断上涨,
```

## 阶段二十五：卦例详情页面

### 任务完成情况

| 任务 | 描述 | 状态 |
|------|------|------|
| 25.1 | 详情页面布局 | ✓ |
| 25.2 | 卦理信息展示 | ✓ |
| 25.3 | 图片展示 | ✓ |

### 功能说明

**GualiDetail.vue** 实现以下功能：

#### 按照规范的输出格式展示

根据《输入输出查找规则.md》中的单卦例输出格式要求，详情页面顶部展示：

```
占问：[占问事由]
占断：[占断]
时间：[年(公历),月日(公历)]
神煞：干禄-[某地支]  驿马-[某地支]  羊刃-[某地支]  桃花-[某地支]
年柱   月柱   日柱   旬空
[年柱] [月柱] [日柱] [旬空]

{图片}
```

#### 详细信息展示

- **卦象信息**：本卦、之卦、卦宫、宫位、代码
- **六爻详情**：按从上爻到初爻的顺序展示
  - 爻位（含世/应标记）
  - 六神
  - 地支
  - 六亲
  - 类型（阳/阴）
  - 状态（动/静）
- **神煞详情**：表格形式展示各神煞的详细信息
- **伏神信息**：如果有伏神，展示伏神详情表格
- **反吟伏吟**：如果有反吟伏吟，展示详情表格

#### 编辑功能

- 可编辑占问事由、占断、图片路径
- 时间字段和重卦字段禁止修改（符合规范）

### 神煞信息格式优化

神煞信息现在按照规范格式展示：
- 顶部显示：`干禄-寅  驿马-巳  羊刃-卯  桃花-酉`
- 详细表格显示：是否在卦中、具体爻位及类型（是神煞/带神煞）

## 技术实现

### 前端组件结构

```
frontend/src/views/
├── CsvImport.vue      # CSV导入页面
├── GualiList.vue      # 卦例列表页面
└── GualiDetail.vue    # 卦例详情页面
```

### API调用

所有页面通过 `frontend/src/api/index.js` 调用后端API：

```javascript
// 卦例相关
createGuali(data)
getGualiList(params)
getGuali(id)
getGualiDetail(id)
updateGuali(id, data)
deleteGuali(id)
importCsv(file)

// 图片相关
getImageConfig()
getImageUrl(filename)
```
