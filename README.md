# liuyaobase —— 六爻数据库系统

一个用于存储、查阅和分析六爻卦例的桌面工具。你可以导入手机端记录的卦例，打标签分类，用复杂条件检索，以及查看八宫变化和互卦。

## 快速开始

双击 `run.bat` 一键启动后端和前端。浏览器会自动打开 `http://localhost:5174/guali`。

```bash
# 或者分别启动：
# 后端 (默认 localhost:8001)
venv\Scripts\python -m uvicorn backend.main:app --host 127.0.0.1 --port 8001

# 前端 (默认 localhost:5174)
cd frontend && npm run dev
```

首次使用请先在"JSON 导入"页面导入你的卦例数据（支持 `.json` 和 `.ly` 文件）。

## C1 卦例管理

访问 `/guali`，左侧为卦例列表，右侧为卦例详情。

### 卦例列表（左侧栏）

- **搜索**：输入框支持混合搜索。比如输入 `1206` 会同时找到编号=1206、日期为 12 月 6 日、以及事由中含"1206"的卦例。如果输入 `0126`（前面带个 0），不会去匹配编号 126——因为如果你想找编号 126，直接输 `126` 就行。
- **标签筛选**：两级下拉，选一级标签后自动出现对应的二级标签。系统标签（占验情况）不在这里显示。
- **批量操作**：勾选卦例后可以批量删除。还有一个"批量查找"按钮，可以上传 CSV 或 JSON 文件，按编号列表批量检索。
- **侧栏折叠**：左侧边缘有一个小窄条，点击可以把整个侧栏收起来，给右侧详情腾地方。

### 卦例详情（右侧面板）

- **卦象表格**：显示本卦和之卦每一爻的六亲、地支、世应、动变标记。最上面一爻是上爻，最下面是初爻。
- **显示开关**：可以勾选显示或隐藏六神、天干、易冒三列。之卦默认只显示变爻，也可以切换为全部或隐藏。
- **编辑**：点"编辑"按钮或者直接双击文本就能修改占问事由和占断。改完点编辑区外面任意地方就自动保存了，按回车也行。一次点击同时保存两项。
- **占验情况**：在显示开关那行的最右边，有个下拉框可以标记这一卦是应验了、模糊、没验还是还没验。默认是"未验"（灰色），选了其它的之后边框会变成对应的颜色。
- **干支日历**：点击"年柱/月柱/日柱/旬空"那一行，会弹出一个日历，每一天都标了干支，节气日有特殊边框。可以翻页看任意年月，点 ⟳ 回到卦例的日期。
- **卦爻辞**：点击本卦名或之卦名，会弹出一个可以拖动的浮窗，里面有卦辞、彖传、象传和六爻的爻辞。
- **标签管理**：点标签旁边的 `+` 可以给这卦加标签，勾选就加上了，取消勾选就去掉。

### 导入卦例

- **JSON 导入** (`/import`)：把 `.json` 或 `.ly` 文件拖进去，点开始导入就行。同一个文件不会重复导入。去重的逻辑是：占问事由、占问时间、本卦、之卦四样完全一样才算是重复，有一项不同就当作新卦例。
- **手动导入** (`/input`)：填占问时间、占问事由、占断内容。本卦和之卦可以用"外卦+内卦"的方式选（选完后会自动显示卦名），也可以直接输入卦名。

### 标签管理 (`/tags`)

所有标签以树形显示。点击一级标签可以收起或展开它的子标签。标了"系统"的是系统内置标签，不能改名也不能删除。

## C2 解卦模块

导航栏"解卦"下拉菜单里有三个功能。

### 八宫变化 (`/jiegua/bagong`)

输入卦例编号，页面会显示本卦和之卦各自经过一世到归魂的七步演变，每一步一张小卡片，上面画了卦象、卦名和变化类型。右边还有一个网络图谱的缩小版，双击里面的节点可以填到左边空行里。图谱上的卦名可以常驻显示（勾选"卦名常驻"）。

### 互卦 (`/jiegua/hugua`)

输入卦例编号，显示这个卦的本卦互卦和之卦互卦。互卦就是把本卦中间四爻重新组合得到的新卦。

### 网络图谱 (`/jiegua/graph`)

一个可以拖拽、缩放的大图，展示 64 卦之间的演变关系。分"阳图谱"和"阴图谱"两种。节点颜色按卦宫分组。双击节点弹出卦爻辞。

## C3 复杂检索

访问 `/search`。这是最强大的功能，可以对所有卦例做多条件组合检索。

### 整体布局

页面分三栏：左边是字段库，中间是条件区和结果列表，右边是卦例详情（点击结果行才会出现）。

### 怎么用——举个例子

假如你想找"本卦六亲中有妻财爻、而且动爻数目等于 2"的卦例：

1. 在左边字段库的"爻属性"分类下，点击**本卦六亲**。条件区会出现一行条件。
2. 在这一行里，来源选"本卦"，字段选"本卦六亲"，运算符选"= (等于)"，值选"妻财"。
3. 在字段库的"数目"分类下，点击**属性数目**。条件区出现第二行，选"本卦"→"动爻"="是"→"的数目 = 2"。
4. 两行条件之间默认是 AND（并且）关系，刚好满足需求。点击条件区顶部的**搜索**按钮。
5. 结果列表里就是同时满足这两个条件的所有卦例。点击某一行，右边会出现这个卦的完整详情。

### 字段库

左边面板分 7 个大类，点击分类名可以展开或收起：

- **时间类**：年柱、月柱、日柱、旬空等。
- **卦类**：本卦和之卦的卦宫、宫位、特殊类型，以及反吟伏吟。
- **爻属性**：爻位、六亲、地支、天干、世应、动爻、暗动、六神、伏神等。注意每个属性的来源可以是本卦、变爻、之卦静爻、易冒伏神或增删伏神——你在添加条件后会看到第一个下拉框就是用来选来源的。
- **关系**：生克、合冲、半合、三合、生旺墓绝等。
- **神煞**：干禄、驿马、羊刃、桃花。
- **数目**：统计某个范围内满足条件的爻有几个。
- **其他**：文本搜索（按占问事由关键词）、标签筛选。

点击任意字段名就会在条件区自动创建一行条件。

### 条件构建

条件区底部有两行按钮，第一行是普通条件（时间、卦类、爻属性……），第二行是条件组（同一爻、同爻位、飞神）。

每种条件的格式都是一串下拉框和输入框的组合，按从左到右的顺序填就行了。下面简要说明每种条件：

- **爻属性/时间/卦类**：来源 → 字段名 → 运算符 → 值。
- **关系**：左对象 → 来源 → 关系（生克合冲等）→ 右对象。
- **神煞**：来源 → 对象 → 神煞类型。
- **数目**：统计范围 → 属性=值 → 运算符 → 数字。
- **文本搜索**：输入关键词，匹配占问事由。
- **标签筛选**：选择一级或二级标签。

### 逻辑连接

条件之间默认是**并且**（AND）关系。每条条件左边有几个小按钮：

- **AND / OR**：在"并且"和"或者"之间切换。OR 是橙黄色的，比较显眼。
- **NOT**：对这个条件取反。点一下变红，再点一下取消。
- **括号按钮** ⌈ 和 ⌋：给连续几条条件加括号分组（就像数学算式里的括号）。被括号包住的条件会有彩色边框提示。

### 条件组

三种特殊的"组合条件"，用于描述"同一爻同时满足多个条件"之类的情况：

- **同一爻**：勾选来源（比如本卦+变爻），然后在这个爻上叠多个条件。比如"六亲=妻财 且 地支=酉"。来源之间是"或者"关系。
- **同爻位**：指定爻位（初爻到上爻），对每个来源分别设条件。
- **飞神**：选择增删飞神或易冒飞神，指定用神（妻财/官鬼等），查找飞神符合条件的卦例。

### 结果与导出

- 列表显示编号、时间、事由、本卦名、之卦名。点击本卦或之卦名能弹出卦爻辞。
- 右上角可以导出为 CSV 或 JSON 文件，文件名可以自己改。
- 勾选结果行后可以批量打标签，配合"全选所有结果"能一次性给检索出的所有卦例加标签。
- 点击结果行，右侧会出现这个卦的完整详情（和 C1 一模一样，也支持编辑和占验情况标记）。

### 方案保存

条件区下方的方案管理可以把你当前的条件和逻辑保存为一个方案，下次直接用。适合保存常用的检索模板，比如"所有动爻≥2 的卦例"。

## 浮动笔记

右下角有一个圆形图标，点一下（或者按 `Ctrl+Shift+Space`）会弹出一个笔记浮窗。这是一个随时记录灵感的随手笔记工具，内容保存在浏览器本地。可以创建多篇笔记，左侧切换，右侧编辑。浮窗可以拖动和调整大小。

### 类 Markdown 语法

在笔记正文中，除了正常打字之外，还可以用以下格式：

| 输入 | 效果 |
|------|------|
| `**524**` | 变成蓝色 `#524`，点击跳转到该卦例。整块删除（不会一个字一个字删） |
| `*斜体*` | *斜体文字* |
| `~~删除~~` | ~~删除线~~ |
| `` `代码` `` | `等宽代码字体` |
| `# 标题` | 一级标题 |
| `## 标题` | 二级标题 |
| `### 标题` | 三级标题 |
| `- 项目` 或 `* 项目` | 无序列表 |
| `1. 项目` | 有序列表 |
| `> 引用` | 引用块 |
| `---` 或 `***` | 分割线 |
| Tab 键 | 插入 4 个空格缩进 |

> **小提示**：如果不小心触发了某种格式（比如打了 `` ` `` 之后所有字都变成等宽字体了），按回车换一行就能退出这个格式。

## 技术参考

### 技术栈

| 层 | 技术 |
|---|------|
| 后端 | Python FastAPI + SQLModel + MySQL |
| 前端 | Vue 3 + Vite + Pinia + Vue Router + Tiptap |
| 算法 | [lunar-python](https://github.com/6tail/lunar-python)（干支节气）、自研六爻排盘 |
| 数据 | AKShare（股票行情） |

### 架构

```
┌─────────────────────────────────────────┐
│              前端 (Vue 3)                │
│   views/  components/  stores/  router/ │
├─────────────────────────────────────────┤
│           API 层 (FastAPI)               │
│  /guali  /tags  /search  /jiegua  ...   │
├─────────────────────────────────────────┤
│           服务层 (services/)              │
│  guali  tag  search  precalculate  ...  │
├─────────────────────────────────────────┤
│          数据访问层 (crud/)               │
│  guali  tag  bagong_gua  guaci  ...     │
├─────────────────────────────────────────┤
│          数据库 (MySQL)                  │
│  16 表 + 36 索引 + 8 存储函数           │
└─────────────────────────────────────────┘
```
