## 附录A：用户使用指南

> 本附录用通俗易懂的方式，帮助您快速理解如何使用复杂检索功能。

### A.1 整体概念：一个"卦例搜索引擎"

把复杂检索模块想象成一个**搜索引擎**（类似百度或Google），但它专门搜索卦例。

```
┌─────────────────────────────────────────────────────────────┐
│                     复杂检索 = 卦例搜索引擎                    │
│                                                              │
│   输入：您想要的卦例特征                                      │
│   输出：符合条件的卦例列表                                    │
└─────────────────────────────────────────────────────────────┘
```

### A.2 字段分类通俗解释

**想象一下**：您在图书馆找书。

- **时间类字段** = 按出版日期找书
  - 例如：找"2024年出版的书" → 找"公历年=2024的卦例"
  - 例如：找"3月份出版的书" → 找"月支=卯的卦例"

- **卦类字段** = 按书分类找书
  - 例如：找"小说类" → 找"本卦卦宫=乾宫的卦例"
  - 例如：找"精装书" → 找"本卦特殊类型=六合的卦例"

- **爻属性字段** = 按书中内容找书（有5种来源可选）
  - 例如：找"包含'爱情'的书" → 找"六亲=妻财的卦例"
  - 五种来源：本卦、变爻、之卦(静爻)、易冒伏神、增删伏神

- **关系字段** = 判断两个地支之间的关系
  - 例如：判断"小明和小红是兄妹" → 判断"两个地支是否相合"

- **神煞字段** = 判断某地支的神煞属性
  - 例如：判断"某人是否有驾照" → 判断"某地支是否为/带干禄"

- **数目判断** = 统计某属性的数量
  - 例如：找"超过3个作者的书" → 找"本卦动爻数目>2的卦例"

### A.3 条件组通俗解释

**条件组 = 把多个条件打包在一起，作为一个整体**

#### 两种条件组

**类比：在人群中找人**

```
同一爻条件组：找"穿红衣服 或 戴眼镜的人"（满足任一条件即可）
同爻位条件组：找"第3排中，穿红衣服 且 戴眼镜的人"（必须全部满足）
```

#### 1. 同一爻条件组（OR逻辑）

**用途**：在多个来源中找符合条件的爻，只要**任一来源**满足即可。

```
┌─────────────────────────────────────────────┐
│ 同一爻条件组                           [×]   │
│ 来源：☑ 本卦  ☑ 增删伏神  ☐ 变爻           │
│ 条件：[六亲] [=] [妻财] AND [地支] [=] [午] │
└─────────────────────────────────────────────┘

含义：本卦中或增删伏神中，有六亲=妻财且地支=午的爻
```

**注意**：同一爻条件组中，爻位是可选的，可以在条件组内指定。

#### 2. 同爻位条件组（AND逻辑）

**用途**：要求多个来源在**同一爻位**上都满足条件。

```
┌─────────────────────────────────────────────┐
│ 同爻位条件组                           [×]   │
│ 爻位：[第3爻] ← 在条件组外指定                │
│                                             │
│ ┌─ 本卦 ─────────────────────────┐         │
│ │ [六亲] [=] [妻财]              │         │
│ └────────────────────────────────┘         │
│                                             │
│ ┌─ 增删伏神 ─────────────────────┐         │
│ │ [六亲] [=] [官鬼]              │         │
│ └────────────────────────────────┘         │
└─────────────────────────────────────────────┘

含义：第3爻位上，本卦是妻财 且 增删伏神是官鬼
```

**注意**：同爻位条件组中，爻位**必须在条件组外**指定。

#### 3. 飞神条件组

**用途**：快速筛选"用神为某六亲时的飞神"。

```
┌─────────────────────────────────────────────┐
│ 飞神条件组                             [×]   │
│ 飞神类型：◉ 增删飞神  ○ 易冒飞神            │
│ 用神（六亲）：[妻财 ▼]                       │
└─────────────────────────────────────────────┘
```

**含义**：
1. 首先找到"增删伏神中六亲为某六亲的爻"（前提：本卦没有该六亲）
2. 然后返回"与这个伏神同爻位的本卦爻" = 飞神
3. 如果有多个爻位都有该六亲伏神，返回所有对应的飞神

**重要说明**：
- **飞神条件组总是返回所有飞神**（可能有多个爻位），如需限定爻位，请用AND连接同一爻条件组
- 在后端检索时，如果本卦已有该六亲（无伏神），该卦例会被自动排除（不匹配）

#### 五种爻来源

| 来源 | 说明 | 使用场景 |
|-----|------|---------|
| 本卦 | 起卦得到的主卦 | 查询主卦中的爻 |
| 变爻 | 动爻变化后的状态 | 查询动爻变成什么 |
| 之卦(静爻) | 变卦后没有动的爻 | 查询变卦后的静爻 |
| 易冒伏神 | 按《易冒》方法装的伏神 | 查询传统伏神 |
| 增删伏神 | 按《增删卜易》方法装的伏神 | 查询实用派伏神 |

### A.4 关系字段通俗解释

**核心原则：关系字段处理的是地支之间的关系，不是爻本身**

**类比：判断两个人之间的关系**

```
普通字段：小明的身高 = 180cm（单一属性）
关系字段：小明和小红 是 兄妹（两人关系）
       → 实际判断：小明的【身份证号】和小红的【身份证号】是否匹配
```

**为什么是地支？**
- 爻的五行属性来自地支（如"子"属水）
- 生克合冲等关系都是地支之间的关系
- 所以系统自动获取爻的地支来判断关系

#### 关系类型

| 类型 | 有无顺序 | 是否有"于"字 | 例子 |
|-----|---------|-------------|------|
| 生克关系 | 有顺序 | 无 | 甲生乙 ≠ 乙生甲 |
| 合冲关系 | 无顺序 | 无 | 甲合乙 = 乙合甲 |
| 地支相同 | 无顺序 | 无 | 甲 = 乙 |
| 生旺墓绝 | 有顺序 | **有** | 甲长生 于 乙 |

#### 场景1：生克关系（有顺序，无"于"字）

```
┌─────────────────────────────────────────────┐
│ [妻财爻] [生] [世爻]                   [×]   │
└─────────────────────────────────────────────┘

含义：妻财爻的五行属性 生 世爻的五行属性
例如：妻财爻是午火，世爻是辰土，火生土，匹配成功！
```

#### 场景2：合冲关系（无顺序，无"于"字）

```
┌─────────────────────────────────────────────┐
│ [妻财爻] [相合] [月支]                 [×]   │
└─────────────────────────────────────────────┘

含义：妻财爻地支 与 月支 相合（无方向）
例如：妻财爻是子，月支是丑，子丑相合！
```

#### 场景3：生旺墓绝（有顺序，有"于"字）

```
┌─────────────────────────────────────────────┐
│ [妻财爻] [长生] [于] [月支]           [×]   │
└─────────────────────────────────────────────┘

含义：妻财爻 的长生位是 月支
例如：妻财爻是巳火，长生在寅，所以月支=寅时匹配
```

**生旺墓绝四阶段表**：

| 五行 | 长生 | 帝旺 | 墓 | 绝 |
|-----|------|------|---|---|
| 金 | 巳 | 酉 | 丑 | 寅 |
| 木 | 亥 | 卯 | 未 | 申 |
| 水/土 | 申 | 子 | 辰 | 巳 |
| 火 | 寅 | 午 | 戌 | 亥 |

### A.5 神煞字段通俗解释

**核心概念：神煞是地支的神煞，判断某地支是否为/带某神煞**

```
┌─────────────────────────────────────────────┐
│ [妻财爻] [是] [干禄]                   [×]   │
└─────────────────────────────────────────────┘

含义：妻财爻的地支是干禄
```

**"是"和"带"的区别**：
- **是**：该地支本身就是某神煞（即该地支就是神煞所在的地支）
- **带**：该地支与神煞地支有相冲或相合关系（神煞传播规则：与神煞地支相冲或相合的地支也"带"该神煞）
- **是或带**：两者皆可

### A.6 数目判断通俗解释

**用途**：统计某属性在卦中的数量

```
┌─────────────────────────────────────────────┐
│ [本卦] 中 [六亲=妻财] 的数目 [=] [0]   [×]   │
└─────────────────────────────────────────────┘

含义：本卦中六亲为妻财的爻数目等于0（即本卦没有妻财爻）
```

**运算符**：=, ≠, >, <, ≥, ≤, 范围(如2-4)

### A.8 常见问题

**Q：同一爻条件组和同爻位条件组有什么区别？**

A：
- **同一爻条件组**：OR逻辑，从多个来源中找符合条件的爻，只要任一来源满足即可
  - 例如：本卦或增删伏神中有妻财爻（可以在不同爻位）
- **同爻位条件组**：AND逻辑，要求多个来源在同一爻位都满足条件
  - 例如：第3爻位上，本卦是妻财且增删伏神是官鬼

**Q：什么时候用关系字段？**

A：当您要判断"两个地支之间的关系"时，比如：
- 爻与爻的关系（相合、相冲、生克）
- 爻与时间的关系（长生、帝旺等）
- 地支是否相同

**Q：五种爻来源怎么选？**

A：
- 查主卦中的爻 → 选"本卦"
- 查动爻变化后的状态 → 选"变爻"
- 查变卦后的静爻 → 选"之卦(静爻)"
- 用《易冒》方法 → 选"易冒伏神"
- 用《增删卜易》方法 → 选"增删伏神"

**Q：关系字段什么情况用"于"字？**

A：
- **有"于"字**：生旺墓绝（长生、帝旺、墓、绝）
- **无"于"字**：生克、合冲、相同

**Q：飞神和伏神是什么关系？**

A：
- 伏神：藏在某爻下面的神
- 飞神：伏神所在爻位上的本卦爻
- 它们是"上下级"关系，在同一爻位

| **之卦(静爻)** | 之卦中未变化的爻 |
| **易冒伏神** | 每爻位的易冒伏神 |

#### B.3.2 爻属性字段与来源兼容性

| 字段名 | 本卦 | 变爻 | 之卦(静爻) | 易冒伏神 | 增删伏神 |
|--------|:----:|:----:|:----------:|:--------:|:--------:|
| 爻位 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 爻类型 | ✅ | ✅ | ✅ | ❌ | ❌ |
| 爻状态 | ✅ | ✅ | ✅ | ❌ | ❌ |
| 暗动 | ✅ | ❌ | ❌ | ❌ | ❌ |
| 六亲 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 天干 | ✅ | ✅ | ✅ | ❌ | ❌ |
| 地支 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 六神 | ✅ | ✅ | ✅ | ✅ | ✅ |
| 世应 | ✅ | ✅ | ✅ | ❌ | ❌ |
| 伏神存在 | ❌ | ❌ | ❌ | ❌ | ✅ |

**字段说明**：
- **天干**：易冒伏神和增删伏神没有天干属性
- **六神**：六神是爻位特征，即在该爻位上的爻都有对应的六神，所以所有来源都支持
- **世应**：世应是根据卦来的爻的特征，本卦和之卦（包括变爻和静爻）都有世应属性
- **爻类型**：伏神本身没有爻类型属性，只有本卦、变爻、之卦(静爻)支持
- **之卦(静爻)存在前提**：如果本卦没有动爻（爻变代码=000000），则之卦不存在，相关字段为NULL
- **变爻来源前提**：同理，"变爻"来源也需要卦例有动爻才存在

### B.4 特殊字段

#### B.4.1 关系字段

**格式**：
- 生克合冲/相同：`[地支1] [关系] [地支2]`
- 生旺墓绝：`[地支1] [关系] [于] [地支2]`

**可用对象**：

| 对象类型 | 可选项 |
|---------|--------|
| 位置类 | 世爻、应爻、初爻~上爻 |

#### B.4.2 神煞字段

**格式**：`[某地支] [是/带/是或带] [某神煞]`

**注意**：神煞是地支的属性，所有有地支的对象都可以判断神煞（包括年月日支）。

## 附录C：数目判断设计

### C.1 需求背景

数目判断是**卦级别**的功能，用于判断某属性在卦中的数量，例如：
- 本卦中妻财爻的数目 = 0（即本卦没有妻财）
- 本卦中动爻的数目 > 2
- 增删伏神存在的爻位数 = 3

### C.2 可判断数目的属性

| 属性 | 说明 | 可能的数目 | 适用来源 |
|-----|------|-----------|----------|
| 爻类型 | 阳爻/阴爻 | 0-6 | 本卦、之卦 |
| 爻状态 | 动爻/静爻 | 0-6 | 仅本卦 |
| 暗动 | 是/否 | 0-6 | 仅本卦 |
| 六亲 | 父母官鬼子孙妻财兄弟 | 0-2 | 本卦、变爻、增删伏神 |
| 地支 | 子丑寅卯... | 0-2 | 所有来源 |
| 增删伏神数目 | 有伏神的爻位 | 0-6 | 仅增删伏神 |

**来源说明**：
- **爻类型**：来源是本卦或之卦
- **爻状态**：只看本卦
- **暗动**：只看本卦
- **六亲**：支持本卦、变爻、增删伏神三种来源
- **地支**：支持所有来源

### C.3 交互设计

```
┌─────────────────────────────────────────────────────────────┐
│ 数目判断条件                                         [×]   │
│                                                             │
│ [本卦 ▼] 中 [六亲=妻财 ▼] 的数目 [=] [0 ▼]                  │
│                                                             │
│ 下拉选项：                                                   │
│ - 第一个：本卦、之卦（统计范围）                              │
│ - 第二个：爻类型、爻状态、暗动、六亲、地支、增删伏神数目        │
│ - 第三个：=, ≠, >, <, ≥, ≤, 范围                            │
│ - 第四个：数字或范围（如：0、1-3）                            │
└─────────────────────────────────────────────┘
```

### C.4 使用场景示例

**场景**：筛选"本卦没有妻财爻，且易冒伏神中的妻财爻被日支克"的卦例

```
条件1（数目判断）：
  [本卦] 中 [六亲=妻财] 的数目 [=] [0]

AND

条件2（同一爻条件组）：
  来源：易冒伏神
  条件：[六亲]=[妻财]

AND

条件3（关系条件）：
  [日支] [克] [条件组2的爻]
```

### C.5 设计确认

| 问题 | 确认结果 |
|-----|---------|
| 是否支持范围判断？ | ✅ 支持（如：动爻数目在2-4之间） |
| 是否支持组合统计？ | ❌ 不需要（如：妻财+官鬼总数目） |
| 是否可逻辑组合？ | ✅ 可以与其他条件用AND/OR连接 |
