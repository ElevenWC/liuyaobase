## 二、Pinia 状态管理

### 2.1 为什么选择 Pinia？

| 对比项 | Vuex (旧) | Pinia (新) |
|--------|-----------|------------|
| TypeScript 支持 | 一般 | 完美支持 |
| 代码复杂度 | 需要 mutations | 直接修改，更简洁 |
| Vue 3 兼容 | 需要 Vuex 4 | 原生支持 |
| **官方推荐** | 已不推荐 | **Vue 官方推荐** |

### 2.2 Pinia Store 设计

```typescript
// stores/useSearchStore.ts
import { defineStore } from 'pinia'
import { ref, computed } from 'vue'

export const useSearchStore = defineStore('search', () => {
  // 状态
  const conditions = ref<Condition[]>([])
  const logicChain = ref<LogicItem[]>([])
  const results = ref<SearchResult[]>([])
  const pagination = ref({ page: 1, pageSize: 20, total: 0 })

  // 计算属性
  const expressionPreview = computed(() => {
    return buildExpressionString(conditions.value, logicChain.value)
  })

  // 方法
  async function executeSearch() {
    const response = await fetch('/api/v3/search', {
      method: 'POST',
      body: JSON.stringify({
        conditions: conditions.value,
        logic: logicChain.value,
        pagination: pagination.value
      })
    })
    const data = await response.json()
    results.value = data.data.results
    pagination.value.total = data.data.total
  }

  return { conditions, logicChain, results, pagination, expressionPreview, executeSearch }
})
```

## 三、预计算字段详解

### 3.1 为什么需要预计算？

| 类型 | 特点 | 示例 |
|------|------|------|
| **静态字段** | 存入数据库时确定 | 本卦代码、爻变代码、占问时间 |
| **动态字段** | 需要实时计算 | 六神、神煞、暗动 |

**解决方案**：在导入卦例时，预先计算并存储这些动态字段，支持索引查询。

## 五、条件组设计

> **详细设计请参见 .C33前端字段构建方案.md 第3章。**

### 5.1 三种条件组

| 条件组类型 | 核心约束 | 多选来源逻辑 | 爻位指定位置 |
|-----------|---------|-------------|-------------|
| **同一爻条件组** | 同一**来源**的爻 | **OR** | 可以在条件组内 |
| **同爻位条件组** | 同一**爻位** | **AND** | **只能**在条件组外 |
| **飞神条件组** | 本卦中与伏神同爻位的爻 | 返回所有飞神 | 用神六亲指定 |

### 5.2 同一爻条件组SQL生成（OR逻辑）

```sql
-- 示例：本卦或增删伏神中有妻财午火
SELECT DISTINCT g.*
FROM guali g
JOIN guali_yao y ON g.id = y.guali_id
WHERE (y.ben_liuqin = '妻财' AND y.ben_dizhi = '午')           -- 本卦
   OR (y.zengshan_liuqin = '妻财' AND y.zengshan_dizhi = '午' AND y.zengshan_exists = TRUE);
```

### 5.3 同爻位条件组SQL生成（AND逻辑）

```sql
-- 示例：第3爻位上，增删伏神是官鬼，本卦是世爻
SELECT DISTINCT g.*
FROM guali g
JOIN guali_yao y ON g.id = y.guali_id
WHERE y.yao_position = 3
  AND y.zengshan_liuqin = '官鬼'
  AND y.zengshan_exists = TRUE
  AND y.ben_shi_ying = '世';
```

### 5.4 飞神条件组SQL生成

```sql
-- 示例：月支克增删飞神（用神为妻财）
-- 飞神 = 与伏神同爻位的本卦爻
SELECT DISTINCT g.*
FROM guali g
JOIN guali_yao y ON g.id = y.guali_id
JOIN guali_time t ON g.id = t.guali_id
WHERE y.zengshan_exists = TRUE
  AND y.zengshan_liuqin = '妻财'
  AND check_ke(t.month_zhi, y.ben_dizhi) = TRUE;
```

## 六、关系字段设计

> **详细设计请参见 .C33前端字段构建方案.md 第4章。**

### 6.1 关系类型

| 关系类型 | 有无顺序 | 是否有"于"字 | SQL函数 |
|---------|:--------:|:------------:|---------|
| 生/克 | 有顺序 | 无 | `check_sheng/check_ke(dizhi1, dizhi2)` |
| 相合/相冲 | 无顺序 | 无 | `check_he/check_chong(dizhi1, dizhi2)` |
| 半合/三合 | 无顺序 | 无 | `check_banhe(dizhi1, dizhi2)` |
| = | 无顺序 | 无 | `dizhi1 = dizhi2` |
| 长生/帝旺/墓/绝 | 有顺序 | **有** | `check_shengwang(dizhi1, dizhi2, type)` |

### 6.2 SQL生成示例

```sql
-- [妻财爻] [生] [世爻]
SELECT DISTINCT g.*
FROM guali g
JOIN guali_yao y1 ON g.id = y1.guali_id  -- 妻财爻
JOIN guali_yao y2 ON g.id = y2.guali_id  -- 世爻
WHERE y1.ben_liuqin = '妻财'
  AND y2.ben_shi_ying = '世'
  AND check_sheng(y1.ben_dizhi, y2.ben_dizhi) = TRUE;

-- [妻财爻] [长生] [于] [月支]
SELECT DISTINCT g.*
FROM guali g
JOIN guali_yao y ON g.id = y.guali_id
JOIN guali_time t ON g.id = t.guali_id
WHERE y.ben_liuqin = '妻财'
  AND check_shengwang(y.ben_dizhi, t.month_zhi, '长生') = TRUE;
```

## 七、神煞字段设计

> **详细设计请参见 .C33前端字段构建方案.md 2.6节和4.7节。**

### 7.1 "是/带"判断

| 判断方式 | 含义 | 存储字段 |
|---------|------|---------|
| **是** | 该爻地支本身就是神煞地支 | `*_is_ganlu` 等 |
| **带** | 该爻地支与神煞地支有冲或合关系 | `*_dai_ganlu` 等 |
| **是或带** | 两者皆可 | OR查询 |

### 7.2 SQL生成示例

```sql
-- [妻财爻] [是] [干禄]
SELECT DISTINCT g.*
FROM guali g
JOIN guali_yao y ON g.id = y.guali_id
JOIN guali_shensha s ON g.id = s.guali_id
WHERE y.ben_liuqin = '妻财'
  AND FIND_IN_SET(y.yao_position, s.ben_is_ganlu) > 0;

-- [妻财爻] [是或带] [桃花]
SELECT DISTINCT g.*
FROM guali g
JOIN guali_yao y ON g.id = y.guali_id
JOIN guali_shensha s ON g.id = s.guali_id
WHERE y.ben_liuqin = '妻财'
  AND (FIND_IN_SET(y.yao_position, s.ben_is_taohua) > 0
    OR FIND_IN_SET(y.yao_position, s.ben_dai_taohua) > 0);
```

## 八、数目判断设计

> **详细设计请参见 .C33-1前端字段构建方案附录.md 附录C。**

### 8.1 功能说明

数目判断是**卦级别**的功能，用于判断某属性在卦中的数量。

### 8.2 可判断数目的属性

| 属性 | 适用来源 | SQL计算方式 |
|-----|---------|-------------|
| 爻类型 | 本卦、之卦 | `COUNT(*) WHERE ben_yao_type='阳'` |
| 爻状态 | 仅本卦 | `COUNT(*) WHERE is_dong=TRUE` |
| 暗动 | 仅本卦 | `COUNT(*) WHERE is_an_dong=TRUE` |
| 六亲 | 本卦、变爻、增删伏神 | `COUNT(*) WHERE ben_liuqin='妻财'` |
| 地支 | 所有来源 | `COUNT(*) WHERE ben_dizhi='子'` |
| 增删伏神数目 | 仅增删伏神 | `COUNT(*) WHERE zengshan_exists=TRUE` |

### 8.3 SQL生成示例

```sql
-- [本卦] 中 [六亲=妻财] 的数目 [=] [0]
SELECT g.*
FROM guali g
WHERE NOT EXISTS (
    SELECT 1 FROM guali_yao y
    WHERE y.guali_id = g.id AND y.ben_liuqin = '妻财'
);

-- [本卦] 中 [爻状态=动爻] 的数目 [>] [2]
SELECT g.*
FROM guali g
WHERE (SELECT COUNT(*) FROM guali_yao y WHERE y.guali_id = g.id AND y.is_dong = TRUE) > 2;
```

## 九、SQL生成器设计

### 9.1 条件组SQL生成器

```python
class ConditionGroupBuilder:
    """条件组SQL生成器"""

    SOURCE_FILTERS = {
        '本卦': '1=1',
        '变爻': 'y.is_dong = TRUE',
        '之卦(静爻)': 'y.is_dong = FALSE',
        '易冒伏神': '1=1',
        '增删伏神': 'y.zengshan_exists = TRUE'
    }

    def build_same_yao_group(self, group: Dict) -> str:
        """构建同一爻条件组（OR逻辑）"""
        sources = group['sources']
        conditions = group['conditions']

        source_sqls = []
        for source in sources:
            source_filter = self.SOURCE_FILTERS.get(source, '1=1')
            cond_sqls = []
            for cond in conditions:
                column = self._get_column(source, cond['field'])
                if column:
                    cond_sqls.append(f"y.{column} {cond['operator']} '{cond['value']}'")

            if cond_sqls:
                source_sql = f"({' AND '.join(cond_sqls)})"
                if source_filter != '1=1':
                    source_sql = f"({source_filter} AND {source_sql})"
                source_sqls.append(source_sql)

        return f"({' OR '.join(source_sqls)})"

    def build_same_position_group(self, group: Dict) -> str:
        """构建同爻位条件组（AND逻辑）"""
        position = group.get('position')
        conditions = [f"y.yao_position = {position}"]

        for source_config in group['sources']:
            source = source_config['source']
            source_filter = self.SOURCE_FILTERS.get(source, '1=1')
            if source_filter != '1=1':
                conditions.append(source_filter)
            for cond in source_config['conditions']:
                column = self._get_column(source, cond['field'])
                if column:
                    conditions.append(f"y.{column} {cond['operator']} '{cond['value']}'")

        return f"({' AND '.join(conditions)})"
```

### 9.2 神煞SQL生成器

```python
class ShenshaBuilder:
    """神煞字段SQL生成器"""

    SHENSHA_FIELDS = {
        '干禄': {'is': 'ganlu', 'dai': 'ganlu'},
        '驿马': {'is': 'yima', 'dai': 'yima'},
        '羊刃': {'is': 'yangren', 'dai': 'yangren'},
        '桃花': {'is': 'taohua', 'dai': 'taohua'}
    }

    def build_shensha_condition(self, obj: str, judge: str, shensha: str, sources: List[str]) -> str:
        conditions = []
        for source in sources:
            prefix = SOURCE_PREFIXES[source]  # 'ben', 'zhi', 'yimao', 'zengshan'
            if judge in ['是', '是或带']:
                field = f"{prefix}_is_{self.SHENSHA_FIELDS[shensha]['is']}"
                conditions.append(f"FIND_IN_SET(y.yao_position, s.{field}) > 0")
            if judge in ['带', '是或带']:
                field = f"{prefix}_dai_{self.SHENSHA_FIELDS[shensha]['dai']}"
                conditions.append(f"FIND_IN_SET(y.yao_position, s.{field}) > 0")

        return f"({' OR '.join(conditions)})"
```

### 9.3 数目判断SQL生成器

```python
class NumberJudgmentBuilder:
    """数目判断SQL生成器"""

    def build_number_judgment(self, scope: str, attr: str, value: str, operator: str) -> str:
        # 解析属性
        if '=' in attr:
            field, field_value = attr.split('=')
            subquery = f"SELECT COUNT(*) FROM guali_yao y WHERE y.guali_id = g.id AND y.{self._get_column(field, scope)} = '{field_value}'"
        else:
            subquery = f"SELECT COUNT(*) FROM guali_yao y WHERE y.guali_id = g.id AND y.{self._get_column(attr, scope)} = TRUE"

        return f"({subquery}) {operator} {value}"
```

## 附录：索引说明

### 什么是索引？

索引就像书的"目录"，可以快速定位数据位置。

```sql
CREATE INDEX idx_liushen ON guali_yao(liushen);
```

| 代码部分 | 含义 |
|---------|------|
| `CREATE INDEX` | 创建索引 |
| `idx_liushen` | 索引名称 |
| `ON guali_yao` | 在 guali_yao 表上 |
| `(liushen)` | 按 liushen 字段建索引 |

### 为什么索引能加快检索？

- **没有索引**：查询时要遍历所有记录
- **有索引**：直接定位到目标记录

### 本项目需要的索引

```sql
-- guali_yao 表

CREATE INDEX idx_ben_liuqin ON guali_yao(ben_liuqin);

CREATE INDEX idx_is_dong ON guali_yao(is_dong);
CREATE INDEX idx_is_an_dong ON guali_yao(is_an_dong);

-- guali_time 表
```
