> 本文档描述解卦模块的设计方案，包括八宫变化、互卦等解卦工具，并预留扩展接口

## 一、模块概述

### 1.1 模块定位

解卦模块（C2）是liuyaobase系统的核心功能之一，提供多种解卦工具帮助用户分析卦例。

### 1.2 包含的解卦工具

| 工具 | 状态 | 说明 |
|------|------|------|
| **八宫变化** | ✅ 确认 | 计算指定卦的七种变化（一世变至归魂变） |
| **互卦** | ✅ 确认 | 从本卦/之卦中提取互卦 |
| **网络图谱** | ✅ 确认 | 力导向布局展示卦之间的关系 |

### 1.3 模块架构

**解卦模块采用导航栏+独立页面架构**：

```
┌─────────────────────────────────────────────────────────────────┐
│  [八宫变化]  [互卦]  [未来工具...]          [卦例编号输入:___]   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│                     当前选中工具的页面内容                        │
│                                                                 │
│   - 八宫变化页面：八宫变化区域(3/4) + 网络图谱(1/4)              │
│   - 互卦页面：互卦显示区域                                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

**与数据库的关系**：
- 用户输入卦例编号 → C2直接查询 guali 表获取 ben_code, yao_bian_code, zhi_code
- 同时可查询 guali_gua 表获取卦宫、宫位、特殊类型等预存信息
- 自定义输入卦名时，通过 bagong_gua 表查询卦代码和属性
- C2 独立于 C1，不通过 C1 获取数据

## 二、八宫变化

### 2.1 功能说明

八宫变化是六爻预测中的核心理论，描述一卦如何通过爻位变化生成其他七卦。

### 2.2 使用限制

**重要规则**：上爻为动爻的卦，**不能使用八宫变化功能**。

```python
def can_use_bagong(yao_bian_code: str) -> bool:
    """
    判断是否可以使用八宫变化
    @param yao_bian_code: 6位爻变代码，1表示动爻
    @return: True表示可用，False表示不可用
    """
    # 上爻是第6位（索引5）
    return yao_bian_code[5] == '0'
```

**示例**：
```
爻变代码 = "100100" → 上爻=0 → 可以使用八宫变化 ✓
爻变代码 = "000001" → 上爻=1 → 不可以使用八宫变化 ✗
```

**卦例入口的数据来源**：

当用户通过卦例编号进入时，数据来源优先级如下：

| 数据 | 卦例编号入口 | 自定义卦名入口 |
|------|------------|--------------|
| 卦代码（ben_code/yao_bian_code/zhi_code） | guali 表 | 用户输入 + bagong_gua 查表 |
| 卦宫/宫位/特殊类型 | guali_gua 表（预存） | bagong_gua 表 |
| 五行 | bagong_gua 表 | bagong_gua 表 |

### 2.3 变化规则

| 变化类型 | 操作 |
|---------|------|
| 一世变 | 本卦第1位（初爻）取反 |
| 二世变 | 一世变第2位取反 |
| 三世变 | 二世变第3位取反 |
| 四世变 | 三世变第4位取反 |
| 五世变 | 四世变第5位取反 |
| 游魂变 | 五世变第4位取反 |
| 归魂变 | 游魂变前3位都取反 |

**注意**：八宫变化**只改变初爻到五爻**，**上爻永远不变**。

### 2.4 核心算法

```python
def flip_bit(code: str, position: int) -> str:
    """位取反"""
    arr = list(code)
    arr[position] = '1' if arr[position] == '0' else '0'
    return ''.join(arr)

def flip_bits(code: str, count: int) -> str:
    """批量位取反（前 n 位）"""
    return ''.join(
        ('1' if bit == '0' else '0') if index < count else bit
        for index, bit in enumerate(code)
    )

def calculate_bagong_bian(code: str) -> dict:
    """计算八宫变化（仅返回代码）"""
    ben = code
    yi_shi = flip_bit(ben, 0)       # 初爻取反
    er_shi = flip_bit(yi_shi, 1)    # 二爻取反
    san_shi = flip_bit(er_shi, 2)   # 三爻取反
    si_shi = flip_bit(san_shi, 3)   # 四爻取反
    wu_shi = flip_bit(si_shi, 4)    # 五爻取反
    you_hun = flip_bit(wu_shi, 3)   # 四爻取反
    gui_hun = flip_bits(you_hun, 3) # 前三位取反

    return {
        'ben': ben,
        'yiShi': yi_shi,
        'erShi': er_shi,
        'sanShi': san_shi,
        'siShi': si_shi,
        'wuShi': wu_shi,
        'youHun': you_hun,
        'guiHun': gui_hun
    }

def calculate_bagong_bian_with_names(code: str) -> dict:
    """计算八宫变化（含卦名映射，一次性查表避免前端二次查询）"""
    codes = calculate_bagong_bian(code)
    result = {}
    for key, code_val in codes.items():
        gua_info = db.get_gua_by_code(code_val)  # 查 bagong_gua 表
        result[key] = {
            'code': code_val,
            'name': gua_info.name,
            'palace': gua_info.palace,
            'element': gua_info.element,
        }
    return result
```

## 三、互卦

### 3.1 功能说明

从重卦中"互"出一个新卦，是解卦的重要辅助工具。

### 3.2 计算规则

**本卦互卦**：
- 互卦内卦 = 本卦二三四爻（位置索引 1, 2, 3）
- 互卦外卦 = 本卦三四五爻（位置索引 2, 3, 4）

**之卦互卦**：
- 互卦内卦 = 之卦二三四爻
- 互卦外卦 = 之卦三四五爻

### 3.3 核心算法

```python
def calculate_hu_gua(code: str) -> str:
    """
    计算互卦
    @param code: 6位本卦/之卦代码
    @return: 6位互卦代码
    """
    # 互卦内卦 = 二三四爻 (索引 1, 2, 3)
    inner = code[1] + code[2] + code[3]
    # 互卦外卦 = 三四五爻 (索引 2, 3, 4)
    outer = code[2] + code[3] + code[4]
    # 组合：内卦 + 外卦
    return inner + outer
```

### 3.4 完整示例

```
本卦：水泽节 110010
─────────────────────────────────────────
爻位分解（从左到右 = 初爻到上爻）：
- 第1位（初爻）：1（阳）
- 第2位（二爻）：1（阳）
- 第3位（三爻）：0（阴）  ← 以上三爻构成内卦兑110
- 第4位（四爻）：0（阴）
- 第5位（五爻）：1（阳）
- 第6位（上爻）：0（阴）  ← 以上三爻构成外卦坎010

本卦互卦计算：
- 内卦（取二三四爻）：第2位1、第3位0、第4位0 → 100 → 震卦
- 外卦（取三四五爻）：第3位0、第4位0、第5位1 → 001 → 艮卦
- 互卦代码：100001
- 查表得：山雷颐

之卦：兑为泽 110110
之卦互卦计算：
- 内卦（取二三四爻）：1, 0, 1 → 101 → 离卦
- 外卦（取三四五爻）：0, 1, 1 → 011 → 巽卦
- 互卦代码：101011
- 查表得：风火家人
```

## 四、网络图谱

### 4.1 图谱分类

由于八宫变化"上爻永远不变"的规则，64卦被分为两个独立的图谱：

**数据来源**：

| 数据类型 | 来源 | 说明 |
|---------|------|------|
| 节点信息（卦名、五行、代码） | bagong_gua 表 | 筛选上爻匹配的32卦 |
| 边信息（变化关系） | 八宫变化实时计算 | 每卦生成7条出边（一世→归魂） |
| 节点五行颜色 | 固定映射表 | 金#FFD700、木#228B22、水#1E90FF、火#FF4500、土#8B4513 |

**图谱构建流程**：

```
1. 根据本卦上爻判断图谱类型（上爻='1'→阳图谱，上爻='0'→阴图谱）
2. 从 bagong_gua 表筛选 code[5] 匹配的32卦作为节点
3. 对每个节点执行 calculate_bagong_bian() → 生成7条有向边
4. 组装 nodes + edges 返回前端渲染力导向图
```

| 图谱名称 | 上爻值 | 包含卦数 | 说明 |
|---------|--------|---------|------|
| **阳图谱** | 1 | 32卦 | 上爻为阳爻的所有卦 |
| **阴图谱** | 0 | 32卦 | 上爻为阴爻的所有卦 |

### 4.2 显示逻辑

```python
def get_graph_type(ben_code: str) -> str:
    """根据本卦代码判断应该显示哪个图谱"""

        return "阳图谱"
    else:
        return "阴图谱"
```

## 五、可扩展架构设计

### 5.1 设计原则

为未来可能加入的解卦方式预留扩展接口，采用策略模式。

### 5.2 解卦工具抽象接口

```python
from abc import ABC, abstractmethod
from typing import Dict, Any

class JieGuaTool(ABC):
    """解卦工具抽象基类"""

    @property
    @abstractmethod
    def name(self) -> str:
        """工具名称"""
        pass

    @property
    @abstractmethod
    def description(self) -> str:
        """工具描述"""
        pass

    @abstractmethod
    def can_use(self, ben_code: str, yao_bian_code: str) -> bool:
        """
        判断是否可以使用此工具
        @param ben_code: 本卦代码
        @param yao_bian_code: 爻变代码
        """
        pass

    @abstractmethod
    def calculate(self, ben_code: str, yao_bian_code: str, **kwargs) -> Dict[str, Any]:
        """
        执行解卦计算
        @return: 计算结果
        """
        pass


class BaGongBianTool(JieGuaTool):
    """八宫变化工具"""

    @property
    def name(self) -> str:
        return "八宫变化"

    @property
    def description(self) -> str:
        return "计算指定卦的七种变化（一世变至归魂变）"

    def can_use(self, ben_code: str, yao_bian_code: str) -> bool:
        return yao_bian_code[5] == '0'  # 上爻非动爻

    def calculate(self, ben_code: str, yao_bian_code: str, **kwargs) -> Dict[str, Any]:
        return calculate_bagong_bian(ben_code)


class HuGuaTool(JieGuaTool):
    """互卦工具"""

    @property
    def name(self) -> str:
        return "互卦"

    @property
    def description(self) -> str:
        return "从卦中提取互卦"

    def can_use(self, ben_code: str, yao_bian_code: str) -> bool:
        return True  # 互卦总是可用

    def calculate(self, ben_code: str, yao_bian_code: str, **kwargs) -> Dict[str, Any]:
        ben_hu = calculate_hu_gua(ben_code)
        result = {"ben_hu_gua": ben_hu}
        if kwargs.get("zhi_code"):
            result["zhi_hu_gua"] = calculate_hu_gua(kwargs["zhi_code"])
        return result


# 工具注册表
JIEGUA_TOOLS: Dict[str, JieGuaTool] = {
    "bagong": BaGongBianTool(),
    "hugua": HuGuaTool(),
    # 未来可添加更多工具：
    # "shensha": ShenShaTool(),
    # "liuyao_qimen": LiuYaoQiMenTool(),
}
```

### 6.2 八宫卦序表结构

```sql
CREATE TABLE bagong_gua (
    code VARCHAR(6) PRIMARY KEY,     -- 6位二进制代码
    name VARCHAR(20) NOT NULL,       -- 卦名（如"乾为天"）
    palace VARCHAR(10) NOT NULL,     -- 所属宫（乾宫、坤宫等）
    element VARCHAR(5) NOT NULL,     -- 五行属性（金/木/水/火/土）

);
```

### 6.3 卦爻辞表结构

```sql
CREATE TABLE guaci (
    code VARCHAR(6) PRIMARY KEY,     -- 6位二进制代码
    gua_ci TEXT,                     -- 卦辞
    tuan_zhuan TEXT,                 -- 彖传
    xiang_zhuan TEXT,                -- 象传
    yao_ci JSON,                     -- 爻辞（JSON格式，初爻到上爻）
    wenyan TEXT,                     -- 文言传（仅乾坤二卦有，用 | 表示换行）
    yong JSON                        -- 用九/用六（仅乾坤二卦有，含辞和象传）
);
```

**乾坤二卦特殊说明**：
- 乾为天（code=111111）：读取 `wenyan`（乾文言）和 `yong.用九`（含 yaoCi 和 xiangZhuan）
- 坤为地（code=000000）：读取 `wenyan`（坤文言）和 `yong.用六`（含 yaoCi 和 xiangZhuan）
- 其他62卦：wenyan 和 yong 字段为 NULL，不显示

## 九、命名冲突风险评估

### 9.1 问题描述

在六爻系统中，存在两套"八宫"相关的命名：

| 命名 | 来源 | 含义 |
|------|------|------|
| 本宫卦、一世卦、二世卦... | 卦例显示系统 | 根据卦宫五行判断的卦类型 |
| 本宫卦、一世卦、二世卦... | 八宫变化系统 | 根据爻位变化规则得出的变化类型 |

### 9.2 风险评估

**结论：命名重复风险较低，可以接受。**

原因分析：
1. **上下文隔离**：卦例显示系统用于展示单个卦例的属性，八宫变化系统用于展示卦与卦之间的关系，两者在不同的UI区域
2. **数据来源不同**：卦例显示系统的"宫位类型"来自数据库查询，八宫变化系统的"变化类型"来自实时计算
3. **唯一交互点是卦例编号**：八宫变化只通过"卦例编号"获取本卦代码，之后的所有计算和显示都独立于卦例显示系统

### 9.3 建议的命名区分

| 场景 | 卦例显示系统 | 八宫变化系统 |
|------|-------------|-------------|
| 变量前缀 | `gua_` | `bagong_` |
| 示例 | `gua_palace_type` | `bagong_change_type` |
| 中文注释 | 宫位类型（如：本宫卦） | 变化类型（如：一世变） |

**乾坤二卦特殊处理**：

| 特殊内容 | 数据来源 | 显示方式 |
|---------|---------|---------|
| 用九/用六 | guaci.yong（JSON） | 在所有爻辞最下方额外显示，含爻辞和小象传 |

渲染逻辑伪代码：

```python
def render_guaci_float(gua_code: str):
    content = db.get_guaci(gua_code)

    result = {
        'gua_ci': content.gua_ci,
        'tuan_zhuan': content.tuan_zhuan,
        'xiang_zhuan': content.xiang_zhuan,
        'yao_list': content.yao_ci,  # 初爻到上爻
    }

    # 乾坤二卦特殊处理
    if gua_code in ('111111', '000000'):
        result['yong'] = content.yong       # 用九/用六
        result['wenyan'] = content.wenyan.replace('|', '\n')  # 文言传换行

    return result
```
